README: Руководство пользователя Sketchware Pro 7

О чём этот документ

Данный репозиторий содержит полное руководство пользователя по приложению Sketchware Pro 7. Это не описание самого приложения как продукта, а инструкция по его использованию — навигация по интерфейсу, настройка, работа с проектами, виджетами, компонентами и практические примеры.

Руководство оформлено в виде HTML-файла (help_sketchware_pro.html) с адаптивным интерфейсом для мобильных устройств.

Технические особенности руководства

Формат

· HTML-файл с встроенными CSS-стилями
· Адаптивная вёрстка для мобильных устройств
· Изображения встроены в документ (base64)

Навигация

· Боковое меню (сайдбар) со списком всех 225 страниц
· Кнопка-гамбургер для открытия/закрытия меню на мобильных
· Нижняя панель навигации с кнопками «Назад» / «Вперёд» и отображением текущего раздела
· Переключение страниц через JavaScript без перезагрузки

Структура каждой страницы

· Заголовок раздела
· Основной контент (текст, таблицы, изображения)
· Футер с информацией об авторе
· Горизонтальная линия разделителя

Интерактивные элементы

· Кликабельные ссылки в оглавлении
· Подсветка активного раздела в меню
· Оверлей для закрытия сайдбара на мобильных

Как использовать руководство

1. Откройте файл help_sketchware_pro.html в любом современном браузере
2. Навигация:
   · На мобильном: нажмите ☰ для открытия меню
   · На десктопе: сайдбар всегда виден слева
3. Поиск раздела: используйте боковое меню или кнопки «Назад/Вперёд»
4. Изучение: следуйте по порядку или выберите нужный раздел
5. Практика: начните с раздела «Создание первого проекта» и переходите к практическим проектам
