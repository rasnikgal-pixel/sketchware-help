Linear(V) — вертикальный

Linear(V) — линейный макет с вертикальным расположением элементов. Все дочерние виджеты выстраиваются в столбик сверху вниз, один под другим.

Иконка в палитре — три горизонтальные полоски друг под другом.

Как работает

  • Первый перетащенный виджет — самый верхний.
  • Второй — ниже первого.
  • Третий — ещё ниже.
  • Если виджеты не помещаются по высоте — они обрезаются снизу.
  • По умолчанию контейнер растягивается на всю ширину экрана.

Когда использовать

  • Основа любого простого экрана — заголовок сверху, содержимое в центре, кнопка снизу.
  • Формы — поле, поле, поле, кнопка — всё в столбик.
  • Списки карточек — несколько CardView друг под другом.
  • Настройки приложения — пункты меню один под другим.
  • Обёртка для содержимого внутри Scroll(V).

Как перетащить Linear(V) на макет

  1. Открой вкладку «Дизайнер».
  2. Раскрой категорию Layouts в палитре слева.
  3. Зажми Linear(V) и, не отпуская, перетащи его на макет.
  4. Отпусти в нужном месте — контейнер появится в разметке.
  5. Чтобы поместить внутрь него виджеты, перетаскивай их из палитры поверх этого контейнера — он подсветится, и виджет встанет внутрь.
  6. Внутрь Linear(V) можно так же перетаскивать другие контейнеры — например, Linear(H) для строки «иконка + текст».
⚠️ Важно: обычный тап по Linear(V) в палитре ничего не делает. Контейнер попадает на макет только перетаскиванием.

Свойства контейнера

Открой панель свойств, тапнув по контейнеру в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7.

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя контейнера. По этому имени контейнер виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — linear1, linear2 и т. д. Переименуй в contentColumn, если это основной столбик содержимого.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». Например, android:background="#FF0000".
Конвертировать Превратить этот контейнер в другой тип макета (например, в RelativeLayout). LinearLayout, RelativeLayout и другие. Если передумал и хочешь относительное позиционирование — выбери RelativeLayout.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет контейнер по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp — фиксированная ширина.		 match_parent, чтобы столбик занял весь экран по ширине.
Высота
Height		 Насколько высоким будет контейнер по вертикали. match_parent, wrap_content, число в dp. wrap_content — высота подстроится под содержимое.
Внутренний отступ
Padding		 Отступ внутри контейнера — от его краёв до содержимого. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Padding 16 со всех сторон — содержимое не липнет к краям экрана.
Внешний отступ
Margin		 Отступ снаружи контейнера — от него до соседних элементов и краёв родителя. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin top 8 — контейнер сдвинется на 8 dp вниз от предыдущего элемента.
Ориентация
Orientation		 Направление, в котором выстраиваются дочерние элементы. horizontal — в строку;
vertical — в столбик.		 Для Linear(V) стоит vertical, менять не нужно.
Сумма весов
Weight sum		 Общая сумма весов дочерних элементов. Нужна, если хочешь распределять свободное место между детьми в пропорциях. Число. 0 — не используется. 3, если три ребёнка с весом 1 — поделят высоту на три равные части.
Положение
Position		 Позиционирование контейнера внутри родителя (влияет на порядок и привязку). none — по умолчанию;
другие варианты зависят от типа родителя.		 Оставь none, если не работаешь с RelativeLayout-родителем.
Гравитация макета
Layout gravity		 Как контейнер выравнивается внутри родителя: по левому краю, центру, правому и т. п. none — по умолчанию;
например, center, center_horizontal, right.		 center_horizontal — столбик встанет по центру родителя.
Вес
Weight		 Доля свободного места родителя, которую займёт этот контейнер. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — контейнер заберёт всё оставшееся место в родителе.

Свойства изображения

Свойство (рус / англ) Что делает Значения Пример
Ресурс фона
Background resource		 Картинка-фон контейнера из ресурсов проекта. NONE — без фона;
любой drawable-ресурс.		 Установи NONE, если фон не нужен.
Цвет фона
Background color		 Заливка контейнера сплошным цветом. NONE — без цвета;
HEX или выбор из палитры (например, #FFFFFF).		 Белый фон для карточки содержимого — #FFFFFF.
Вращение
Rotation		 Поворот контейнера вокруг центра. Градусы. 0 — без поворота. 90 — контейнер развернётся на 90°.
Прозрачность
Alpha		 Насколько контейнер и его содержимое прозрачны. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 0.5 — половина прозрачности.
TranslationX Сдвиг контейнера по горизонтали без изменения его места в разметке (визуальный сдвиг). Число в dp. 0.0 — без сдвига. 20.0 — контейнер визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг контейнера по вертикали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.
ScaleX Масштаб по горизонтали — растягивает или сжимает контейнер по ширине. Число. 1.0 — исходный размер. 1.5 — ширина увеличится в 1,5 раза.
ScaleY Масштаб по вертикали — растягивает или сжимает контейнер по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: на первых порах достаточно четырёх свойств — Ширина, Высота, Внутренний отступ, Внешний отступ. Остальные оставь по умолчанию.

Практический пример: экран с шапкой и содержимым

  1. Перетащи на макет Linear(V) — он будет корневым.
  2. Внутрь него перетащи Linear(H) — это будет шапка.
  3. Внутрь шапки перетащи TextView с названием экрана.
  4. Ниже шапки (внутрь корневого Linear(V)) перетащи ещё один Linear(V) — это столбик содержимого.
  5. Внутрь столбика содержимого перетаскивай поля, кнопки и другие виджеты.
  6. Тапни по корневому Linear(V) и задай Внутренний отступ 16 со всех сторон.
⚠️ Важно: если элементов больше, чем помещается на экране — Linear(V) их обрезает. Чтобы добавить прокрутку, вложи Linear(V) внутрь Scroll(V). Без этого нижние элементы будут недоступны.
💡 Совет: для экрана с шапкой и подвалом используй структуру: Linear(V) → Linear(H) (шапка) + Scroll(V) → Linear(V) (содержимое) + Linear(H) (подвал). Так шапка и подвал останутся на месте, а прокручиваться будет только середина.
💡 Совет: не забывай про Padding — контент, прижатый к краям экрана, выглядит плохо. Добавляй 16dp отступов по краям.

Резюме

  • Linear(V) — контейнер, выстраивающий дочерние элементы в столбик сверху вниз.
  • Перетаскивается на макет так же, как любой другой виджет — перетаскиванием, а не тапом.
  • Виджеты и вложенные контейнеры попадают внутрь тем же способом: перетаскиванием поверх Linear(V).
  • Главные свойства: Ширина, Высота, Внутренний и Внешний отступы, Ориентация, Вес.
  • Свойства изображения (фон, прозрачность, вращение, масштаб) — визуальные, для тонкой настройки.
  • Лишние по высоте элементы обрезаются — для прокрутки оборачивай в Scroll(V).

Частые ошибки новичков

  • Тапают по Linear(V) в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Забывают про Scroll(V). Большой экран без обёртки в Scroll(V) — половина содержимого просто не видна.
  • Меняют Orientation вручную на horizontal — тогда контейнер превращается в строку и теряет смысл Linear(V).
  • Не задают Padding. Контент прижимается к краям — выглядит плохо и неудобно читается.
  • Складывают всё в один Linear(V) без вложенных контейнеров. Разметка запутывается, сложно менять отдельные блоки.
