RadioButton — радиокнопка

RadioButton — радиокнопка. Виджет, который может быть выбран или не выбран. Ключевое отличие от CheckBox: RadioButton работает только в группе (RadioGroup), и внутри группы выбрать можно только один вариант.

Иконка в палитре — круг с точкой внутри.

Как работает

  • Имеет два состояния: Checked = true (выбрана) или false (не выбрана).
  • Тап по радиокнопке выбирает её и снимает выбор с остальных в той же RadioGroup.
  • Вне RadioGroup работать как «группа» не будет — это просто одиночная кнопка.
  • При выборе срабатывает событие onCheckedChanged — там можно описать логику.
  • Внешне отличается от CheckBox: не квадрат с галочкой, а круг с точкой.

Когда использовать

  • Выбор одного варианта из нескольких:
    • пол (Мужской / Женский);
    • возрастная категория (до 18 / 18–25 / 25+);
    • способ оплаты (Карта / Наличные / Онлайн);
    • тип доставки (Курьер / Самовывоз).
  • Фильтры — «Сначала новые», «Сначала старые», «По популярности» (только один активен).
  • Анкеты и опросы — где на вопрос нужен один ответ.
  • Настройки — переключение между взаимоисключающими режимами.

Настройки

Настройка Что делает Значения
Text Подпись рядом с кнопкой. Любая строка.
Checked Начальное состояние (выбрана / не выбрана). Переключатель: вкл / выкл.
TextColor Цвет текста подписи. HEX или выбор из палитры.
TextSize Размер текста. Число в sp.
ButtonTint Цвет самого круга. HEX или выбор из палитры.
Enabled Активна ли кнопка. Переключатель: вкл / выкл.
Padding / Margin Внутренние и внешние отступы. Число в dp для каждой стороны.
Width / Height Ширина и высота. wrap_content или match_parent.

💡 Совет для новичков: главные свойства радиокнопки — Текст, Checked, Размер текста. Радиокнопки всегда добавляются в RadioGroup, а не в обычный контейнер.

Как перетащить RadioButton на макет

RadioButton, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Раскрой категорию Layouts в палитре слева.
  3. Зажми RadioGroup и, не отпуская, перетащи её на макет.
  4. Отпусти в нужном месте — группа появится в разметке.
  5. Раскрой категорию Widgets в палитре слева.
  6. Зажми RadioButton и, не отпуская, перетащи его поверх RadioGroup — группа подсветится, и кнопка встанет внутрь.
  7. Повтори перетаскивание 2–5 раз — по числу вариантов.
  8. Тапни по каждой кнопке в рабочей области и задай Текст — например, «Мужской», «Женский».
  9. Каждой радиокнопке присвой уникальный ID.
  10. Одной кнопке включи Checked = вкл, остальным оставь выкл.
  11. Если нужна логика при выборе — открой вкладку «События» и добавь событие onCheckedChanged.
⚠️ Важно: обычный тап по RadioButton в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: RadioButton вне RadioGroup не образует группу. Даже если их несколько, они не связаны между собой — можно будет «выбрать» сразу все.
⚠️ Важно: всем радиокнопкам в группе нужны уникальные ID. Если ID совпадают — переключение работать не будет.
⚠️ Важно: одна из кнопок должна быть Checked = true в свойствах. Иначе при запуске приложения не будет выбрано ничего, и логика может не сработать с первого тапа.
💡 Совет: ставь Orientation = vertical у RadioGroup, если вариантов больше двух. Горизонтальный режим годится только для 2–3 коротких подписей.
💡 Совет: для чтения выбранного варианта в логике используй блок getCheckedRadioButtonId у RadioGroup. Он вернёт ID выбранной кнопки.
💡 Совет: не используй RadioButton для выбора нескольких вариантов. Для этого — CheckBox. Частая путаница у новичков: радиокнопки — один вариант, чекбоксы — несколько.
❌ Частая ошибка: добавлять RadioButton в макет без RadioGroup. Тогда группа не работает: все кнопки ведут себя независимо.
❌ Частая ошибка: забывать про Checked = true хотя бы у одной кнопки. Пользователь запускает приложение и не понимает, что уже что-то «выбрано» — а выбор пустой.

Резюме

  • RadioButton — радиокнопка для взаимоисключающего выбора одного варианта из нескольких.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Работает только в составе RadioGroup. Без группы — просто одиночная кнопка.
  • Всем радиокнопкам в группе нужны уникальные ID — иначе переключение не работает.
  • Одной кнопке стоит задать Checked = вкл в свойствах — чтобы при запуске сразу был выбран вариант.
  • Ключевые свойства: Текст, Checked, Размер текста, Цвет текста.
  • Для чтения выбранного варианта в логике используется getCheckedRadioButtonId.
  • Для выбора нескольких вариантов используется CheckBox, а не RadioButton.

Частые ошибки новичков

  • Тапают по RadioButton в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетаскивают RadioButton без RadioGroup. Кнопки не образуют группу — можно «выбрать» все сразу.
  • Задают одинаковые ID. Переключение не работает.
  • Не ставят Checked = вкл ни одной кнопке. При запуске ничего не выбрано.
  • Путают с CheckBox. RadioButton — один вариант, CheckBox — несколько.
  • Не добавляют событие onCheckedChanged. Логика при выборе не срабатывает.
  • Делают горизонтальную RadioGroup с длинными подписями. Кнопки не помещаются. Лучше vertical.
