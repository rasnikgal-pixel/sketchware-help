CodeView — поле кода

CodeView — окно для отображения кода с подсветкой синтаксиса. Показывает текст так, как его видят программисты в редакторе: ключевые слова — одним цветом, строки — другим, комментарии — третьим.

Иконка в палитре — прямоугольник с символами < >.

Как работает

  • Отображает текст с форматированием, похожим на код в IDE.
  • Поддерживает подсветку синтаксиса для разных языков: Java, Kotlin, HTML, XML, JavaScript, C++, Python и других.
  • Может показывать номера строк слева.
  • Поддерживает перенос строк или горизонтальную прокрутку (в зависимости от настроек).
  • Может быть только для чтения или с возможностью выделения и копирования текста.

Когда использовать

  • Приложения-справочники по программированию.
  • Обучающие курсы — примеры кода внутри урока.
  • Документация библиотек — фрагменты API.
  • Заметки программиста — сохранённые сниппеты.
  • Демонстрация кода — например, «как выглядит этот блок в Java».

Настройки

Настройка Что делает Значения
Code Текст, который отображается (задаётся в логике). Любая строка с кодом.
Language Язык для подсветки. Java, Kotlin, HTML, XML, JavaScript, C++, Python и другие.
ShowLineNumbers Показывать ли номера строк. Переключатель: вкл / выкл.
WrapContent Переносить ли длинные строки. Переключатель: вкл / выкл.
TextSize Размер текста кода. Число в sp.
BackgroundColor Фон окна кода. HEX или выбор из палитры.
EnableLineWrap Включать/выключать перенос. Переключатель: вкл / выкл.
Width / Height Ширина и высота. match_parent или wrap_content.
HorizontalScrollingEnabled Горизонтальная прокрутка при длинных строках. Переключатель: вкл / выкл.

Свойства виджета

Открой панель свойств, тапнув по CodeView в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — codeview1).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — codeview1, codeview2 и т. д. Переименуй в exampleCode, если это пример кода.
Пользовательские атрибуты Дополнительные XML-атрибуты. Здесь задаются язык, номера строк, цвета. Пары «атрибут = значение». Например, app:codeLanguage="java", app:showLineNumbers="true".
Конвертировать Показывает полный класс компонента: br.tiagohm.codeview.CodeView. CodeView и другие типы виджетов. Оставь как есть.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет окно кода по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent — стандарт для окна кода.
Высота
Height		 Насколько высоким будет окно кода по вертикали. match_parent, wrap_content, число в dp. wrap_content или фиксированная — например, 300dp.

Padding		 Отступ внутри виджета. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 8 со всех сторон. Для окна кода лучше 12.
Внешний отступ
Margin		 Отступ снаружи виджета. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin top 12 — отступ от предыдущего текста.
Гравитация макета
Layout gravity		 Как виджет выравнивается внутри родителя. none — по умолчанию;
например, center_horizontal.		 Обычно оставляют none.
Вес
Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 0 — стандарт.

Цвет фона

HEX или выбор из палитры.		 Тёмный фон — #1E1E1E.

Включено		 Можно ли взаимодействовать с виджетом. Переключатель: вкл — активен;
выкл — заблокирован.		 На скриншоте — включено.
Вращение
Rotation		 Поворот виджета вокруг центра. Градусы. 0 — без поворота. Обычно оставляют 0.
Прозрачность
Alpha		 Насколько виджет прозрачен. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.

ScaleY Масштаб по вертикали — растягивает или сжимает виджет по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: ключевые настройки (Language, ShowLineNumbers, WrapContent, TextSize) задаются через Пользовательские атрибуты — в виде app:codeLanguage="java", app:showLineNumbers="true". Сам текст кода задаётся в логике через setCode.

Как перетащить CodeView на макет

CodeView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V) или Scroll(V) с Linear(V).
  3. Раскрой категорию Библиотеки в палитре слева.
  4. Зажми CodeView и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — окно кода появится в разметке.
  6. В свойствах задай Ширину = match_parent, Высоту = wrap_content.
  7. Через Пользовательские атрибуты задай язык, показ номеров строк, цвет фона.
  8. Присвой осмысленный ID — он нужен для логики.
  9. Открой вкладку «События» и добавь в onCreate блок setCode или setText — задай текст кода.
  10. Если код должен меняться в зависимости от выбора пользователя — обновляй его в событии кнопки или списка.
⚠️ Важно: обычный тап по CodeView в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: CodeView не форматирует код. Если в тексте нет правильных отступов и переносов строк — он покажет как есть. Задавай текст с уже готовым форматированием.
⚠️ Важно: подсветка работает только при указании правильного языка. Если поставить Java, а показать HTML — синтаксис подсветится некорректно.
⚠️ Важно: CodeView увеличивает вес APK, так как тянет за собой движок подсветки. Если код в приложении — просто текст, используй обычный TextView с моноширинным шрифтом.
💡 Совет: задавай фон тёмного цвета (#1E1E1E или #282C34) и светлый текст — как в современных редакторах. Так код читается легче.
💡 Совет: для длинных фрагментов используй обёртку Scroll(V) вокруг CodeView. Иначе код обрежется по высоте.
💡 Совет: для копирования кода пользователем добавь отдельную кнопку «Копировать». CodeView позволяет выделять текст, но удобнее — одна кнопка.
💡 Совет: для примеров кода на несколько языков создавай отдельные CodeView для каждого языка и показывай нужный через setVisibility.
❌ Частая ошибка: использовать CodeView для обычного текста. Он весит больше TextView, а подсветка не нужна.
❌ Частая ошибка: задавать язык подсветки неправильно. Например, Java для Kotlin-кода — ключевые слова совпадут не полностью, подсветка будет странной.
❌ Частая ошибка: размещать CodeView без прокрутки. Длинный код обрежется, и пользователь не увидит остальное.

Резюме

  • CodeView — окно для отображения кода с подсветкой синтаксиса.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Текст кода задаётся в логике через setCode или setText.
  • Ключевые параметры (Language, ShowLineNumbers, цвета) задаются через Пользовательские атрибуты.
  • Подсветка работает только при правильном указании языка.
  • Для длинного кода оборачивай в Scroll(V).
  • Не используй CodeView для обычного текста — он тяжелее TextView.

Частые ошибки новичков

  • Тапают по CodeView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Не задают текст кода в логике. Виджет пустой.
  • Ищут Language и ShowLineNumbers в обычных свойствах. Через «Пользовательские атрибуты» — app:codeLanguage, app:showLineNumbers.
  • Оставляют неправильный язык подсветки. Синтаксис отображается странно.
  • Не оборачивают в Scroll(V) для длинного кода. Нижняя часть обрезается.
  • Используют CodeView для обычного текста. Лишний вес APK — достаточно TextView.
  • Не задают ID. Логика не может обратиться к виджету.
