Менеджер Java/Kotlin

Менеджер Java/Kotlin — раздел меню «Настройка», через который добавляются файлы кода на Java или Kotlin в проект. Позволяет расширить возможности Sketchware Pro 7 за счёт собственного кода.

Иконка в меню — кофейное зерно (символ Java).

Что можно делать

  • Добавлять готовые Java- или Kotlin-классы в проект.
  • Просматривать список добавленных файлов.
  • Удалять ненужные.
  • Использовать классы из логики через блоки.

Зачем это нужно

  • Доступ к функциям, которых нет в стандартных блоках Sketchware.
  • Подключение сторонних библиотек через готовый код.
  • Оптимизация сложных операций.
  • Расширение возможностей приложения.
  • Работа с API, где нужен собственный код.

Когда использовать

  • Нужна функция, которой нет в блоках Sketchware.
  • Подключаешь внешнюю библиотеку — её надо вписать в класс.
  • Нужен кастомный компонент, который не реализован в Sketchware.
  • Требуется точный контроль над кодом.

Для простых проектов этот раздел не нужен — все задачи решаются блоками.

Форматы

Формат Особенности
Java (.java) Классический язык Android.
Kotlin (.kt) Современный язык, рекомендован Google.

Как добавить

  1. Открой меню ⋮ → Менеджер Java/Kotlin.
  2. Нажми кнопку «+» или «Добавить».
  3. Выбери файл .java или .kt из памяти устройства.
  4. Укажи имя класса — оно должно совпадать с именем файла.
  5. Нажми «Сохранить» — файл появится в проекте.

Как использовать

  1. Добавь класс в Менеджер.
  2. В логике появятся новые блоки для работы с этим классом.
  3. Если блоков нет — потребуется ручное редактирование кода через Менеджер XML-команд.

Как удалить

  1. Открой Менеджер Java/Kotlin.
  2. Найди нужный файл.
  3. Используй контекстное меню → «Удалить».
  4. Подтверди удаление.
⚠️ Важно: класс должен быть корректным. Синтаксическая ошибка в Java-коде приведёт к тому, что проект не соберётся.
⚠️ Важно: имена файлов и классов должны совпадать. Файл MyClass.java должен содержать класс MyClass. Иначе — ошибка компиляции.
⚠️ Важно: не удаляй стандартные классы проекта. Они используются Sketchware для генерации кода.
⚠️ Важно: это раздел для продвинутых. Если ты не знаешь Java/Kotlin — не используй. Ошибки здесь ломают весь проект.
💡 Совет: используй этот раздел только когда нет альтернативы. 95% задач решаются стандартными блоками.
💡 Совет: если нужна функция из библиотеки — сначала проверь, есть ли для неё готовый компонент в Sketchware. Часто есть.
💡 Совет: для тестирования добавь класс в отдельный проект. Убедись, что он работает, потом переноси в основной.
💡 Совет: бери готовые классы из проверенных источников — GitHub, Stack Overflow. Не пиши Java-код с нуля, если не уверен.
💡 Совет: комментируй код — даже если это чужой класс. Так ты поймёшь, что он делает.
❌ Частая ошибка: добавлять классы без понимания. Ошибка в коде ломает сборку всего проекта.
❌ Частая ошибка: не совпадают имя файла и класса. Компилятор выдаёт ошибку.
❌ Частая ошибка: удалять стандартные классы. Приложение перестаёт собираться.
❌ Частая ошибка: использовать этот раздел для простых задач. Стандартные блоки справятся быстрее и без риска.
❌ Частая ошибка: пиратские классы из непроверенных источников. Возможны вирусы или неработающий код.

Резюме

  • Менеджер Java/Kotlin — раздел для добавления собственного кода в проект.
  • Поддерживает Java (.java) и Kotlin (.kt).
  • Используется для функций, которых нет в блоках Sketchware.
  • Требует понимания языка — иначе сломает проект.
  • Имена файлов и классов должны совпадать.
  • Не удаляй стандартные классы проекта.
  • Для 95% задач этот раздел не нужен — хватит стандартных блоков.
  • Тестируй классы в отдельном проекте перед переносом.

Частые ошибки новичков

  • Добавляют классы без понимания. Проект не собирается.
  • Имя файла ≠ имя класса. Ошибка компиляции.
  • Удаляют стандартные классы. Проект ломается.
  • Используют для простых задач. Избыточно и рискованно.
  • Берут код из непроверенных источников. Риск вирусов.
  • Не тестируют в отдельном проекте. Ломают рабочий проект.
  • Не комментируют код. Потом не могут разобраться.
