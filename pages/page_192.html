Проект 2. Кнопка + Toast

Второй проект — учимся реагировать на действия пользователя. Перетаскиваем на макет кнопку и показываем всплывающее сообщение при нажатии. Это первое приложение с логикой.

После этого проекта ты поймёшь:

  • как перетащить кнопку на макет;
  • как создать событие onClick;
  • как использовать блок Toast;
  • как связать виджет и логику.

Что будем делать

  • Создадим новый проект в Sketchware Pro 7.
  • Откроем редактор экрана и перетащим из палитры на макет виджет Button.
  • В панели свойств зададим текст кнопки и присвоим ей id — без id логика не заработает.
  • Создадим событие onClick для этой кнопки и перетащим на блочное полотно блок Toast.
  • Соберём APK, запустим и проверим, что при нажатии появляется всплывающее сообщение.

Перетаскивание Button на макет

  • Создай новый проект — как в предыдущем проекте.
    • Имя: Кнопка и Toast.
    • Пакет: com.example.buttontoast.
    • Проект: ButtonToast.
  • В Дизайнере найди категорию Widgets.
  • Зажми Button и перетащи его (drag & drop) на макет экрана.
  • Тапни по Button на макете — откроется панель свойств.
  • Измени Text на Нажми меня.
  • Присвой id — myButton. Это важно для логики.
Подсказка для новичка. Виджеты не «добавляются» и не «вставляются» — их именно перетаскивают из палитры на макет. Если кнопка не встаёт — удерживай палец и отпусти прямо над макетом.

💡 Совет: id виджета — обязателен. Без него виджет не появится в списке событий.

Событие onClick

  • Открой вкладку «События».
  • В левом меню выбери категорию View.
  • Нажми «+» внизу справа.
  • В открывшемся диалоге найди myButton.
  • Раскрой список событий для неё.
  • Отметь onClick галочкой.
  • Нажми «Добавить».

В центре экрана появится плитка onClick для myButton.

  • Тапни по стрелке > слева от onClick.
  • Откроется блочное полотно — здесь собираем логику.

Блок Toast

  • В палитре блоков найди категорию «Дополнительные» или View.
  • Найди блок Toast — всплывающее сообщение.
  • Перетащи его на полотно.
  • В поле блока впиши: Кнопка нажата!
  • Готово — логика описана.

Что получилось:

  • При нажатии на кнопку приложение покажет всплывающее сообщение Кнопка нажата! внизу экрана.
  • Сообщение исчезнет само через 2 секунды.

Запуск

  • Нажми «Сохранить» в шапке проекта.
  • Нажми «▶ Запустить» внизу.
  • Приложение установится и откроется.

Что ты увидишь:

  • Экран с кнопкой Нажми меня.
  • При нажатии — всплывающее сообщение Кнопка нажата!.
  • Сообщение исчезает через 2 секунды.

Если что-то не работает:

  • Проверь, что у кнопки задан id — myButton.
  • Проверь, что событие onClick добавлено.
  • Проверь, что в блоке Toast введён текст.
  • Открой Logcat — там указана причина.

Что можно улучшить

  • Считать нажатия — заведи переменную count и увеличивай её при каждом нажатии.
  • Показывать счётчик — Toast с текстом «Нажато N раз».
  • Перетащить вторую кнопку на макет — например, «Сбросить счётчик».
  • Изменить текст в TextView — вместо Toast использовать setText для другого виджета.

💡 Совет: попробуй заменить Toast на setText. Перетащи TextView на макет под кнопкой и в onClick меняй его текст. Так ты поймёшь разницу между всплывающим сообщением и изменением интерфейса.

⚠️ Важно: id виджета — критично для логики. Если забыл задать — вернись в Дизайнер, задай id, потом возвращайся к событиям.

⚠️ Важно: не путай onClick и onLongClick. Первое — обычное нажатие, второе — долгое. Для кнопки обычно нужен onClick.

Резюме

  • Создали новый проект ButtonToast.
  • Перетащили Button из палитры на макет и задали ей id myButton.
  • Создали событие onClick и перетащили на полотно блок Toast.
  • Собрали и запустили APK — при нажатии появляется сообщение.

Частые ошибки новичков

  • Не задан id виджета. Без id кнопка не появится в списке событий — логику не создать.
  • Путают onClick и onLongClick. onClick — обычное нажатие, onLongClick — удержание пальца.
  • Пустое поле в блоке Toast. Если текст не введён, сообщение будет пустым — проверь поле.
  • Забыли сохранить проект. Перед запуском всегда нажимай «Сохранить».
  • Игнорирование Logcat. Если Toast не появляется — открой Logcat, там прямая причина.
