MultiAutoCompleteTextView — несколько автоподсказок

MultiAutoCompleteTextView — расширенная версия AutoCompleteTextView, которая поддерживает несколько значений в одном поле. Пользователь вводит первое слово, выбирает из подсказок, ставит разделитель — и продолжает вводить следующее.

Иконка в палитре — поле с двумя вертикальными метками и выпадающим списком.

Как работает

  • Пользователь вводит текст — появляется выпадающий список подсказок, как у обычного AutoCompleteTextView.
  • После выбора или ввода значения пользователь ставит разделитель (обычно запятую).
  • Начинает вводить следующее значение — снова появляются подсказки.
  • В поле накапливается список значений через запятую: Москва, Казань, Сочи.
  • Каждое значение можно удалить вручную, стерев его.

Когда использовать

  • Ввод тегов — несколько меток в одном поле.
  • Список получателей — email-адреса через запятую.
  • Множественный выбор городов — когда нужно несколько вариантов.
  • Категории и ключевые слова — например, теги статьи.

По сути — «поле ввода тегов», как в блогах или на сайтах.

Из чего состоит

  • MultiAutoCompleteTextView — само поле.
  • Список подсказок — задаётся в логике.
  • Токенайзер (Tokenizer) — определяет, какой символ считать разделителем между значениями. Обычно запятая.
  • Выпадающий список — появляется при вводе каждого нового значения.

Основные свойства

  • Hint — подсказка внутри поля.
  • Text — начальные значения.
  • InputType — тип ввода.
  • TextColor / TextSize — цвет и размер текста.
  • Threshold — минимальное число символов для старта автодополнения.
  • DropDownWidth / DropDownBackground — параметры выпадающего списка.
  • Width / Height — match_parent или wrap_content.
  • MaxLines / MinLines — ограничения по высоте (обычно многострочный).

Как добавить

  • Выбери контейнер, в который хочешь положить поле.
  • Тап по MultiAutoCompleteTextView в палитре — виджет добавится внутрь.
  • Задай Hint и Threshold в свойствах.
  • Присвой виджету id для работы в логике.
  • Открой вкладку «События» и добавь:
    • блок setSimpleItems — список подсказок;
    • блок setTokenizer — разделитель (запятая, пробел и т.д.).

⚠️ Важно: без настройки Tokenizer в логике поле будет вести себя как обычное AutoCompleteTextView — без учёта разделителей. Вводить несколько значений не получится.

⚠️ Важно: список подсказок задаётся в логике, а не в свойствах виджета. В Дизайнере ты настраиваешь только внешний вид.

💡 Совет: в качестве разделителя используй запятую с пробелом — это самый привычный формат для пользователей. Тогда ввод будет выглядеть аккуратно: Москва, Казань, Сочи.

💡 Совет: не ставь слишком много подсказок — поле ввода тегов с автодополнением удобно, только если вариантов не десятки тысяч. Для больших списков используй другой подход.

💡 Совет: показывай пользователю уже введённые значения — они видны в поле через запятую. Это позволяет легко удалить лишнее.

❌ Частая ошибка: путать AutoCompleteTextView и MultiAutoCompleteTextView. Первый — для одного значения, второй — для нескольких через разделитель.

❌ Частая ошибка: забыть указать Tokenizer. Без него подсказки появляются только для первого слова, а после запятой — нет.
