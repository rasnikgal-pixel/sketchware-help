Intent — переходы между экранами

Intent — компонент для перехода между экранами. Открывает новую Activity, передаёт данные и возвращает результат. Это основной инструмент навигации в приложении.

Иконка в диалоге добавления — стрелка с узлом.

Как работает

  • Открывает новый экран приложения или другого приложения.
  • Может передавать данные: строки, числа, флаги.
  • Может ожидать результата — например, после выбора файла или фото.
  • Может запускать системные действия: позвонить, открыть браузер, отправить письмо.
  • Существует в двух вариантах: явный (конкретный экран) и неявный (действие, которое выберет система).

Когда использовать

  • Переход между экранами — из главного меню в настройки.
  • Открытие деталей — тап по элементу списка, открытие подробной информации.
  • Передача данных — имя пользователя, выбранный товар, ID записи.
  • Возврат с результатом — после выбора фото, файла, контакта.
  • Системные действия — звонок, браузер, email, карта.

Основные настройки при добавлении

  • Имя компонента — идентификатор для вызова в логике. Например, goToSettings.
  • Целевое Activity — экран, который откроется (при явном Intent).

Основные блоки в логике

  • startActivity — запустить новый экран.
  • startActivityForResult — запустить экран и ожидать результат.
  • putExtra — передать данные вместе с Intent.
  • getExtra — получить данные из Intent (в новой Activity).
  • setAction — задать действие (для неявного Intent).
  • setData — задать данные (URL, телефон, координаты).
  • finish — закрыть текущий экран.

Как использовать

  • Подключи компонент Intent на вкладке «Компонент».
  • Задай ему имя — например, goToSecond.
  • В логике найди блоки Intent в палитре.
  • Для перехода: вызови startActivity с указанием, куда идти.
  • Для передачи данных: перед startActivity используй putExtra с ключом и значением.
  • Для получения данных в новой Activity: используй getExtra в её onCreate.

⚠️ Важно: новая Activity должна существовать в проекте. Добавь её через Менеджер представлений, иначе Intent не сработает.

⚠️ Важно: ключи данных должны совпадать при передаче и чтении. Если в putExtra ключ user_name, а в getExtra — username, данные не найдутся.

⚠️ Важно: getExtra возвращает значение по умолчанию, если данные не переданы. Задавай понятное значение по умолчанию — например, пустую строку или 0.

⚠️ Важно: после startActivity текущий экран остаётся в стеке. Если не хочешь возвращаться назад — используй finish после запуска.

💡 Совет: для передачи сложных данных (например, всего объекта) используй SharedPreferences или сохраняй в базу данных, а через Intent передавай только ID.

💡 Совет: для системных действий (звонок, браузер) используй неявный Intent с setAction. Например, Intent.ACTION_DIAL с номером телефона.

💡 Совет: не передавай через Intent большие объёмы данных (например, картинки). Есть ограничение на размер — приложение может упасть.

💡 Совет: для возврата результата используй startActivityForResult, а в вызываемой Activity — блок setResult перед finish.

❌ Частая ошибка: открывать Activity, которой нет в проекте. Intent не сработает, а ошибка не всегда видна.

❌ Частая ошибка: не совпадают ключи при передаче и чтении. Данные «теряются», хотя код выполняется.

❌ Частая ошибка: передавать большие данные через Intent. Приложение падает с ошибкой TransactionTooLargeException.

❌ Частая ошибка: забыть про finish, если не хочешь возвращаться назад. Пользователь нажимает «Назад» и попадает на предыдущий экран.
