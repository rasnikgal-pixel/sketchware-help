Показать исходный код

Показать исходный код — раздел меню «Настройка», который открывает сгенерированный код проекта: Java-файлы и XML-разметку. Здесь видно, во что Sketchware превращает блочную логику и визуальный дизайн.

Иконка в меню — символы < > или окно с кодом.

Что можно посмотреть

  • Java-файлы — код логики: MainActivity.java и другие.
  • XML-файлы — разметка экранов: main.xml и другие.
  • AndroidManifest.xml — главный файл конфигурации.
  • styles.xml / colors.xml — тема и цвета.
  • strings.xml — строки приложения.
  • Любые другие сгенерированные файлы проекта.

Зачем это нужно

  • Понять, как работает блочная логика — увидеть код, который генерирует Sketchware.
  • Проверить ошибки — иногда видно, где именно проблема.
  • Изучить примеры — как реализованы стандартные блоки.
  • Скопировать фрагменты — перенести код в другой проект.
  • Найти неэффективность — увидеть, где логика работает не оптимально.
  • Разобраться в структуре — как устроено приложение.

Как открыть

  • Открой меню ⋮ → Показать исходный код.
  • Откроется список файлов проекта, сгруппированных по категориям.
  • Тапни по нужному файлу — содержимое откроется в просмотрщике.
  • Код отображается с подсветкой синтаксиса (если доступно).
  • Копируй нужные фрагменты через длинное нажатие и «Копировать».

Что важно понимать

  • Код генерируется автоматически — он не написан человеком, а создан Sketchware по блокам.
  • Код перезаписывается при каждой сборке. Изменения здесь не сохраняются.
  • Нельзя редактировать код через этот раздел. Он только для просмотра.
  • Код не всегда оптимален — Sketchware генерирует стандартные шаблоны, иногда избыточные.
  • Имена классов и методов могут быть неочевидными. Например, _OnClick_Button1 — это onClick для кнопки button1.

Пример: понять блок setText

Если ты добавил блок setText для TextView, в сгенерированном коде это будет:

textView1.setText("Привет");

Полезно для понимания, что делает блок.

Пример: понять логику if

Блок if (условие) { действие } генерирует:

if (условие) {
    действие;
}

Всё как в стандартном Java.

⚠️ Важно: не пытайся редактировать код через этот раздел. Изменения не сохраняются — всё перезапишется при следующей сборке.

⚠️ Важно: код не всегда читаемый. Имена переменных вида _var1, _var2 — это автоматически созданные имена.

⚠️ Важно: не всё в коде очевидно. Некоторые вещи генерируются Sketchware внутренне и не видны в блоках.

⚠️ Важно: не изучай код как учебник Java. Это сгенерированный код, не всегда оптимальный и не всегда образцовый.
