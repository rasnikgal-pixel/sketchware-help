SignInButton — вход через Google

SignInButton — кнопка входа через аккаунт Google. Пользователь тапает — и входит в приложение, используя свою учётную запись Google, без ввода пароля и регистрации.

Иконка в палитре — кнопка с логотипом Google и надписью.

Как работает

  • Отображает фирменную кнопку с логотипом Google и надписью «Войти через Google».
  • При тапе — открывается диалог выбора аккаунта Google, сохранённого на устройстве.
  • Пользователь выбирает аккаунт — приложение получает токен авторизации.
  • Через токен можно получить имя, email, фото профиля и другие данные.
  • Если у пользователя нет аккаунта Google на устройстве — откроется экран входа в Google.

Когда использовать

  • Быстрая регистрация — не заставлять вводить email и пароль.
  • Авторизация в приложении — вместо собственной формы входа.
  • Персонализация — получить имя и фото профиля.
  • Синхронизация данных — привязать данные к аккаунту.
  • Облачное хранение — сохранять данные в Google Drive или Firebase.
  • Социальные функции — привязка к аккаунту для отзывов и комментариев.

Настройки

Light — светлая;
Colorful — яркая.

Margin / Padding Отступы. Число в dp.

Основные

Свойство (рус / англ) Что делает Значения Пример

Конвертировать Показывает полный класс компонента: com.google.android.gms.common.SignInButton. SignInButton и другие типы виджетов. Оставь как есть.

Как перетащить SignInButton на макет

SignInButton, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Зарегистрируйся в Google Cloud Console.
  2. Настрой OAuth 2.0 — тип «Android». Укажи имя пакета приложения и SHA-1 сертификата подписи.
  3. Получи Client ID для OAuth.
  4. В Sketchware Pro 7 подключи библиотеку Google Sign-In через Менеджер библиотек.
  5. Открой вкладку «Дизайнер». Убедись, что на макете уже есть контейнер — Linear(V) или RelativeLayout.
  6. Раскрой категорию Google в палитре слева.
  7. Зажми SignInButton и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  8. Отпусти в нужном месте — кнопка появится в разметке.
  9. Через Пользовательские атрибуты задай app:buttonSize, app:colorScheme, app:signInText.
  10. Присвой осмысленный ID — он нужен для логики.
  11. Открой вкладку «События» — добавь событие onClick для кнопки.
  12. Внутри onClick вызови блок signIn — запрос на вход.
  13. Добавь события onSignInSuccess и onSignInFailed — реакцию на результат.
⚠️ Важно: обычный тап по SignInButton в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: без настройки OAuth в Google Cloud кнопка не работает. Нужно зарегистрировать приложение, указать пакет и SHA-1 отпечаток.
⚠️ Важно: SHA-1 отпечаток берётся из сертификата, которым подписано приложение. Для тестовой сборки — один отпечаток, для релиза (Google Play) — другой. Оба нужно добавить в консоль.
⚠️ Важно: без google-services.json файла (для Firebase Auth) или правильной настройки OAuth вход не сработает. Ошибки часто скрыты в логах.
💡 Совет: для простых приложений используй SignInButton в паре с Firebase Auth. Firebase возьмёт на себя большую часть работы — легче, чем чистая настройка OAuth.
💡 Совет: после успешного входа сохраняй данные пользователя в SharedPreferences — чтобы не запрашивать вход при каждом запуске.
💡 Совет: задавай ButtonSize = Wide, если кнопка в форме — она растянется на всю ширину. Для небольших экранов — Standard.
💡 Совет: используй ColorScheme = Dark для тёмной темы приложения. Light — для светлой. Colorful — для ярких приложений.
💡 Совет: предусмотри выход из аккаунта — добавь кнопку «Выйти» в настройках профиля. Пользователь должен иметь возможность сменить аккаунт.
❌ Частая ошибка: не указать SHA-1 отпечаток при настройке OAuth. Кнопка нажимается, но вход не срабатывает.
❌ Частая ошибка: использовать debug-версию SHA-1 для релизного APK. При публикации в Google Play нужен release-отпечаток.
❌ Частая ошибка: не обрабатывать onSignInFailed. Пользователь тапает, ничего не происходит, ошибки не видно.
❌ Частая ошибка: не показывать имя пользователя после входа. Пользователь не понимает, что вошёл успешно.
❌ Частая ошибка: забыть про кнопку «Выйти». Пользователь не может сменить аккаунт.

Резюме

  • SignInButton — фирменная кнопка входа через аккаунт Google.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Требует настройки OAuth 2.0 в Google Cloud Console с указанием пакета и SHA-1.
  • Нужна библиотека Google Sign-In (или Firebase Auth) через Менеджер библиотек.
  • Ключевые параметры (ButtonSize, ColorScheme, Text) задаются через Пользовательские атрибуты.
  • Реакция на тап и сам вход — через логику (onClick, signIn, onSignInSuccess).
  • Debug и release версии приложения требуют разные SHA-1 в консоли.
  • Обязательно предусмотри кнопку «Выйти» и обработку ошибок входа.

Частые ошибки новичков

  • Тапают по SignInButton в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Не настраивают OAuth. Кнопка нажимается, но вход не работает.
  • Не указывают SHA-1. Вход отклоняется, ошибка в логах.
  • Используют debug SHA-1 для релизной сборки. Вход не работает у пользователей из Google Play.
  • Не обрабатывают onSignInFailed. Пользователь не понимает, что произошло.
  • Забывают кнопку «Выйти». Пользователь не может сменить аккаунт.
  • Ищут ButtonSize и ColorScheme в обычных свойствах. Через «Пользовательские атрибуты».
  • Не задают ID. Логика не может подключиться к кнопке.
