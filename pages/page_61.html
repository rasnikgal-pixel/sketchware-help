TextInputLayout — красивое поле ввода

TextInputLayout — современное поле ввода с плавающей меткой. Внутри него размещается обычный EditText, но снаружи добавляется подпись, которая ведёт себя особым образом: пока поле пустое — подпись стоит внутри, как placeholder; как только пользователь начинает вводить — подпись плавно поднимается вверх и остаётся над полем.

Иконка в палитре — прямоугольник с текстом и подчёркиванием.

Как работает

  • TextInputLayout — внешняя обёртка.
  • EditText внутри — само поле для ввода.
  • Hint (подпись) — задаётся у TextInputLayout через свойство Hint. Пока поле пустое, она отображается внутри на месте текста. При вводе — поднимается вверх.
  • Поле имеет подчёркивание снизу — цвет зависит от состояния: обычное, в фокусе, с ошибкой.
  • Можно задать вспомогательный текст под полем и сообщение об ошибке.

Когда использовать

  • Формы входа и регистрации — email, пароль, имя.
  • Анкеты и опросы — поля с чёткими подписями.
  • Настройки профиля — имя, телефон, адрес.
  • Любые формы, где важно, чтобы пользователь понимал, что вводит.

TextInputLayout — стандарт для современных Android-приложений. Обычный EditText без обёртки выглядит устаревшим.

Из чего состоит

  • TextInputLayout — контейнер.
  • EditText — поле ввода внутри.
  • Hint — текст-подпись.
  • HelperText — подсказка под полем.
  • ErrorText — сообщение об ошибке (красным).

Настройки

Настройка Что делает Значения
Hint Текст подписи поля. Любая строка.
HintTextColor Цвет подписи в обычном состоянии. HEX или выбор из палитры.
HintTextAppearance Стиль подписи. Ссылка на стиль.
BoxBackgroundMode Режим фона поля. filled — залитый;
outline — с рамкой;
none — только подчёркивание.
BoxStrokeColor Цвет обводки или подчёркивания. HEX или выбор из палитры.
BoxCornerRadiusTopStart / TopEnd / BottomStart / BottomEnd Радиус скругления углов рамки. Число в dp.
ErrorEnabled Включать/выключать режим ошибки. Переключатель: вкл / выкл.
CounterEnabled Счётчик символов справа снизу. Переключатель: вкл / выкл.
PasswordToggleEnabled Иконка «глаза» для показа пароля. Переключатель: вкл / выкл.
Width / Height Ширина и высота компонента. По умолчанию match_parent по ширине и wrap_content по высоте.

Основные

Свойство (рус / англ) Что делает Значения Пример

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет поле ввода по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent — стандарт для формы.
Высота
Height		 Насколько высоким будет поле по вертикали. match_parent, wrap_content, число в dp. wrap_content — высота подстроится под содержимое.
Внутренний отступ
Padding		 Отступ внутри компонента — от краёв до содержимого. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 0 со всех сторон. Обычно padding задаётся у самого EditText.
Внешний отступ
Margin		 Отступ снаружи компонента — от него до соседних элементов и краёв родителя. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin bottom 16 — между полями формы.

Layout gravity		 Как компонент выравнивается внутри родителя. none — по умолчанию;
например, center_horizontal.		 Обычно оставляют none.
Вес
Weight		 Доля свободного места родителя, которую займёт компонент. Работает только внутри родителя с весом. Число. 0 — вес не задан. 0 — стандарт.

💡 Совет для новичков: большинство ключевых настроек (BoxBackgroundMode, BoxStrokeColor, BoxCornerRadius*, PasswordToggleEnabled) задаются через Пользовательские атрибуты — их нужно вручную прописать в виде app:boxBackgroundMode="outline", app:passwordToggleEnabled="true" и так далее. Готовый стиль можно задать через атрибут style — как на скриншоте.

Как перетащить TextInputLayout на макет

TextInputLayout, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Раскрой категорию AndroidX в палитре слева.
  3. Зажми TextInputLayout и, не отпуская, перетащи его на макет (обычно внутрь Linear(V) формы).
  4. Отпусти в нужном месте — обёртка появится в разметке.
  5. Перетащи внутрь TextInputLayout виджет EditText — без него поле не будет работать.
  6. В свойствах TextInputLayout задай Hint — это подпись поля.
  7. Через Пользовательские атрибуты задай стиль (style), app:boxBackgroundMode, app:boxCornerRadius*, app:passwordToggleEnabled и другие параметры.
  8. В свойствах EditText настрой InputType: текст, число, email, пароль.
⚠️ Важно: обычный тап по TextInputLayout в палитре ничего не делает. Компонент попадает на макет только перетаскиванием.
⚠️ Важно: TextInputLayout без EditText внутри — пустая обёртка, которая ничего не отображает. Это частая причина «пропавшего» поля.
⚠️ Важно: при использовании BoxBackgroundMode = outline (рамка) не задавай Hint у EditText — только у TextInputLayout. Иначе появится два текста подписи одновременно.
💡 Совет: для форм с несколькими полями используй BoxBackgroundMode = outline и задай радиус скругления 8dp — выглядит современно и аккуратно.
💡 Совет: для пароля всегда включай PasswordToggleEnabled — пользователь может проверить, что ввёл, не стирая весь текст.
❌ Частая ошибка: задавать Hint одновременно и у TextInputLayout, и у EditText. Подпись дублируется или ведёт себя непредсказуемо.

Резюме

  • TextInputLayout — современная обёртка для EditText с плавающей подписью.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Внутрь обязательно перетаскивается EditText — без него поле не работает.
  • Hint задаётся у TextInputLayout, а не у EditText.
  • Ключевые параметры вида (стиль рамки, радиус, иконка пароля) задаются через Пользовательские атрибуты или через атрибут style.
  • InputType поля (текст, число, email, пароль) задаётся у вложенного EditText.

Частые ошибки новичков

  • Тапают по TextInputLayout в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетаскивают TextInputLayout без EditText. Пустая обёртка, поле не отображается.
  • Задают Hint одновременно у TextInputLayout и EditText. Подпись дублируется.
  • Ищут PasswordToggleEnabled, BoxBackgroundMode и BoxCornerRadius в обычных свойствах. Их нужно задавать через «Пользовательские атрибуты» или через style.
  • Не указывают InputType у EditText. Поле работает как обычный текст, не пропускает цифры, email или пароль.
  • Забывают про Material-библиотеку. Без неё TextInputLayout не отобразится или отобразится без стиля.
  • Используют TextInputLayout без надобности. Если нужен просто EditText без подписи — обёртка не нужна.
