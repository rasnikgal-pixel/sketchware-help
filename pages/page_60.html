CardView — карточка

CardView — карточка с закруглёнными углами и тенью. Контейнер, который визуально выделяет группу связанных элементов на фоне остального экрана. Классический элемент Material Design, используется почти во всех современных приложениях.

Иконка в палитре — прямоугольник с закруглёнными углами.

Как работает

  • CardView — это контейнер, внутри которого размещаются другие виджеты.
  • По умолчанию имеет скруглённые углы и тень (elevation), которая отделяет карточку от фона.
  • Может быть плоским (без тени) или объёмным (с глубокой тенью).
  • Внутри карточки обычно размещают Linear(V) с содержимым: картинка, заголовок, описание, кнопка.

Когда использовать

  • Списки новостей — каждая новость отдельной карточкой.
  • Карточки товаров — фото, название, цена, кнопка «Купить».
  • Профили пользователей — аватар, имя, описание.
  • Настройки — каждый пункт или группа пунктов в отдельной карточке.
  • Дашборды — статистика, графики, метрики, каждая в своей карточке.

Это самый популярный контейнер для визуальной группировки в Android.

Настройки

Настройка Что делает Значения
CardBackgroundColor Цвет фона карточки. HEX или выбор из палитры.
CardCornerRadius Радиус скругления углов. Число в dp. Чем больше — тем круглее. На скриншоте — 2dp.
CardElevation Высота тени. Число в dp. 0dp — без тени;
4–8dp — стандарт;
16dp+ — сильный объём. На скриншоте — 2dp.
ContentPadding Внутренние отступы содержимого от краёв карточки. Число в dp для каждой стороны.
CardUseCompatPadding Учитывать ли padding на разных версиях Android. Переключатель: вкл / выкл.
CardPreventCornerOverlap Предотвращать наложение содержимого на скругления. Переключатель: вкл / выкл.
Width / Height Ширина и высота карточки. match_parent или wrap_content.
Margin Внешние отступы между карточками. Число в dp.

Свойства контейнера

Открой панель свойств, тапнув по CardView в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — cardview1).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя компонента. По этому имени он виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — cardview1, cardview2 и т. д. Переименуй в newsCard, если это карточка новости.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Здесь задаются ключевые параметры карточки. Пары «атрибут = значение». На скриншоте заданы app:cardElevation="2dp" и app:cardCornerRadius="2dp".
Конвертировать Показывает полный класс компонента: androidx.cardview.widget.CardView. CardView (AndroidX) и другие. Обычно менять не нужно.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широкой будет карточка по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent — для карточки-баннера;
wrap_content — для карточки-плитки.
Высота
Height		 Насколько высокой будет карточка по вертикали. match_parent, wrap_content, число в dp. wrap_content — стандарт для карточки в списке.
Внутренний отступ
Padding		 Отступ внутри карточки — от её краёв до содержимого. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 8 со всех сторон. Классика — 12–16 dp.
Внешний отступ
Margin		 Отступ снаружи карточки — от неё до соседних элементов и краёв родителя. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin 8 со всех сторон — карточки не липнут друг к другу.
Гравитация макета
Layout gravity		 Как карточка выравнивается внутри родителя. none — по умолчанию;
например, center_horizontal, right.		 center_horizontal — карточка по центру.
Вес
Weight		 Доля свободного места родителя, которую займёт карточка. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — карточка заберёт всё оставшееся место.

Свойства изображения

Свойство (рус / англ) Что делает Значения Пример
Ресурс фона
Background resource		 Картинка-фон карточки из ресурсов проекта. NONE — без фона;
любой drawable-ресурс.		 Обычно оставляют NONE, а фон задают через CardBackgroundColor в пользовательских атрибутах.
Цвет фона
Background color		 Заливка карточки сплошным цветом. NONE — без цвета;
HEX или выбор из палитры.		 Белый фон карточки — #FFFFFF. Для Material Design часто задают через app:cardBackgroundColor.
Enabled
Включено		 Реагирует ли карточка на нажатия (событие onClick). Переключатель: вкл — активно;
выкл — заблокировано.		 На скриншоте — включено.
Вращение
Rotation		 Поворот карточки вокруг центра. Градусы. 0 — без поворота. Обычно оставляют 0.
Прозрачность
Alpha		 Насколько карточка прозрачна. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.
TranslationX Сдвиг карточки по горизонтали без изменения её места в разметке. Число в dp. 0.0 — без сдвига. 20.0 — визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг карточки по вертикали без изменения её места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.
ScaleX Масштаб по горизонтали — растягивает или сжимает карточку по ширине. Число. 1.0 — исходный размер. 1.5 — ширина увеличится в 1,5 раза.
ScaleY Масштаб по вертикали — растягивает или сжимает карточку по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: ключевые параметры карточки (CardCornerRadius, CardElevation, CardBackgroundColor) задаются через Пользовательские атрибуты — их нужно вручную прописать в виде app:cardCornerRadius="12dp", app:cardElevation="4dp", app:cardBackgroundColor="#FFFFFF".

Как перетащить CardView на макет

CardView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Раскрой категорию AndroidX в палитре слева.
  3. Зажми CardView и, не отпуская, перетащи его на макет (обычно внутрь Linear(V) или внутрь Scroll(V) → Linear(V)).
  4. Отпусти в нужном месте — карточка появится в разметке.
  5. В свойствах задай базовые параметры: Ширина, Высота, Внутренний отступ, Внешний отступ.
  6. Через Пользовательские атрибуты задай app:cardCornerRadius, app:cardElevation, app:cardBackgroundColor.
  7. Внутрь карточки перетащи Linear(V), а в него — содержимое: ImageView, TextView, Button.
⚠️ Важно: обычный тап по CardView в палитре ничего не делает. Карточка попадает на макет только перетаскиванием.
⚠️ Важно: CardView не подстраивает размер под содержимое автоматически, если задан match_parent. Проверь Высоту — для карточки в списке обычно wrap_content.
⚠️ Важно: если задаёшь CardCornerRadius, содержимое карточки может «вылезать» за скруглённые углы — картинка, например. Используй CardPreventCornerOverlap = true или задавай внутренние отступы через ContentPadding.
💡 Совет: классическая карточка для списка: CardCornerRadius = 12dp, CardElevation = 4dp, ContentPadding = 12dp, Margin = 8dp. Такой набор выглядит аккуратно и нейтрально.
💡 Совет: не ставь слишком глубокую тень (CardElevation больше 12dp) — на тёмных темах она выглядит грязно, а на светлых создаёт эффект «парящих» карточек.
❌ Частая ошибка: перетаскивать содержимое прямо в CardView, без промежуточного Linear(V). Может сработать, но вложенная структура упрощает управление отступами и выравниванием.

Резюме

  • CardView — карточка с закруглёнными углами и тенью, классический контейнер Material Design.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Ключевые параметры (cardCornerRadius, cardElevation, cardBackgroundColor) задаются через Пользовательские атрибуты.
  • Внутрь карточки обычно перетаскивают Linear(V), а в него — содержимое.
  • Стандарт для карточки в списке: radius 12dp, elevation 4dp, padding 12dp, margin 8dp.
  • Не ставь глубокую тень без необходимости — она портит внешний вид.

Частые ошибки новичков

  • Тапают по CardView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Ищут настройки CardCornerRadius и CardElevation в обычных свойствах. Их нужно задавать через «Пользовательские атрибуты».
  • Оставляют Высоту = match_parent. Карточка растянется на весь экран и перестанет быть «карточкой».
  • Не задают Margin. Карточки в списке слипаются друг с другом.
  • Ставят большую CardElevation. Тени выглядят грязно, особенно на тёмной теме.
  • Кладут содержимое прямо в CardView без Linear(V). Усложняет управление отступами и выравниванием.
  • Забывают, что картинка внутри карточки может вылезать за скруглённые углы. Нужно включать CardPreventCornerOverlap.
