SeekBar — ползунок

SeekBar — ползунок для выбора значения из диапазона. Пользователь тянет ползунок влево или вправо, задавая число в определённых пределах.

Иконка в палитре — горизонтальная линия с круглым ползунком.

Как работает

  • Представляет диапазон значений — обычно от 0 до 100, но можно задать любой.
  • Пользователь тянет ползунок — значение меняется.
  • Текущее значение можно прочитать в логике через блок getProgress.
  • При движении ползунка срабатывает событие onProgressChanged — можно реагировать в реальном времени.
  • При отпускании ползунка срабатывает onStopTrackingTouch — удобно для сохранения значения.

Когда использовать

  • Громкость — регулятор звука.
  • Яркость — настройка экрана.
  • Размер шрифта — выбор из диапазона.
  • Рейтинг — оценка от 1 до 10.
  • Фильтр цены — выбор максимальной цены.
  • Прогресс воспроизведения — позиция в аудио или видео.
  • Любое числовое значение с диапазоном.

Основные свойства

  • Progress — текущее значение.
  • Max — максимальное значение. По умолчанию 100.
  • Min — минимальное значение (обычно 0).
  • ProgressTint — цвет пройденной части полосы.
  • ProgressBackgroundTint — цвет оставшейся части.
  • ThumbTint — цвет круглого ползунка.
  • Padding / Margin — внутренние и внешние отступы.
  • Width / Height — match_parent по ширине, wrap_content по высоте.

Как добавить

  • Выбери контейнер, куда хочешь положить ползунок.
  • Тап по SeekBar в палитре — виджет добавится внутрь.
  • Задай Max — например, 100.
  • Задай Progress — стартовое значение (обычно 0 или 50).
  • Присвой id — для работы в логике.
  • Открой вкладку «События» — добавь событие onProgressChanged (реакция в реальном времени) или onStopTrackingTouch (реакция при отпускании).

⚠️ Важно: без onProgressChanged ползунок двигается визуально, но ничего не делает. Логику нужно описывать вручную.

⚠️ Важно: Max нельзя задать меньше Progress. Если Progress = 50, а Max = 10 — значение обрежется до 10. Проверяй порядок настройки.

💡 Совет: показывай текущее значение рядом с ползунком через TextView. Пользователь не понимает, что значит «ползунок на 60%» — добавь «60%» или «60 из 100».

💡 Совет: для выбора громкости или яркости используй Progress = 50, Max = 100 — нейтральный старт. Пользователь сам решит, в какую сторону двигать.

💡 Совет: для действий, которые тяжело выполнять в реальном времени (например, отправка запроса на сервер), используй onStopTrackingTouch, а не onProgressChanged. Событие onProgressChanged срабатывает десятки раз в секунду при движении — сервер не выдержит.

❌ Частая ошибка: пытаться получить значение сразу при запуске экрана. Событие onProgressChanged не сработает, пока пользователь не тронет ползунок. Для начального значения читай свойство Progress в onCreate.

❌ Частая ошибка: забывать, что Max — это максимальное значение, а не количество шагов. Для диапазона от 0 до 5 ставь Max = 5, а не Max = 6.
