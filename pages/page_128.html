Calendar — работа с датами

Calendar — компонент для работы с датой и временем. Позволяет получать текущую дату, форматировать её, складывать и вычитать дни, месяцы, годы, конвертировать между форматами.

Иконка в диалоге добавления — календарь с числами.

Как работает

  • Даёт доступ к текущей дате и времени устройства.
  • Позволяет устанавливать конкретную дату вручную.
  • Поддерживает арифметику дат: прибавить день, отнять месяц, добавить год.
  • Форматирует дату и время в строку любого вида: 29.09.2026, Sep 29, 2026, 17:35.
  • Конвертирует между миллисекундами и компонентами даты (год, месяц, день).
  • Может сравнивать две даты: раньше, позже, равно.

Когда использовать

  • Отображение текущей даты — «Сегодня 29 сентября».
  • Форматирование — запись даты в журнал, документ.
  • Напоминания — вычисление момента срабатывания.
  • Расчёт возраста — разница между датами.
  • Сроки годности — когда истекает что-то.
  • Периоды — с какой по какую дату.
  • Работа с CalendarView и DatePicker — конвертация миллисекунд в понятную дату.

Настройки при добавлении

Настройка Что задаёт Пример
Имя компонента Идентификатор для вызова в логике. calendar, myCalendar.

Основные блоки в логике

Блок Что делает
Calendar.getInstance() Получить текущую дату.
setTimeInMillis Установить дату из миллисекунд.
getTimeInMillis Получить дату в миллисекундах.
get Получить компонент: год, месяц, день, час, минуту.
set Установить конкретное значение.
add Прибавить или отнять: день, месяц, год, час.
format Отформатировать дату в строку.
SimpleDateFormat Задать шаблон форматирования.
after / before Сравнить две даты.
compareTo Сравнить и получить число.

Форматы даты

Шаблон Пример результата Когда использовать
dd.MM.yyyy 29.09.2026 Отображение пользователю в России.
yyyy-MM-dd 2026-09-29 ISO-формат. Удобно для сортировки и API.
dd MMMM yyyy 29 сентября 2026 Читаемая дата в тексте.
HH:mm 17:35 24-часовой формат.
hh:mm a 05:35 PM 12-часовой формат (US).

Где: dd — день, MM — месяц, yyyy — год, HH — часы, mm — минуты, ss — секунды.

Как использовать

  1. Подключи компонент Calendar на вкладке «Компонент».
  2. Задай ему имя — например, calendar.
  3. В логике используй блоки:
    • Calendar.getInstance() — получи текущую дату.
    • format с шаблоном — получи строку даты.
    • add — отнимай или прибавляй дни, месяцы, годы.
    • getTimeInMillis — получи число для передачи в другие блоки.

Пример: показать текущую дату

  • В onCreate — вызови Calendar.getInstance().
  • Через format с шаблоном dd.MM.yyyy — получи строку.
  • Установи её в TextView через setText.

Пример: «Через 7 дней»

  • Возьми текущую дату через getInstance.
  • Через add(DAY_OF_MONTH, 7) прибавь 7 дней.
  • Отформатируй в строку.
  • Покажи пользователю: «Напоминание через 7 дней: 06.10.2026».
⚠️ Важно: месяцы нумеруются с 0. Январь — 0, декабрь — 11. Частая причина сдвигов даты на месяц.
⚠️ Важно: год указывается полностью: 2026, а не 26. Если ошибиться — получишь неверную дату.
⚠️ Важно: даты хранятся в миллисекундах от 1 января 1970 года. Это внутренний формат Android. При работе с другими компонентами (DatePicker, CalendarView) используй getTimeInMillis для конвертации.
⚠️ Важно: форматирование даты — задача локали. Если пользователь в другой стране, формат может отличаться. Для хранения используй ISO (yyyy-MM-dd), для отображения — локальный.
💡 Совет: для сортировки дат храни их в формате yyyy-MM-dd — это ISO-стандарт, удобный для сравнения.
💡 Совет: для отображения пользователю используй локальный формат: dd.MM.yyyy для России.
💡 Совет: для вычислений используй миллисекунды. Например, для разницы между двумя датами — вычти одну из другой, получишь миллисекунды.
💡 Совет: для напоминаний используй Calendar для вычисления момента срабатывания + Notification для показа. Через AlarmManager — если напоминание должно сработать даже при закрытом приложении.
❌ Частая ошибка: забыть про нумерацию месяцев с 0. Январь = 0, не 1. Это самая частая причина сдвигов даты.
❌ Частая ошибка: указывать год в двух цифрах (26 вместо 2026). Результат — неверная дата.
❌ Частая ошибка: путать HH и hh в формате. HH — 24-часовой, hh — 12-часовой. Разные результаты.
❌ Частая ошибка: не сохранять часовой пояс. Если приложение работает с датами из разных регионов — учитывай TimeZone.

Резюме

  • Calendar — компонент для работы с датой и временем.
  • Даёт текущую дату, поддерживает арифметику и форматирование.
  • Основные блоки: getInstance, getTimeInMillis, setTimeInMillis, get, set, add, format, after, before.
  • Формат задаётся через шаблон: dd.MM.yyyy, yyyy-MM-dd, HH:mm.
  • Даты хранятся в миллисекундах от 1970-01-01.
  • Месяцы нумеруются с 0 — январь = 0, декабрь = 11.
  • Для хранения и сортировки используй ISO (yyyy-MM-dd), для отображения — локальный.
  • Для напоминаний — Calendar + Notification (+ AlarmManager, если нужно в фоне).

Частые ошибки новичков

  • Забывают нумерацию месяцев с 0. Дата сдвигается на месяц.
  • Указывают год в двух цифрах. Получают неверную дату.
  • Путают HH и hh. Не то время в формате 12/24.
  • Не учитывают часовой пояс. Даты из других регионов отображаются неверно.
  • Не конвертируют миллисекунды. DatePicker и CalendarView работают в миллисекундах — нужен getTimeInMillis.
  • Хранят даты в произвольном формате. Теряют возможность сортировки.
  • Отображают ISO пользователю. Локальный формат удобнее.
