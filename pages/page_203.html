Проект 4. Заметки

Четвёртый проект — учимся сохранять данные между запусками приложения. Делаем простые заметки: пользователь вводит текст, нажимает «Сохранить» — данные остаются в приложении даже после перезапуска.

После этого проекта ты поймёшь:

  • как работать с SharedPreferences;
  • как сохранять и читать данные;
  • как использовать ListView для отображения списка;
  • как связывать ввод, сохранение и отображение.

Что будем делать

  • Создать проект.
  • Добавить EditText для ввода заметки.
  • Добавить Button для сохранения.
  • Добавить ListView для отображения списка.
  • Подключить SharedPreferences.
  • Сохранять заметки и загружать их при запуске.

EditText для ввода

  • Создай новый проект:
    • Имя: Заметки.
    • Пакет: com.example.notes.
    • Проект: NotesApp.
  • В Дизайнере:
    • Основной контейнер — Linear(V).
    • Добавь EditText для ввода, id noteInput.
    • Hint: «Введите заметку».
    • InputType: textMultiLine.
    • Ширина: match_parent.

Button для сохранения

  • Добавь Button под EditText.
  • id: saveBtn.
  • Text: Сохранить.
  • Ширина: match_parent.

ListView для списка

  • Добавь ListView под кнопкой.
  • id: notesList.
  • Ширина: match_parent.
  • Высота: match_parent (растянуть на остаток).

Структура макета:

  • Linear(V) — корень.
  • EditText — ввод.
  • Button — сохранить.
  • ListView — список заметок.

SharedPreferences для хранения

  • Открой вкладку «Компонент».
  • Нажми «+» → SharedPreferences.
  • Имя: prefs.
  • Сохрани.

Что будем хранить: список заметок в виде одной строки, где заметки разделены символом |.

Например: Купить хлеб|Позвонить маме|Полить цветы.

При загрузке — разбиваем строку по | и получаем список.

Логика приложения

В onCreate — загрузка заметок

  • Открой событие onCreate.
  • Добавь блоки:
    • String saved = prefs.getString("notes", "")
    • if saved ≠ "":
      • String[] notes = saved.split("|")
      • setListData для notesList = notes

Что это делает: при запуске приложения читаем сохранённые заметки и заполняем ListView.

В onClick кнопки saveBtn — сохранение

  • Открой событие onClick для saveBtn.
  • Добавь блоки:
    • String note = noteInput.getText()
    • Проверка: если note = "" → Toast «Введите заметку» и выход.
    • String saved = prefs.getString("notes", "")
    • if saved = "":
      • prefs.putString("notes", note)
    • else:
      • prefs.putString("notes", saved + "|" + note)
    • noteInput.setText("") — очистить поле.
    • Toast «Заметка сохранена».
    • Обновить список: снова прочитать prefs.getString, разбить по |, setListData для notesList.

Что это делает: добавляет новую заметку к сохранённым и обновляет список на экране.

Обработка тапа по заметке (опционально)

  • Открой событие onItemClick для notesList.
  • Добавь блок:
    • Toast с текстом выбранной заметки.
    • Так пользователь может посмотреть полный текст заметки.

Запуск

  • Нажми «Сохранить».
  • Нажми «▶ Запустить».
  • Введи заметку → нажми «Сохранить» → заметка появляется в списке.
  • Закрой приложение → открой снова → заметки на месте.

Что ты увидишь:

  • Поле ввода.
  • Кнопка «Сохранить».
  • Список заметок внизу.

Если что-то не работает:

  • Проверь, что id виджетов заданы.
  • Проверь, что SharedPreferences подключён.
  • Проверь логику разделения по |.
  • Открой Logcat — там указана причина.

Что можно улучшить

  • Удаление заметок — долгое нажатие или отдельная кнопка.
  • Редактирование — тап по заметке открывает её в EditText.
  • Дата создания — добавить к каждой заметке дату.
  • Категории — цветные метки или разделы.
  • Поиск — SearchView для фильтрации заметок.
  • База данных — вместо SharedPreferences использовать SQLite или Firebase.

💡 Совет: для большого количества заметок используй RecyclerView вместо ListView — он быстрее.

💡 Совет: для хранения дат используй компонент Calendar — он форматирует дату в строку.

⚠️ Важно: SharedPreferences не для больших данных. 100+ заметок с текстом — уже тяжело. Для больших объёмов — база данных.

⚠️ Важно: не используй | в тексте заметки. Этот символ — разделитель. Если пользователь введёт |, заметки «склеятся».

💡 Совет: для защиты от ошибки используй более редкий разделитель — например, ;;; или ~#~.

⚠️ Важно: не забудь про проверку пустой заметки. Иначе в списке появятся пустые строки.

⚠️ Важно: не забудь обновлять ListView после сохранения. Иначе новая заметка появится только при перезапуске.
