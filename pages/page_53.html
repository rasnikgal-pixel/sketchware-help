Scroll(V) — вертикальная прокрутка

Scroll(V) — контейнер с вертикальной прокруткой. Содержимое внутри него можно сдвигать вверх-вниз, если оно не помещается по высоте экрана.

Иконка в палитре — прямоугольник с изогнутой стрелкой в вертикальной плоскости.

Как работает

  • Внутри Scroll(V) может быть только один дочерний элемент — обычно это Linear(V).
  • Все виджеты перетаскиваются внутрь этого Linear(V), и вместе они образуют прокручиваемый столбик.
  • Высота содержимого определяется суммой высот виджетов внутри.
  • Если высота содержимого больше высоты экрана — появляется вертикальная прокрутка.
  • Если меньше — прокрутка не появляется, содержимое стоит на месте.

Когда использовать

  • Формы с множеством полей — когда ввод не помещается на один экран.
  • Экраны с длинным текстом — статьи, описания, инструкции.
  • Списки карточек — несколько CardView друг под другом.
  • Экраны настроек — длинные меню с пунктами.
  • Практически любой экран, где содержимого больше, чем помещается на дисплей.

Это самый часто используемый контейнер после Linear(V).

Структура, которую нужно строить

  • Scroll(V) — внешний контейнер с прокруткой.
  • Linear(V) — единственный дочерний элемент внутри Scroll(V).
  • Внутри Linear(V) — сами виджеты: TextView, EditText, Button и другие.

Без Linear(V) внутри виджеты не будут корректно выстраиваться в столбик.

Как перетащить Scroll(V) на макет

  1. Открой вкладку «Дизайнер».
  2. Раскрой категорию Layouts в палитре слева.
  3. Зажми Scroll(V) и, не отпуская, перетащи его на макет.
  4. Отпусти в нужном месте — контейнер появится в разметке.
  5. Сразу перетащи внутрь Scroll(V) контейнер Linear(V) — без него прокрутка работать не будет.
  6. Затем перетаскивай нужные виджеты (TextView, EditText, Button) внутрь Linear(V).
⚠️ Важно: обычный тап по Scroll(V) в палитре ничего не делает. Контейнер попадает на макет только перетаскиванием.

Свойства контейнера

Открой панель свойств, тапнув по контейнеру в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — vscroll2).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя контейнера. По этому имени контейнер виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — vscroll1, vscroll2 и т. д. Переименуй в contentScroll, если это основная прокрутка экрана.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». Например, android:fillViewport="true".
Конвертировать Превратить этот контейнер в другой тип (например, в HorizontalScrollView). ScrollView, HorizontalScrollView и другие. Если нужна горизонтальная прокрутка — переключи на HorizontalScrollView.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет контейнер по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent, чтобы область прокрутки заняла весь экран по ширине.
Высота
Height		 Насколько высоким будет контейнер по вертикали. match_parent, wrap_content, число в dp. match_parent — прокрутка займёт весь экран по высоте. С wrap_content прокрутка не появится.
Внутренний отступ
Padding		 Отступ внутри контейнера — от его краёв до содержимого. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Padding 16 со всех сторон — содержимое не липнет к краям экрана.
Внешний отступ
Margin		 Отступ снаружи контейнера — от него до соседних элементов и краёв родителя. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin top 8 — прокрутка начнётся на 8 dp ниже шапки.
Гравитация макета
Layout gravity		 Как контейнер выравнивается внутри родителя: по левому краю, центру, правому и т. п. none — по умолчанию;
например, center_horizontal, right.		 center_horizontal — контейнер встанет по центру родителя.
Вес
Weight		 Доля свободного места родителя, которую займёт этот контейнер. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — контейнер заберёт всё оставшееся место в родителе (например, между шапкой и подвалом).

Ресурс фона

любой drawable-ресурс.		 Установи NONE, если фон не нужен.
Цвет фона
Background color		 Заливка контейнера сплошным цветом. NONE — без цвета;
HEX или выбор из палитры (например, #FFFFFF).		 Белый фон под прокруткой содержимого — #FFFFFF.
Вращение
Rotation		 Поворот контейнера вокруг центра. Градусы. 0 — без поворота. 90 — контейнер развернётся на 90°.
Прозрачность
Alpha		 Насколько контейнер и его содержимое прозрачны. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 0.5 — половина прозрачности.
TranslationX Сдвиг контейнера по горизонтали без изменения его места в разметке (визуальный сдвиг). Число в dp. 0.0 — без сдвига. 20.0 — контейнер визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг контейнера по вертикали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.
ScaleX Масштаб по горизонтали — растягивает или сжимает контейнер по ширине. Число. 1.0 — исходный размер. 1.5 — ширина увеличится в 1,5 раза.
ScaleY Масштаб по вертикали — растягивает или сжимает контейнер по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: на первых порах достаточно четырёх свойств — Ширина, Высота, Внутренний отступ, Внешний отступ. Остальные оставь по умолчанию.

Практический пример: длинная форма

  1. Перетащи на макет Linear(V) — он будет корневым.
  2. Внутрь перетащи Scroll(V).
  3. Сразу перетащи внутрь Scroll(V) контейнер Linear(V).
  4. Внутрь Linear(V) перетаскивай поля формы: TextView, EditText, Button.
  5. Тапни по Scroll(V) и убедись, что Высота стоит match_parent, а Ширина — match_parent.
  6. Задай Scroll(V) Внутренний отступ 16 со всех сторон.
  7. Готово: длинная форма помещается на экран и прокручивается.
⚠️ Важно: Scroll(V) с одним дочерним элементом — жёсткое требование Android. Если попытаться перетащить внутрь несколько элементов напрямую, минуя Linear(V), поведение будет непредсказуемым.
⚠️ Важно: не вкладывай Scroll(V) в Scroll(V) — получится конфликт жестов, прокрутка будет дёргаться или зависать.
⚠️ Важно: если внутри Scroll(V) находится ListView или RecyclerView, прокрутка может работать некорректно — эти компоненты имеют собственную прокрутку. Для таких случаев используются специальные настройки высоты (wrap_content) или заголовки/подвалы списка.
💡 Совет: если прокрутка «не работает» — проверь, что у Scroll(V) стоит match_parent по высоте. С wrap_content контейнер растянется по содержимому и прокручивать будет нечего.

Резюме

  • Scroll(V) — контейнер с вертикальной прокруткой: содержимое листается вверх-вниз.
  • Перетаскивается на макет так же, как любой другой виджет — перетаскиванием, а не тапом.
  • Внутри должен быть ровно один дочерний элемент — обычно Linear(V).
  • Прокрутка появляется только тогда, когда высота содержимого превышает высоту экрана.
  • Главное условие работы: Высота контейнера = match_parent.
  • Главные свойства: Ширина, Высота, Внутренний и Внешний отступы, Гравитация макета, Вес.
  • Свойства изображения — визуальные, для тонкой настройки.

Частые ошибки новичков

  • Тапают по Scroll(V) в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетаскивают Scroll(V) без Linear(V) внутрь. Прокрутки нет — виджеты не размещаются в столбик.
  • Ставят Высоте wrap_content. Тогда Scroll(V) растянется по содержимому, и прокручивать будет нечего.
  • Перетаскивают внутрь Scroll(V) несколько элементов напрямую, минуя Linear(V). Нарушается требование Android «один дочерний элемент».
  • Вкладывают Scroll(V) в Scroll(V). Жесты конфликтуют, прокрутка дёргается.
  • Кладут ListView или RecyclerView прямо в Scroll(V). Двойная прокрутка работает некорректно — эти компоненты сами скроллятся.
