VideoView — видеоплеер

VideoView — проигрыватель видео. Виджет, который воспроизводит видеофайл: из ресурсов приложения, из памяти устройства или из интернета по прямой ссылке.

Иконка в палитре — прямоугольник с треугольником «play» внутри.

Как работает

  • Отображает область проигрывания видео.
  • Внизу обычно появляется панель управления: play/pause, перемотка, время, полоса прогресса.
  • Видео задаётся через логику — блок setVideoPath или setVideoURI.
  • Поддерживает локальные файлы (из памяти устройства) и сетевые ссылки (HTTP, RTSP).
  • Имеет собственные события: готовность к проигрыванию, завершение, ошибка.

Когда использовать

  • Видеоплеер — воспроизведение файлов из памяти.
  • Обучающие курсы — уроки внутри приложения.
  • Промо-ролики — рекламные видео на главном экране.
  • Онлайн-кинотеатр — простой плеер для потока.
  • Заставка при запуске — короткий интро-ролик.

Настройки

Настройка Что делает Значения
VideoPath / VideoURI Путь к видеофайлу. Обычно задаётся в логике, а не в свойствах. Путь к файлу, ссылка или ресурс.
AutoPlay Автоматически ли начинать воспроизведение при запуске. Переключатель: вкл / выкл.
Looping Повторять ли видео по кругу. Переключатель: вкл / выкл.
KeepScreenOn Не выключать экран во время просмотра. Переключатель: вкл / выкл.
Background Фон области видео. HEX или drawable-ресурс.
Width / Height Размеры виджета. match_parent по ширине, wrap_content или фиксированная высота.
Padding / Margin Внутренние и внешние отступы. Число в dp для каждой стороны.

Свойства виджета

Открой панель свойств, тапнув по VideoView в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — videoview2).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — videoview1, videoview2 и т. д. Переименуй в mainPlayer, если это основной плеер.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». Например, android:keepScreenOn="true".
Конвертировать Показывает тип виджета — VideoView. Обычно менять не нужно. VideoView и другие типы виджетов. Оставь как есть.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широкой будет область видео по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent — стандарт для плеера.
Высота
Height		 Насколько высокой будет область видео по вертикали. match_parent, wrap_content, число в dp. 220dp — стандарт для встроенного плеера.
Внутренний отступ
Padding		 Отступ внутри виджета. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 8 со всех сторон.
Внешний отступ
Margin		 Отступ снаружи виджета — от него до соседних элементов. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin bottom 16 — между плеером и следующим блоком.
Гравитация макета
Layout gravity		 Как виджет выравнивается внутри родителя. none — по умолчанию;
например, center_horizontal.		 Обычно оставляют none.
Вес
Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 0 — стандарт.

Ресурс фона

любой drawable-ресурс.		 Обычно оставляют NONE.
Цвет фона

HEX или выбор из палитры.		 Чёрный фон — #000000.

Включено		 Реагирует ли виджет на тапы и ввод. Переключатель: вкл — активен;
выкл — заблокирован.		 На скриншоте — включено.
Вращение
Rotation		 Поворот виджета вокруг центра. Градусы. 0 — без поворота. Обычно оставляют 0.
Прозрачность
Alpha		 Насколько виджет прозрачен. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.
TranslationX Сдвиг виджета по горизонтали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. 20.0 — визуально сдвинется на 20 dp вправо.

ScaleY Масштаб по вертикали — растягивает или сжимает виджет по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: в панели свойств задаётся только внешний вид. Путь к видео задаётся в логике через блоки setVideoPath или setVideoURI — в событиях вкладки «События».

Как перетащить VideoView на макет

VideoView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V), Linear(H) или RelativeLayout.
  3. Раскрой категорию Widgets в палитре слева.
  4. Зажми VideoView и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — плеер появится в разметке.
  6. Присвой осмысленный ID — он нужен для управления из логики.
  7. Открой вкладку «События» и добавь логику:
    • в onCreate — блок setVideoPath или setVideoURI с путём к видео;
    • блок start — запуск воспроизведения;
    • блок pause — пауза;
    • блок stopPlayback — остановка.
  8. Настрой события виджета: onPrepared, onCompletion, onError.
⚠️ Важно: обычный тап по VideoView в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: для воспроизведения видео из интернета требуется разрешение INTERNET в Менеджере разрешений. Без него видео не загрузится.
⚠️ Важно: для воспроизведения локальных файлов может потребоваться разрешение на чтение памяти. Без него VideoView не получит доступ к файлу.
⚠️ Важно: VideoView не работает без указания видео в логике. В Дизайнере виджет выглядит как чёрный прямоугольник — пока не задан путь.
💡 Совет: для воспроизведения из ресурсов копируй видео в res/raw через Менеджер ресурсов. Тогда путь будет выглядеть как android.resource://имя.пакета/raw/имя_файла.
💡 Совет: для онлайн-видео используй прямые ссылки на MP4-файлы или потоковые форматы (HLS, DASH). Ссылки на YouTube напрямую не работают — нужен компонент YoutubePlayer (категория Google).
💡 Совет: задавай Width = match_parent, Height = 220–260dp для стандартного плеера. Растягивать видео на весь экран без необходимости не стоит.
💡 Совет: не забывай освобождать ресурсы при уходе с экрана. Иначе воспроизведение может продолжаться в фоне и расходовать батарею.
❌ Частая ошибка: перетащить VideoView и ждать, что видео заиграет само. Без setVideoPath в логике — плеер пустой.
❌ Частая ошибка: использовать ссылку на YouTube. VideoView не поддерживает YouTube-плеер, только прямые видеофайлы.

Резюме

  • VideoView — встроенный плеер для воспроизведения видео из ресурсов, памяти или интернета.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Путь к видео задаётся в логике через setVideoPath или setVideoURI, а не в свойствах.
  • Управление (start, pause, stopPlayback) — тоже в логике.
  • Для онлайн-видео нужно разрешение INTERNET; для локальных — доступ к памяти.
  • Не поддерживает ссылки YouTube — только прямые видеофайлы или потоки.
  • Стандартный размер — match_parent по ширине, 220–260dp по высоте.

Частые ошибки новичков

  • Тапают по VideoView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Не задают путь к видео в логике. Плеер пустой — чёрный прямоугольник.
  • Ищут VideoPath в свойствах. Путь задаётся в событиях через setVideoPath.
  • Забывают разрешение INTERNET. Онлайн-видео не загружается.
  • Используют ссылку на YouTube. VideoView с ней не работает.
  • Растягивают на весь экран без необходимости. Стандартная высота — 220–260dp.
  • Не освобождают ресурсы при уходе с экрана. Воспроизведение идёт в фоне, расход батареи.
