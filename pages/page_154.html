PhoneAuth — вход по SMS

PhoneAuth — авторизация по номеру телефона. Пользователь вводит номер, получает SMS с кодом, вводит код — и входит в приложение. Не нужно помнить пароль — только телефон под рукой.

Иконка в диалоге добавления — логотип Firebase.

Как работает

  • Пользователь вводит номер телефона.
  • Firebase отправляет SMS с кодом подтверждения.
  • Пользователь вводит код из SMS.
  • Если код верный — пользователь авторизован.
  • Firebase создаёт аккаунт автоматически, если его не было.
  • Уникальный ID пользователя — номер телефона.

Когда использовать

  • Быстрая регистрация — не нужен email и пароль.
  • Мобильные приложения — пользователь уже с телефоном.
  • Приложения для доставки — курьер связывается по телефону.
  • Мессенджеры — регистрация по номеру, как в WhatsApp.
  • Приложения в странах, где email менее популярен.
  • Двухфакторная аутентификация — дополнительная проверка.
  • Приложения с оплатой — телефон связан с платёжным методом.

Основные настройки при добавлении

  • Имя компонента — идентификатор для вызова. Например, phoneAuth.

Основные блоки в логике

  • sendVerificationCode — отправить код на номер.
  • verifyPhoneNumber — проверить введённый код.
  • signOut — выход.

События PhoneAuth

  • onCodeSent — код отправлен на номер.
  • onVerificationSuccess — код верный, пользователь авторизован.
  • onVerificationFailed — код неверный или ошибка.

Как использовать

  • Зарегистрируйся в Firebase Console.
  • В разделе Authentication включи Phone.
  • Скачай google-services.json и подключи его в Sketchware Pro 7.
  • Подключи компонент PhoneAuth на вкладке «Компонент».
  • Задай имя — например, phoneAuth.
  • Добавь разрешение INTERNET.
  • В логике:
    • отправка кода — sendVerificationCode с номером телефона;
    • проверка кода — verifyPhoneNumber с введённым кодом;
    • в onVerificationSuccess — переход на главный экран;
    • в onVerificationFailed — показать сообщение об ошибке.

Пример: вход по телефону

  • EditText для номера телефона.
  • Button «Отправить код» → sendVerificationCode.
  • EditText для кода.
  • Button «Подтвердить» → verifyPhoneNumber.
  • В onVerificationSuccess — переход на главный экран.

Формат номера телефона

  • С кодом страны: +79991234567.
  • Без пробелов, дефисов, скобок.
  • Только цифры и знак + в начале.

⚠️ Важно: номер должен быть в международном формате с кодом страны. +7 для России, +380 для Украины, +1 для США. Иначе SMS не придёт.

⚠️ Важно: SMS не бесплатны. Firebase взимает плату за отправку SMS после определённого лимита. Следи за用量.

⚠️ Важно: не все номера работают — виртуальные, VoIP, тестовые могут быть заблокированы.

⚠️ Важно: для тестирования используй тестовые номера из Firebase Console. Иначе за каждую SMS придётся платить.

⚠️ Важно: пользователь может ввести неправильный номер. Проверяй формат перед отправкой.

⚠️ Важно: защита от спама — Firebase имеет лимиты на отправку SMS с одного устройства. Не давай пользователю спамить кнопкой «Отправить».

💡 Совет: для ввода номера используй отдельное поле с подсказкой: «+7 999 123-45-67». Помогает пользователю понять формат.

💡 Совет: для повторной отправки добавь таймер: «Отправить повторно можно через 60 секунд». Так пользователь не будет спамить.

💡 Совет: для тестирования используй номера из раздела Phone numbers for testing в Firebase Console. Они работают без реальной SMS.

💡 Совет: для автоматического чтения SMS используй SMS Retriever API. Код подставляется в поле автоматически без участия пользователя. Это удобнее.

💡 Совет: для сохранения сессии Firebase помнит пользователя. При следующем запуске — не нужно вводить код снова.

💡 Совет: не показывай пользователю полный номер после входа. Маскируй часть: +7 999 ***-**-67.

❌ Частая ошибка: номер без кода страны. SMS не приходит, ошибка не всегда видна.

❌ Частая ошибка: не использовать тестовые номера при разработке. SMS платные, счёт растёт.

❌ Частая ошибка: не обрабатывать onVerificationFailed. Пользователь вводит неверный код, но не понимает почему.

❌ Частая ошибка: не ограничивать число попыток. Пользователь может бесконечно запрашивать SMS.

❌ Частая ошибка: не проверять формат номера перед отправкой. Firebase вернёт ошибку.
