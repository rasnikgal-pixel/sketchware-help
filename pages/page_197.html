Проект 3. Калькулятор

Третий проект — учимся работать с числами и переменными. Делаем простой калькулятор: два поля для ввода, кнопки для действий, результат в отдельном поле.

После этого проекта ты поймёшь:

  • как работать с EditText и числами;
  • как создавать и использовать переменные;
  • как делать вычисления через блоки;
  • как выводить результат в TextView.

Что будем делать

  • Создать проект.
  • Добавить два EditText для чисел.
  • Добавить четыре кнопки: +, −, ×, ÷.
  • Добавить TextView для результата.
  • Описать логику вычислений.
  • Запустить и проверить.

Разметка кнопок

  • Создай новый проект:
    • Имя: Калькулятор.
    • Пакет: com.example.calc.
    • Проект: Calculator.
  • В Дизайнере:
    • Добавь Linear(V) как основной контейнер.
    • Внутри — два EditText для чисел.
    • Присвой им id: num1 и num2.
    • Задай InputType = numberDecimal — только числа.
    • Добавь TextView для результата, id result.
    • Добавь четыре кнопки: +, −, ×, ÷.
    • id кнопок: btnAdd, btnSub, btnMul, btnDiv.
    • Размести их в Linear(H) — в одну строку.

TextView для результата

  • Добавь TextView под кнопками.
  • Присвой id result.
  • Задай TextSize = 20sp, TextStyle = bold.
  • Text: 0 — как заглушка.
  • Gravity: center.

Переменные

Переменные нужны для хранения значений между блоками.

  • Открой вкладку «События».
  • Найди событие onCreate.
  • Открой его блочное полотно.
  • В палитре найди блок «Объявить переменную».
  • Объяви переменные:
    • a — тип Число (double).
    • b — тип Число (double).
    • res — тип Число (double).

💡 Совет: для чисел с дробной частью используй double. Для целых — int.

Логика вычислений

Для каждой кнопки создай событие onClick и собери блоки:

Для кнопки + (btnAdd):

  • a = getText из num1, в число
  • b = getText из num2, в число
  • res = a + b
  • setText для result = res

Для кнопки − (btnSub):

  • a = getText из num1, в число
  • b = getText из num2, в число
  • res = a - b
  • setText для result = res

Для кнопки × (btnMul):

  • a = getText из num1, в число
  • b = getText из num2, в число
  • res = a * b
  • setText для result = res

Для кнопки ÷ (btnDiv):

  • a = getText из num1, в число
  • b = getText из num2, в число
  • Проверка: если b = 0 → Toast «На ноль делить нельзя!».
  • Иначе: res = a / b, setText для result = res.

⚠️ Важно: проверка деления на ноль обязательна. Без неё приложение может показать «Infinity» или упасть.

💡 Совет: используй блок getText с конвертацией в число. Если просто взять текст — получишь строку, а не число.

Запуск

  • Нажми «Сохранить».
  • Нажми «▶ Запустить».
  • Введи два числа, нажми на кнопку — результат появится в TextView.

Что ты увидишь:

  • Два поля для ввода.
  • Четыре кнопки.
  • Результат внизу.

Если что-то не работает:

  • Проверь, что все id заданы.
  • Проверь, что у EditText стоит InputType = numberDecimal.
  • Проверь, что переменные объявлены в onCreate.
  • Открой Logcat — там указана причина.

Что можно улучшить

  • Добавить кнопку = — чтобы не считать автоматически.
  • История вычислений — ListView с предыдущими результатами.
  • Кнопка очистки — очищает поля и результат.
  • Обработка ошибок — если поля пустые, показать сообщение.
  • Больше операций — процент, степень, корень.

💡 Совет: попробуй добавить кнопку =. Тогда вычисления будут срабатывать не сразу после выбора операции, а по подтверждению.

⚠️ Важно: не забывай про id. Без него блоки не найдут виджеты.

⚠️ Важно: проверяй деление на ноль. Частая ошибка — приложение падает.

⚠️ Важно: не путай строки и числа. Если не сконвертировать текст в число — блоки будут работать со строкой, и результат будет неверным.
