Проект 3. Калькулятор

Третий проект — учимся работать с числами и переменными. Делаем простой калькулятор: два поля для ввода, кнопки для действий, результат в отдельном поле.

После этого проекта ты поймёшь:

  • как работать с EditText и числами;
  • как создавать и использовать переменные;
  • как делать вычисления через блоки;
  • как выводить результат в TextView.

Что будем делать

  • Создадим новый проект в Sketchware Pro 7.
  • Откроем редактор экрана и перетащим на макет два поля EditText для ввода чисел.
  • Перетащим четыре кнопки: +, −, ×, ÷, а также TextView для результата.
  • Зададим всем виджетам id — без них логика не найдёт их.
  • Объявим переменные и опишем вычисления для каждой кнопки.
  • Соберём APK и проверим, что калькулятор считает правильно.

Разметка экрана

  • Создай новый проект:
    • Имя: Калькулятор.
    • Пакет: com.example.calc.
    • Проект: Calculator.
  • В Дизайнере:
    • Перетащи из палитры на макет Linear(V) как основной контейнер.
    • Внутрь него перетащи два EditText для чисел.
    • Присвой им id: num1 и num2.
    • Задай InputType = numberDecimal — только числа.
    • Перетащи TextView для результата, id result.
    • Перетащи четыре кнопки: +, −, ×, ÷.
    • id кнопок: btnAdd, btnSub, btnMul, btnDiv.
    • Перетащи их в Linear(H) — чтобы стояли в одну строку.
Подсказка для новичка. Виджеты перетаскиваются из палитры на макет, а не «добавляются» и не «вставляются». Если виджет не встаёт в нужное место — удерживай палец и отпусти над контейнером.

TextView для результата

  • Перетащи TextView из палитры на макет под кнопками.
  • Присвой id result.
  • Задай TextSize = 20sp, TextStyle = bold.
  • Text: 0 — как заглушка.
  • Gravity: center.

Переменные

Переменные нужны для хранения значений между блоками.

  • Открой вкладку «События».
  • Найди событие onCreate.
  • Открой его блочное полотно.
  • В палитре найди блок «Объявить переменную».
  • Объяви переменные:
    • a — тип Число (double).
    • b — тип Число (double).
    • res — тип Число (double).

💡 Совет: для чисел с дробной частью используй double. Для целых — int.

Логика вычислений

Для каждой кнопки создай событие onClick и собери блоки:

Для кнопки + (btnAdd):

  • a = getText из num1, в число
  • b = getText из num2, в число
  • res = a + b
  • setText для result = res

Для кнопки − (btnSub):

  • a = getText из num1, в число
  • b = getText из num2, в число
  • res = a - b
  • setText для result = res

Для кнопки × (btnMul):

  • a = getText из num1, в число
  • b = getText из num2, в число
  • res = a * b
  • setText для result = res

Для кнопки ÷ (btnDiv):

  • a = getText из num1, в число
  • b = getText из num2, в число
  • Проверка: если b = 0 → Toast «На ноль делить нельзя!».
  • Иначе: res = a / b, setText для result = res.

⚠️ Важно: проверка деления на ноль обязательна. Без неё приложение может показать «Infinity» или упасть.

💡 Совет: используй блок getText с конвертацией в число. Если просто взять текст — получишь строку, а не число.

Запуск

  • Нажми «Сохранить».
  • Нажми «▶ Запустить».
  • Введи два числа, нажми на кнопку — результат появится в TextView.

Что ты увидишь:

  • Два поля для ввода.
  • Четыре кнопки.
  • Результат внизу.

Если что-то не работает:

  • Проверь, что все id заданы.
  • Проверь, что у EditText стоит InputType = numberDecimal.
  • Проверь, что переменные объявлены в onCreate.
  • Открой Logcat — там указана причина.

Что можно улучшить

  • Перетащить на макет кнопку = — чтобы не считать автоматически.
  • История вычислений — перетащить ListView и хранить предыдущие результаты.
  • Кнопка очистки — очищает поля и результат.
  • Обработка ошибок — если поля пустые, показать сообщение.
  • Больше операций — процент, степень, корень (дополнительные кнопки на макете).

💡 Совет: попробуй перетащить на макет ещё одну кнопку =. Тогда вычисления будут срабатывать не сразу после выбора операции, а по подтверждению.

⚠️ Важно: не забывай про id. Без него блоки не найдут виджеты.

⚠️ Важно: проверяй деление на ноль. Частая ошибка — приложение падает.

⚠️ Важно: не путай строки и числа. Если не сконвертировать текст в число — блоки будут работать со строкой, и результат будет неверным.

Резюме

  • Создали новый проект Calculator.
  • Перетащили на макет два EditText, четыре кнопки и TextView для результата.
  • Задали всем виджетам id — без них логика не работает.
  • Объявили переменные a, b, res и описали вычисления для каждой кнопки.
  • Собрали и запустили APK — калькулятор считает.

Частые ошибки новичков

  • Не задан id виджета. Блоки не найдут EditText и TextView — логика сломается.
  • Не сконвертировали текст в число. Строка «5» плюс строка «3» дадут «53», а не 8.
  • Нет проверки деления на ноль. Приложение покажет «Infinity» или упадёт.
  • Переменные объявлены не в onCreate. Тогда они не будут доступны другим событиям.
  • InputType не numberDecimal. Пользователь сможет ввести буквы — приложение упадёт при вычислении.
