Левое меню

Левое меню — это вертикальная панель на вкладке «События», где перечислены категории событий. Отсюда ты выбираешь, какое событие добавить: для экрана, для виджета, для компонента или для чего-то ещё.

Каждое событие относится к одной из пяти категорий. Выбор категории определяет, какие события будут доступны в диалоге добавления.

Из чего состоит левое меню

Сверху вниз расположены пять категорий.

Категория Что содержит Иконка
Активность События жизненного цикла экрана. Круговая стрелка с буквой «A».
View События виджетов, добавленных в Дизайнере. Список или окно.
Компонент События сервисов, подключённых на вкладке «Компонент». Окно с полями.
Drawer События бокового меню (если оно есть в проекте). Боковая панель.
More Block Пользовательские блоки, созданные вручную. Пазл или фигурный блок.

Как работает выбор категории

  • Тап по категории — открывает диалог добавления событий этой категории.
  • В диалоге — список доступных событий с чекбоксами.
  • Отмечаешь нужные, нажимаешь «Добавить» — они появляются в центре экрана в виде плиток.
  • Каждая категория хранит свои события: события View не смешиваются с событиями Activity.

Что важно понимать про каждую категорию

  • Активность — самая важная категория. Здесь onCreate, onStart, onResume и другие события жизненного цикла.
  • View — пополняется автоматически. Как только ты добавишь кнопку в Дизайнере и присвоишь ей id, для неё появятся события в этой категории.
  • Компонент — пополняется после подключения сервисов (Intent, SharedPreferences, Timer и т. д.).
  • Drawer — если бокового меню нет, категория пустая.
  • More Block — если пользовательских блоков нет, категория пустая или скрыта.
⚠️ Важно: не все категории заполнены сразу. Например, на новом проекте категория «View» пустая — потому что ещё нет виджетов. Категория «Компонент» пустая — потому что нет компонентов.
⚠️ Важно: если событие не появляется в диалоге, значит, для него нет условий. Например, onClick для кнопки не появится, пока кнопка не добавлена в Дизайнере и ей не задан id.
💡 Совет: начинай с Активности. Событие onCreate — это точка входа в любое приложение. Здесь настраивай переменные, читай данные, задавай начальные значения.
💡 Совет: добавляй события View только для тех виджетов, с которыми действительно будешь работать в логике. Пустые события создают мусорный код.
💡 Совет: для бокового меню сначала добавь Drawer в разметку (через свойства макета), потом используй категорию Drawer.
❌ Частая ошибка: искать событие View в категории Активность и наоборот. Каждая категория — своя.
❌ Частая ошибка: не задавать id виджетам. Без id виджет не появится в категории View, и событие для него добавить не получится.
❌ Частая ошибка: думать, что More Block — стандартное событие. Это пользовательские блоки, которые создаются отдельно вручную.

Резюме

  • Левое меню — вертикальная панель категорий событий на вкладке «События».
  • В нём пять категорий: Активность, View, Компонент, Drawer, More Block.
  • Каждая категория хранит свои события — они не смешиваются.
  • Список событий в категории зависит от того, что уже есть в проекте: виджеты, компоненты, Drawer.
  • Активность — самая важная категория, где находится onCreate.
  • View пополняется автоматически при добавлении виджетов с ID.
  • Компонент пополняется после подключения сервисов.
  • Выбор категории открывает диалог добавления событий.

Частые ошибки новичков

  • Ищут событие View в категории Активность. Каждая категория — своя.
  • Не задают ID виджетам. Виджет не появляется в категории View.
  • Не подключают компонент. События компонента не появятся.
  • Путают Drawer с боковым меню виджета. Drawer — это специальный контейнер в разметке.
  • Думают, что More Block — стандартный. Это пользовательские блоки, создаются вручную.
  • Ожидают увидеть все события сразу. Список формируется из того, что уже добавлено в проект.
  • Пытаются добавлять события без нужных компонентов. Их просто не будет в списке.
