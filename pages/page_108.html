Что такое событие

Событие — это действие или ситуация, на которую приложение реагирует. Например: пользователь запустил экран, нажал кнопку, изменил текст в поле. Событие — это точка входа в логику: без него блоки не выполняются.

По сути событие — это «когда что-то произошло, сделай следующее». Ты выбираешь событие и описываешь, что должно случиться.

Из чего состоит событие

  • Название — например, onCreate, onClick, onCheckedChanged.
  • Описание — краткое пояснение, когда срабатывает.
  • Блоки — команды, которые выполняются при срабатывании.
  • Привязка к виджету или экрану — событие принадлежит либо экрану (Activity), либо конкретному виджету.

Какие бывают события

События жизненного цикла Activity

  • onCreate — при создании экрана. Самое первое событие.
  • onStart — при появлении экрана.
  • onResume — при возобновлении работы.
  • onPause — при паузе (например, пользователь свернул приложение).
  • onStop — когда экран стал невидим.
  • onDestroy — при уничтожении экрана.
  • onBackPressed — при нажатии кнопки «Назад».

События виджетов (View)

  • onClick — при тапе по кнопке, картинке и т.д.
  • onLongClick — при долгом нажатии.
  • onCheckedChanged — при переключении чекбокса, свитча, радиокнопки.
  • onTextChanged — при изменении текста в поле ввода.
  • onItemClick — при выборе элемента списка.
  • onItemSelected — при выборе в Spinner.
  • onProgressChanged — при движении SeekBar.
  • onRatingChanged — при изменении RatingBar.

События компонентов

  • onResponse — при получении ответа от RequestNetwork.
  • onErrorResponse — при ошибке сетевого запроса.
  • onTimerTick — при срабатывании Timer.
  • onBindViewHolder — при отрисовке элемента RecyclerView.

Как добавить событие

  1. Открой вкладку «События» (вторая вкладка проекта).
  2. В левом меню выбери категорию: Активность, View, Компонент, Drawer или More Block.
  3. Тапни по кнопке «+» внизу справа.
  4. Откроется диалог со списком событий выбранной категории.
  5. Отметь нужное событие галочкой и нажми «Добавить».
  6. Событие появится в центральном списке.

Как открыть событие для редактирования

  • Найди его в списке на вкладке «События».
  • Тапни по стрелке > слева от названия — откроется блочное полотно.
  • На полотне добавляй блоки из палитры.
  • Для возврата — стрелка назад в шапке.

Как удалить событие

  • Тапни по стрелке ∨ справа от события.
  • Раскроется пункт «Сброс» — удаление блоков внутри (но само событие останется).
  • Для полного удаления события используй контекстное меню или долгий тап по нему.

⚠️ Важно: событие без блоков ничего не делает. Оно существует в структуре проекта, но при срабатывании не выполняет действий.

⚠️ Важно: не добавляй событие дважды. Если onClick для кнопки уже есть — второй раз он не появится, но и не будет дублироваться. Не путай: одно событие onClick может содержать много блоков.

⚠️ Важно: события виджетов появляются в списке только после того, как виджет добавлен в Дизайнере и ему присвоен id. Без id виджет не появится в категории View.

💡 Совет: для простой кнопки достаточно одного события onClick. Не добавляй onLongClick, onTouch и другие «на всякий случай» — это лишний код.

💡 Совет: для стартовой инициализации используй onCreate. Здесь настраивай переменные, читай данные из SharedPreferences, показывай приветствие.

💡 Совет: для сохранения данных используй onPause или onStop — когда пользователь уходит с экрана. Это предотвратит потерю данных при сворачивании.

💡 Совет: не дублируй логику в разных событиях. Если одно и то же нужно в onCreate и в onClick — вынеси в More Block и вызывай оттуда.

❌ Частая ошибка: добавлять событие для виджета без id. Виджет не появится в списке — событие добавить не получится.

❌ Частая ошибка: путать события Activity и View. onCreate — это событие экрана, onClick — событие кнопки. Это разные категории.

❌ Частая ошибка: добавлять события «про запас». Каждое пустое событие — это лишний метод в коде приложения. Много таких — APK тяжелее, сборка дольше.
