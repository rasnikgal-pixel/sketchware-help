Логика SettingsActivity

SettingsActivity — экран настроек приложения. Здесь пользователь переключает тему, выбирает размер шрифта редактора, включает автосохранение и выбирает акцентный цвет.

Логика этого экрана двусторонняя: с одной стороны — чтение сохранённых настроек и отображение их в элементах управления. С другой стороны — запись новых значений, когда пользователь что-то меняет.

Как открыть логику этого экрана

  1. Открой вкладку «События».
  2. Переключись на экран settings.xml через селектор внизу (или через Менеджер представлений).
  3. Ты увидишь список событий только этого экрана.

События SettingsActivity

У этого экрана шесть событий:

  1. При создании / (onCreate) — загрузка сохранённых настроек в элементы управления.
  2. Нажатие btnSettingsBack / (onClick) — возврат на главный экран.
  3. themeSwitch onCheckedChanged — переключение темы.
  4. fontSeek onProgressChanged — изменение размера шрифта редактора.
  5. autosaveSwitch onCheckedChanged — включение / выключение автосохранения.
  6. accentSpinner onItemSelected — выбор акцентного цвета интерфейса.

Событие 1. При создании / (onCreate)

Когда срабатывает: при открытии экрана SettingsActivity.

Что делает: читает сохранённые настройки из хранилища и устанавливает их в элементы управления — чтобы пользователь видел текущие значения.

Порядок блоков:

  1. Прочитать булево / (Get Boolean) по ключу theme_dark. Значение по умолчанию: false. Результат в isDark.
  2. Установить отмечен / (Set Checked) для виджета themeSwitch = isDark.
  3. Прочитать число / (Get Int) по ключу editor_font_size. Значение по умолчанию: 14. Результат в fontSize.
  4. Установить прогресс / (Set Progress) для виджета fontSeek = fontSize.
  5. Прочитать булево / (Get Boolean) по ключу autosave. Значение по умолчанию: true. Результат в auto.
  6. Установить отмечен / (Set Checked) для виджета autosaveSwitch = auto.
  7. Прочитать строку / (Get String) по ключу ui_accent_color. Значение по умолчанию: "#2a7". Результат в accent.
  8. В зависимости от значения accent — Установить выбор / (Set Selection) для accentSpinner:
    • Если accent == "#2a7" — позиция 0.
    • Если accent == "#27a" — позиция 1.
    • Если accent == "#a72" — позиция 2.
    • Если accent == "#a27" — позиция 3.

Псевдокод onCreate:

// ──── Тема ────
// Читаем сохранённое состояние темы.
isDark = getBoolean("theme_dark", false)

// Устанавливаем Switch в это состояние.
themeSwitch.setChecked(isDark)

// ──── Размер шрифта ────
fontSize = getInt("editor_font_size", 14)
fontSeek.setProgress(fontSize)

// ──── Автосохранение ────
auto = getBoolean("autosave", true)
autosaveSwitch.setChecked(auto)

// ──── Акцентный цвет ────
accent = getString("ui_accent_color", "#2a7")

if (accent == "#2a7") {
    accentSpinner.setSelection(0)
} else if (accent == "#27a") {
    accentSpinner.setSelection(1)
} else if (accent == "#a72") {
    accentSpinner.setSelection(2)
} else {
    accentSpinner.setSelection(3)
}

Что важно понять:

  • Без этого события пользователь при каждом открытии настроек видел бы «сброшенные» переключатели — не совпадающие с реально сохранёнными значениями.
  • Значение по умолчанию обязательно. Если ключа нет (первый запуск) — блок вернёт его.
  • Мы читаем и устанавливаем в том же порядке, в каком элементы идут в разметке сверху вниз — так удобнее проверять.

Событие 2. Нажатие btnSettingsBack / (onClick)

Когда срабатывает: при тапе по кнопке «←» в шапке экрана настроек.

Что делает: закрывает SettingsActivity и возвращает пользователя на главный экран.

Порядок блоков:

  1. Завершить / (Finish) для компонента goToScreen.

Псевдокод onClick btnSettingsBack:

// Закрываем текущий экран. Android вернёт пользователя на главный.
goToScreen.finish()

Событие 3. themeSwitch onCheckedChanged

Когда срабатывает: при переключении Switch «Тёмная тема».

Что делает: сохраняет новое состояние темы и применяет его.

Порядок блоков:

  1. Получить отмечен / (Get Checked) для виджета themeSwitch. Результат в isChecked.
  2. Записать булево / (Put Boolean) по ключу theme_dark = isChecked.
  3. Если / (If) isChecked == true: Установить ночной режим / (Set Night Mode) = Да / (Yes).
  4. Иначе / (Else): Установить ночной режим / (Set Night Mode) = Нет / (No).

Псевдокод onCheckedChanged themeSwitch:

isChecked = themeSwitch.isChecked()

// Сохраняем в хранилище.
putBoolean("theme_dark", isChecked)

// Применяем тему.
if (isChecked == true) {
    setNightMode(YES)
} else {
    setNightMode(NO)
}

Что важно понять:

  • Порядок блоков критичен: сначала сохраняем, потом применяем.
  • Без сохранения — при следующем запуске приложение забудет выбор пользователя.
  • Без применения — тема не переключится визуально, пока пользователь не закроет и не откроет экран заново.

Событие 4. fontSeek onProgressChanged

Когда срабатывает: при движении ползунка fontSeek.

Что делает: сохраняет новое значение размера шрифта редактора.

Порядок блоков:

  1. Получить прогресс / (Get Progress) для виджета fontSeek. Результат в size.
  2. Записать число / (Put Int) по ключу editor_font_size = size.

Псевдокод onProgressChanged fontSeek:

size = fontSeek.getProgress()
putInt("editor_font_size", size)

Что важно понять:

  • Событие срабатывает много раз — при каждом движении ползунка. Это нормально, сохранение в хранилище быстрое.
  • Значение сохраняется сразу — не нужно ждать кнопки «Сохранить».
  • Реальное применение размера шрифта произойдёт в EditorActivity при следующем открытии экрана.

Событие 5. autosaveSwitch onCheckedChanged

Когда срабатывает: при переключении Switch «Включить автосохранение».

Что делает: сохраняет новое состояние флага и показывает уведомление пользователю.

Порядок блоков:

  1. Получить отмечен / (Get Checked) для виджета autosaveSwitch. Результат в isChecked.
  2. Записать булево / (Put Boolean) по ключу autosave = isChecked.
  3. Если / (If) isChecked == true: Всплывающее сообщение / (Toast) = "Автосохранение включено".
  4. Иначе / (Else): Всплывающее сообщение / (Toast) = "Автосохранение выключено".

Псевдокод onCheckedChanged autosaveSwitch:

isChecked = autosaveSwitch.isChecked()

putBoolean("autosave", isChecked)

if (isChecked == true) {
    Toast("Автосохранение включено")
} else {
    Toast("Автосохранение выключено")
}

Что важно понять:

  • Toast здесь нужен, чтобы пользователь увидел подтверждение своего действия. Без него переключение ощущается «немым».
  • Флаг автосохранения будет использоваться в EditorActivity при редактировании HTML — если он включён, изменения сохраняются автоматически.

Событие 6. accentSpinner onItemSelected

Когда срабатывает: при выборе элемента в списке accentSpinner.

Что делает: сохраняет выбранный акцентный цвет интерфейса.

Порядок блоков:

  1. Получить позицию / (Get Position) для accentSpinner. Результат в pos.
  2. В зависимости от pos — определить цвет:
    • Позиция 0 → color = "#2a7" (зелёный).
    • Позиция 1 → color = "#27a" (синий).
    • Позиция 2 → color = "#a72" (оранжевый).
    • Иначе → color = "#a27" (розовый).
  3. Записать строку / (Put String) по ключу ui_accent_color = color.
  4. Всплывающее сообщение / (Toast) = "Цвет изменён".

Псевдокод onItemSelected accentSpinner:

pos = accentSpinner.getSelectedItemPosition()

if (pos == 0) {
    color = "#2a7"
} else if (pos == 1) {
    color = "#27a"
} else if (pos == 2) {
    color = "#a72"
} else {
    color = "#a27"
}

putString("ui_accent_color", color)
Toast("Цвет изменён")

Что важно понять:

  • Перед тем как использовать Spinner, нужно заполнить его элементами. Это делается либо в разметке, либо через логику в onCreate (блок Установить список / (Set List Data)).
  • В HelpStudio список цветов задан статически в свойствах accentSpinner — четыре варианта подписей: «Зелёный», «Синий», «Оранжевый», «Розовый».
  • Событие onItemSelected срабатывает при каждом выборе, включая первый автоматический выбор при загрузке экрана. Поэтому Toast «Цвет изменён» может появиться сразу при открытии настроек — это нормально.

Что важно понять про логику SettingsActivity

Первое — экран настроек двусторонний. С одной стороны, он читает сохранённые значения и показывает их в элементах. С другой стороны, он записывает новые значения, когда пользователь что-то меняет.

Второе — каждое изменение сохраняется сразу. Не нужно кнопки «Применить» или «Сохранить». Пользователь двигает ползунок — значение уже сохранено. Переключает тумблер — уже сохранено.

Третье — тема применяется через отдельный блок. Установить ночной режим / (Set Night Mode) — это не обычная запись в хранилище. Это команда системе Android перерисовать интерфейс в тёмных или светлых цветах.

Четвёртое — акцентный цвет сохраняется, но пока не применяется. В этой версии HelpStudio акцентный цвет только сохраняется в хранилище. Чтобы он реально применился к кнопкам и полям — нужно в onCreate каждого экрана прочитать его и установить через соответствующий блок. Это можно добавить в следующей версии.

Пятое — размер шрифта тоже только сохраняется. Реально размер шрифта редактора применяется в EditorActivity при открытии — там в onCreate нужно прочитать editor_font_size и установить размер текста для editorText.

Совет. Проверь работу настроек: открой экран, переключи тему — она применится. Двинь ползунок — значение сохранится. Переключи автосохранение — Toast появится. Перезапусти приложение — все настройки должны остаться.
Частая ошибка. Забыть про значение по умолчанию при чтении. Если ключа нет (первый запуск) и значение по умолчанию не задано — приложение может упасть или показать неправильное состояние. Всегда указывай значение по умолчанию.
