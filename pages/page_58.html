BottomNavigationView — нижняя навигация

BottomNavigationView — нижнее меню навигации. Компонент, который показывает 3–5 иконок с подписями внизу экрана. Пользователь тапает по иконке, и приложение переключается между основными разделами.

Иконка в палитре — прямоугольник с выделенной нижней полосой.

Как работает

  • Внизу экрана — горизонтальный ряд иконок.
  • Активная иконка подсвечивается цветом colorAccent, остальные — серые.
  • При тапе по иконке срабатывает событие и открывается соответствующий раздел.
  • Меню «прибито» к нижнему краю — не уезжает при прокрутке содержимого.

Из чего состоит

  • Пункты меню (MenuItem) — обычно 3–5 штук, каждый с иконкой и подписью.
  • Слушатель (OnNavigationItemSelectedListener) — реагирует на выбор пункта.
  • Активный пункт — тот, который выбран в данный момент.

Когда использовать

  • Основные разделы приложения — «Главная», «Поиск», «Профиль».
  • Мессенджеры и соцсети — «Чаты», «Контакты», «Настройки».
  • Магазины — «Каталог», «Корзина», «Избранное», «Профиль».
  • Любое приложение с 3–5 главными экранами, между которыми пользователь переключается часто.

Настройки

Настройка Что делает Значения
Background Цвет фона меню. HEX или выбор из палитры.
ItemIconTint Цвет иконок пунктов. HEX или выбор из палитры.
ItemTextColor Цвет текста подписей под иконками. HEX или выбор из палитры.
Menu Файл меню, где описаны пункты. Ресурс-файл (например, bottom_navigation_menu.xml).
LabelVisibilityMode Когда показывать подписи под иконками. Всегда, никогда или только у активного пункта.
Width / Height Ширина и высота компонента. По умолчанию match_parent по ширине и wrap_content по высоте.

Как перетащить BottomNavigationView на макет

BottomNavigationView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Раскрой категорию AndroidX в палитре слева.
  3. Зажми BottomNavigationView и, не отпуская, перетащи его на макет (лучше внутрь Linear(V) с гравитацией bottom или в RelativeLayout с alignParentBottom).
  4. Отпусти в нужном месте — меню появится в разметке.
  5. В свойствах задай цвета (Цвет фона, ItemIconTint, ItemTextColor) и LabelVisibilityMode.
  6. В Менеджере ресурсов → Менеджер меню создай XML-файл меню с пунктами: id, иконка, заголовок.
  7. В свойствах компонента укажи этот файл в поле Menu.
  8. Открой вкладку «События» — добавь событие onNavigationItemSelected и блоки для каждого пункта.
⚠️ Важно: обычный тап по BottomNavigationView в палитре ничего не делает. Компонент попадает на макет только перетаскиванием.
⚠️ Важно: BottomNavigationView не переключает экраны автоматически. Он только сообщает логике, какой пункт выбран. Что показывать — описывается в блоках событий вручную (обычно через Fragment или смену видимости Linear).
⚠️ Важно: Android рекомендует 3–5 пунктов в нижнем меню. Меньше трёх — выглядит странно, больше пяти — иконки становятся слишком мелкими, а некоторые могут уйти в раздел «Ещё».
💡 Совет: подписи под иконками — обязательны. Иконки без подписей пользователю непонятны, если он не знает приложение.
💡 Совет: используй BottomNavigationView для главных разделов приложения, а вкладки (TabLayout) — для второстепенных внутри одного раздела.
❌ Частая ошибка: перетащить BottomNavigationView без меню. Компонент появится пустой полосой без иконок — потому что не указан файл меню.

Резюме

  • BottomNavigationView — нижнее меню навигации в стиле Material Design, 3–5 иконок с подписями.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Ключевые настройки: Menu (файл меню), ItemIconTint, ItemTextColor, LabelVisibilityMode.
  • Сам по себе не переключает экраны — нужно событие onNavigationItemSelected.
  • Оптимальное количество пунктов — 3–5.
  • Подходит для главных разделов приложения, между которыми пользователь часто переключается.

Частые ошибки новичков

  • Тапают по BottomNavigationView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетащили меню, но не указали файл Menu. Меню пустое, без иконок и подписей.
  • Не добавили событие onNavigationItemSelected. Иконки видны, но при тапе ничего не происходит.
  • Сделали больше 5 пунктов. Иконки становятся мелкими, часть может уйти в раздел «Ещё».
  • Не задали подписи у пунктов. Иконки без подписей пользователю непонятны.
  • Путают с TabLayout. TabLayout — вкладки сверху, BottomNavigationView — меню снизу.
  • Забывают про Material-библиотеку. Без неё компонент может не отобразиться.
