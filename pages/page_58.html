BottomNavigationView — нижняя навигация

BottomNavigationView — нижнее меню навигации. Компонент, который показывает 3–5 иконок с подписями внизу экрана. Пользователь тапает по иконке, и приложение переключается между основными разделами.

Иконка в палитре — прямоугольник с выделенной нижней полосой.

Как работает

  • Внизу экрана — горизонтальный ряд иконок.
  • Активная иконка подсвечивается цветом colorAccent, остальные — серые.
  • При тапе по иконке срабатывает событие и открывается соответствующий раздел.
  • Меню «прибито» к нижнему краю — не уезжает при прокрутке содержимого.

Из чего состоит

  • Пункты меню (MenuItem) — обычно 3–5 штук, каждый с иконкой и подписью.
  • Слушатель (OnNavigationItemSelectedListener) — реагирует на выбор пункта.
  • Активный пункт — тот, который выбран в данный момент.

Когда использовать

  • Основные разделы приложения — «Главная», «Поиск», «Профиль».
  • Мессенджеры и соцсети — «Чаты», «Контакты», «Настройки».
  • Магазины — «Каталог», «Корзина», «Избранное», «Профиль».
  • Любое приложение с 3–5 главными экранами, между которыми пользователь переключается часто.

Настройки

  • Background — цвет фона меню.
  • ItemIconTint — цвет иконок.
  • ItemTextColor — цвет текста подписей.
  • Menu — файл меню, где описаны пункты (bottom_navigation_menu.xml).
  • LabelVisibilityMode — показывать подписи всегда, никогда или только у активного.
  • Width / Height — match_parent по ширине, wrap_content по высоте.

Как добавить

  • Тап по BottomNavigationView в палитре — компонент добавится в текущий выбранный контейнер.
  • В свойствах задай цвета и LabelVisibilityMode.
  • В Менеджере ресурсов → Менеджер меню создай XML-файл меню с пунктами: id, иконка, заголовок.
  • В свойствах компонента укажи этот файл в поле Menu.
  • Открой вкладку «События» — добавь событие onNavigationItemSelected и блоки для каждого пункта.

⚠️ Важно: BottomNavigationView не переключает экраны автоматически. Он только сообщает логике, какой пункт выбран. Что показывать — описывается в блоках событий вручную (обычно через Fragment или смену видимости Linear).

⚠️ Важно: Android рекомендует 3–5 пунктов в нижнем меню. Меньше трёх — выглядит странно, больше пяти — иконки становятся слишком мелкими, а некоторые могут уйти в раздел «Ещё».

💡 Совет: подписи под иконками — обязательны. Иконки без подписей пользователю непонятны, если он не знает приложение.

💡 Совет: используй BottomNavigationView для главных разделов приложения, а вкладки (TabLayout) — для второстепенных внутри одного раздела.

❌ Частая ошибка: добавить BottomNavigationView без меню. Компонент появится пустой полосой без иконок — потому что не указан файл меню.
