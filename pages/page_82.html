ListView — вертикальный список

ListView — вертикальный список элементов. Классический компонент Android для отображения однотипных строк: названий, сообщений, контактов, настроек. Каждый элемент — отдельная строка, которую можно нажать.

Иконка в палитре — прямоугольник с несколькими горизонтальными полосами.

Как работает

  • Отображает список элементов сверху вниз.
  • Каждый элемент — строка с текстом (или с текстом и иконкой, в зависимости от адаптера).
  • Прокручивается вертикально, если элементы не помещаются на экран.
  • Создаёт только видимые элементы — для сотен строк это работает быстро.
  • Реагирует на тап по элементу — событие onItemClick.
  • Может быть привязан к массиву данных или к базе данных (SQLite, Firebase).

Когда использовать

  • Список контактов — имя и телефон.
  • Список сообщений — чат или SMS.
  • Меню настроек — пункты с иконками.
  • Список покупок — задачи или товары.
  • Результаты поиска — строки с совпадениями.
  • Любой однотипный вертикальный список.

Основные свойства

  • Adapter — задаётся в логике, не в свойствах.
  • Divider — цвет или изображение разделителя между строками.
  • DividerHeight — высота разделителя (в dp).
  • ChoiceMode — режим выбора: none, singleChoice, multipleChoice.
  • Background — цвет фона списка.
  • Scrollbars — показывать ли полосу прокрутки.
  • Width / Height — match_parent по ширине, обычно match_parent и по высоте.
  • Padding / Margin — внутренние и внешние отступы.

Как добавить

  • Выбери контейнер, куда хочешь положить список. Чаще всего — корневой Linear(V) или RelativeLayout.
  • Тап по ListView в палитре — компонент добавится внутрь.
  • Присвой id — без него логика не сможет обратиться к списку.
  • Открой вкладку «События» и добавь в onCreate:
    • блок setListData — простой способ задать список строк;
    • или блок setAdapter — для более сложного адаптера с картинками и форматированием.
  • Добавь событие onItemClick — реакцию на тап по элементу.

⚠️ Важно: без адаптера в логике ListView отображается как пустая область. Просто добавить в разметку недостаточно.

⚠️ Важно: ListView не вкладывается в Scroll(V). У него собственная прокрутка, и вместе с прокруткой родителя возникает конфликт. Если нужен список внутри прокручиваемого экрана — используй RecyclerView с NestedScrollView.

⚠️ Важно: ListView устарел в современном Android. Google рекомендует использовать RecyclerView. Однако в Sketchware Pro 7 ListView проще в настройке, и для многих задач его достаточно.

💡 Совет: для простого списка (только текст) используй блок setListData с массивом строк. Это самый быстрый способ сделать рабочий список.

💡 Совет: для списка с иконками или карточками создай свой Layout (элемент списка) в Дизайнере и подключи его как адаптер. Это требует больше шагов, но даёт полный контроль над видом.

💡 Совет: для выбора одного элемента из списка используй ChoiceMode = singleChoice. Sketchware покажет радиокнопки справа от каждой строки.

💡 Совет: задавай DividerHeight = 1dp для тонкой разделительной линии. Без разделителя элементы сливаются и плохо читаются.

❌ Частая ошибка: добавить ListView и ждать, что он покажет данные. Без логики — он пустой.

❌ Частая ошибка: оборачивать ListView в Scroll(V). Прокрутка работает нестабильно: список либо не прокручивается, либо ведёт себя странно.
