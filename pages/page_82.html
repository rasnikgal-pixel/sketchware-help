ListView — вертикальный список

ListView — вертикальный список элементов. Классический компонент Android для отображения однотипных строк: названий, сообщений, контактов, настроек. Каждый элемент — отдельная строка, которую можно нажать.

Иконка в палитре — прямоугольник с несколькими горизонтальными полосами.

Как работает

  • Отображает список элементов сверху вниз.
  • Каждый элемент — строка с текстом (или с текстом и иконкой, в зависимости от адаптера).
  • Прокручивается вертикально, если элементы не помещаются на экран.
  • Создаёт только видимые элементы — для сотен строк это работает быстро.
  • Реагирует на тап по элементу — событие onItemClick.
  • Может быть привязан к массиву данных или к базе данных (SQLite, Firebase).

Когда использовать

  • Список контактов — имя и телефон.
  • Список сообщений — чат или SMS.
  • Меню настроек — пункты с иконками.
  • Список покупок — задачи или товары.
  • Результаты поиска — строки с совпадениями.
  • Любой однотипный вертикальный список.

Настройки

Настройка Что делает Значения
Adapter Связывает данные со списком. Задаётся в логике. ArrayAdapter, CustomAdapter.
Divider Цвет или изображение разделителя между строками. HEX или drawable-ресурс.
DividerHeight Высота разделителя. Число в dp. По умолчанию — 1dp.
ChoiceMode Режим выбора элемента. none, singleChoice, multipleChoice.
Background Цвет фона списка. HEX или drawable-ресурс.
Scrollbars Показывать ли полосу прокрутки. Переключатель: вкл / выкл.
Width / Height Ширина и высота. match_parent по ширине, обычно match_parent и по высоте.
Padding / Margin Внутренние и внешние отступы. Число в dp для каждой стороны.

Свойства виджета

Основные

Конвертировать Показывает тип виджета — ListView. Обычно менять не нужно. ListView и другие типы виджетов. Оставь как есть.
Высота разделителя
Divider height		 Высота разделительной линии между строками. Число в dp. По умолчанию — 1dp. 1dp — тонкая линия; 8dp — воздух между строками.
Пользовательский вид

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет список по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent — стандарт для списка.
Высота
Height		 Насколько высоким будет список по вертикали. match_parent, wrap_content, число в dp. match_parent — чтобы список занимал весь экран.
Внутренний отступ
Padding		 Отступ внутри виджета. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 8 со всех сторон.
Внешний отступ
Margin		 Отступ снаружи виджета — от него до соседних элементов. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Обычно 0 — список занимает всё свободное место.
Гравитация макета
Layout gravity		 Как виджет выравнивается внутри родителя. none — по умолчанию;
например, center_horizontal.		 Обычно оставляют none.
Вес
Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — список заберёт всё оставшееся место.

💡 Совет для новичков: ключевые настройки ListView — Высота разделителя, Пользовательский вид, Цвет фона. Данные подключаются в логике — через блоки setListData или setAdapter.

Как перетащить ListView на макет

ListView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V) или RelativeLayout. Чаще всего список — единственный элемент на экране.
  3. Раскрой категорию Списки в палитре слева.
  4. Зажми ListView и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — список появится в разметке.
  6. Присвой осмысленный ID — без него логика не сможет обратиться к списку.
  7. Открой вкладку «События» и добавь в onCreate:
    • блок setListData — простой способ задать список строк;
    • или блок setAdapter — для более сложного адаптера с картинками и форматированием.
  8. Добавь событие onItemClick — реакцию на тап по элементу.
⚠️ Важно: обычный тап по ListView в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: без адаптера в логике ListView отображается как пустая область. Просто добавить в разметку недостаточно.
⚠️ Важно: ListView не вкладывается в Scroll(V). У него собственная прокрутка, и вместе с прокруткой родителя возникает конфликт. Если нужен список внутри прокручиваемого экрана — используй RecyclerView с NestedScrollView.
⚠️ Важно: ListView устарел в современном Android. Google рекомендует использовать RecyclerView. Однако в Sketchware Pro 7 ListView проще в настройке, и для многих задач его достаточно.
💡 Совет: для простого списка (только текст) используй блок setListData с массивом строк. Это самый быстрый способ сделать рабочий список.
💡 Совет: для списка с иконками или карточками создай свой Layout (элемент списка) в Дизайнере и подключи его как адаптер. Это требует больше шагов, но даёт полный контроль над видом.
💡 Совет: для выбора одного элемента из списка используй ChoiceMode = singleChoice. Sketchware покажет радиокнопки справа от каждой строки.
💡 Совет: задавай DividerHeight = 1dp для тонкой разделительной линии. Без разделителя элементы сливаются и плохо читаются.
❌ Частая ошибка: перетащить ListView и ждать, что он покажет данные. Без логики — он пустой.
❌ Частая ошибка: оборачивать ListView в Scroll(V). Прокрутка работает нестабильно: список либо не прокручивается, либо ведёт себя странно.

Резюме

  • ListView — вертикальный список однотипных строк.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Работает только через адаптер, задаваемый в логике (setListData или setAdapter).
  • Без логики остаётся пустой областью.
  • Ключевые свойства: Высота разделителя, Пользовательский вид, ChoiceMode.
  • Не вкладывай ListView в Scroll(V) — прокрутка конфликтует.
  • Для простых списков ListView проще, чем RecyclerView; для сложных — RecyclerView предпочтительнее.
  • Событие onItemClick — реакция на тап по элементу.

Частые ошибки новичков

  • Тапают по ListView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетащили список, но не подключили адаптер. Область пустая.
  • Ищут содержимое списка в свойствах. Данные задаются только в логике.
  • Вкладывают ListView в Scroll(V). Прокрутка не работает — конфликт двух скроллов.
  • Используют ListView для сложных карточек. Лучше подходит RecyclerView.
  • Не задают ID. Логика не может обратиться к списку.
  • Не добавляют onItemClick. Тап по элементу ничего не делает.
