LottieAnimation — JSON-анимация

LottieAnimation — виджет для воспроизведения векторных анимаций в формате Lottie. Это JSON-файл, созданный в Adobe After Effects с плагином Bodymovin. Анимация выглядит как видео, но весит в разы меньше и масштабируется без потери качества.

Иконка в палитре — прямоугольник с воспроизводимой анимацией.

Как работает

  • Отображает анимацию из JSON-файла, подключённого к проекту.
  • Анимация может проигрываться автоматически или запускаться в логике по кнопке.
  • Может зацикливаться (повторяться бесконечно) или проиграться один раз.
  • Может менять скорость, направление, положение внутри виджета.
  • Как и любая векторная графика, не теряет качество при увеличении.

Когда использовать

  • Онбординг — красивые анимированные экраны знакомства с приложением.
  • Индикаторы загрузки — креативные спиннеры вместо стандартных.
  • Пустые состояния — «Нет данных», «Ничего не найдено» — с анимацией.
  • Иконки-кнопки — например, анимированное «сердце» при лайке.
  • Праздничные эффекты — при достижении цели или победы.
  • Заставка при запуске — короткая анимация логотипа.

Основные свойства

  • LottieFile — путь к JSON-файлу анимации (загружается через Менеджер ресурсов).
  • AutoPlay — начинать воспроизведение сразу при появлении на экране.
  • Loop — повторять бесконечно.
  • Speed — скорость воспроизведения (1.0 — норма, 0.5 — медленнее, 2.0 — быстрее).
  • ScaleType — как вписывать анимацию в размеры виджета: fitCenter, centerCrop, fitXY.
  • Width / Height — размеры виджета.
  • Background — фон позади анимации.

Как добавить

  • Сначала скачай JSON-файл анимации. Источники: lottiefiles.com, lottiefiles.com/featured, или экспорт из After Effects с плагином Bodymovin.
  • Загрузи JSON через Менеджер ресурсов — он должен оказаться в проекте.
  • Выбери контейнер, куда хочешь положить анимацию.
  • Тап по LottieAnimation в палитре — виджет добавится внутрь.
  • В свойствах укажи LottieFile — выбери загруженный JSON.
  • Задай AutoPlay, Loop и Speed.
  • Присвой id — если хочешь управлять из логики (пауза, стоп, воспроизведение заново).
  • В событиях используй блоки: playAnimation, pauseAnimation, cancelAnimation, setSpeed.

⚠️ Важно: JSON-файл должен быть правильно загружен в проект. Если файл повреждён или в неправильном формате — анимация не отобразится.

⚠️ Важно: AutoPlay = true запускает анимацию сразу при появлении экрана. Если анимация длинная и зацикленная — это может раздражать пользователя. Для фоновых анимаций лучше AutoPlay = false и запуск по событию.

⚠️ Важно: Lottie-анимации требуют ресурсов при воспроизведении. Если у тебя 10 таких виджетов на одном экране — приложение будет тормозить. Оптимально — 1–2 крупные анимации на экран.

💡 Совет: для индикатора загрузки используй короткую (1–2 секунды) зацикленную анимацию. Так пользователь видит, что приложение работает.

💡 Совет: для онбординга используй разные анимации на каждой странице ViewPager. Это создаёт ощущение качества.

💡 Совет: источник бесплатных Lottie-анимаций — lottiefiles.com. Там тысячи готовых JSON-файлов бесплатно. Скачивай JSON и загружай в Менеджер ресурсов.

💡 Совет: не используй Lottie для фоновых видео. Для сложных анимаций (многослойных, с эффектами) Lottie будет тормозить. Здесь лучше подходит обычное видео, но оно весит больше.

❌ Частая ошибка: добавлять LottieAnimation без загруженного JSON. Виджет пустой, пользователь не понимает, почему.

❌ Частая ошибка: включать Loop = true для длинной анимации, которая должна проиграть один раз. Она будет крутиться бесконечно и раздражать.

❌ Частая ошибка: ставить 10+ Lottie-анимаций на один экран. Приложение будет заметно тормозить.

❌ Частая ошибка: использовать видео-файлы вместо Lottie. JSON-анимация весит в разы меньше и масштабируется без потери качества.
