LottieAnimation — JSON-анимация

LottieAnimation — виджет для воспроизведения векторных анимаций в формате Lottie. Это JSON-файл, созданный в Adobe After Effects с плагином Bodymovin. Анимация выглядит как видео, но весит в разы меньше и масштабируется без потери качества.

Иконка в палитре — прямоугольник с воспроизводимой анимацией.

Как работает

  • Отображает анимацию из JSON-файла, подключённого к проекту.
  • Анимация может проигрываться автоматически или запускаться в логике по кнопке.
  • Может зацикливаться (повторяться бесконечно) или проиграться один раз.
  • Может менять скорость, направление, положение внутри виджета.
  • Как и любая векторная графика, не теряет качество при увеличении.

Когда использовать

  • Онбординг — красивые анимированные экраны знакомства с приложением.
  • Индикаторы загрузки — креативные спиннеры вместо стандартных.
  • Пустые состояния — «Нет данных», «Ничего не найдено» — с анимацией.
  • Иконки-кнопки — например, анимированное «сердце» при лайке.
  • Праздничные эффекты — при достижении цели или победы.
  • Заставка при запуске — короткая анимация логотипа.

Настройки

Настройка Что делает Значения
LottieFile Путь к JSON-файлу анимации (загружается через Менеджер ресурсов). Имя загруженного JSON-файла.
AutoPlay Начинать воспроизведение сразу при появлении на экране. Переключатель: вкл / выкл.
Loop Повторять бесконечно. Переключатель: вкл / выкл.
Speed Скорость воспроизведения. 1.0 — норма;
0.5 — медленнее;
2.0 — быстрее.
ScaleType Как вписывать анимацию в размеры виджета. fitCenter, centerCrop, fitXY.
Width / Height Размеры виджета. match_parent или wrap_content.
Background Фон позади анимации. HEX или drawable-ресурс.

Свойства виджета

Открой панель свойств, тапнув по LottieAnimation в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — lottie1).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — lottie1, lottie2 и т. д. Переименуй в loadingAnimation, если это спиннер загрузки.
Пользовательские атрибуты Дополнительные XML-атрибуты. Здесь задаётся ScaleType и привязка в RelativeLayout. Пары «атрибут = значение». На скриншоте заданы android:scaleType="fitCenter" и android:layout_centerInParent="true".
Конвертировать Показывает полный класс компонента: com.airbnb.lottie.LottieAnimationView. LottieAnimationView и другие типы виджетов. Оставь как есть.

💡 Совет для новичков: ключевые настройки (LottieFile, AutoPlay, Loop, Speed) задаются в логике через блоки: setAnimation, playAnimation, setRepeatCount, setSpeed. В панели свойств доступны только базовые параметры и ScaleType через «Пользовательские атрибуты».

Как перетащить LottieAnimation на макет

LottieAnimation, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Сначала скачай JSON-файл анимации. Источники: lottiefiles.com или экспорт из After Effects с плагином Bodymovin.
  2. Загрузи JSON через Менеджер ресурсов — он должен оказаться в проекте.
  3. Открой вкладку «Дизайнер».
  4. Убедись, что на макете уже есть контейнер — Linear(V) или RelativeLayout.
  5. Раскрой категорию Библиотеки в палитре слева.
  6. Зажми LottieAnimation и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  7. Отпусти в нужном месте — анимация появится в разметке.
  8. Через Пользовательские атрибуты задай android:scaleType="fitCenter" и при необходимости привязку в RelativeLayout.
  9. Присвой осмысленный ID — он нужен для логики.
  10. Открой вкладку «События» и добавь в onCreate:
    • блок setAnimation — задать JSON-файл;
    • блок playAnimation — запустить воспроизведение;
    • блок setRepeatCount — задать количество повторов или бесконечность;
    • блок setSpeed — задать скорость.
⚠️ Важно: обычный тап по LottieAnimation в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: JSON-файл должен быть правильно загружен в проект. Если файл повреждён или в неправильном формате — анимация не отобразится.
⚠️ Важно: AutoPlay = true запускает анимацию сразу при появлении экрана. Если анимация длинная и зацикленная — это может раздражать пользователя. Для фоновых анимаций лучше AutoPlay = false и запуск по событию.
⚠️ Важно: Lottie-анимации требуют ресурсов при воспроизведении. Если у тебя 10 таких виджетов на одном экране — приложение будет тормозить. Оптимально — 1–2 крупные анимации на экран.
💡 Совет: для индикатора загрузки используй короткую (1–2 секунды) зацикленную анимацию. Так пользователь видит, что приложение работает.
💡 Совет: для онбординга используй разные анимации на каждой странице ViewPager. Это создаёт ощущение качества.
💡 Совет: источник бесплатных Lottie-анимаций — lottiefiles.com. Там тысячи готовых JSON-файлов бесплатно. Скачивай JSON и загружай в Менеджер ресурсов.
💡 Совет: не используй Lottie для фоновых видео. Для сложных анимаций (многослойных, с эффектами) Lottie будет тормозить. Здесь лучше подходит обычное видео, но оно весит больше.
❌ Частая ошибка: перетащить LottieAnimation без загруженного JSON. Виджет пустой, пользователь не понимает, почему.
❌ Частая ошибка: включать Loop = true для длинной анимации, которая должна проиграть один раз. Она будет крутиться бесконечно и раздражать.
❌ Частая ошибка: ставить 10+ Lottie-анимаций на один экран. Приложение будет заметно тормозить.
❌ Частая ошибка: использовать видео-файлы вместо Lottie. JSON-анимация весит в разы меньше и масштабируется без потери качества.

Резюме

  • LottieAnimation — виджет для воспроизведения векторных JSON-анимаций.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Требует загруженный JSON-файл анимации в Менеджере ресурсов.
  • Управление (play, pause, repeat, speed) — через логику.
  • ScaleType задаётся через Пользовательские атрибуты — android:scaleType.
  • Источник бесплатных анимаций — lottiefiles.com.
  • Ограничивай количество анимаций на экране — 1–2 крупные, иначе тормоза.
  • Для длинной одноразовой анимации не включай Loop.

Частые ошибки новичков

  • Тапают по LottieAnimation в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Не загружают JSON-файл. Анимация пустая.
  • Забывают запустить анимацию в логике. AutoPlay по умолчанию может быть выключен.
  • Ставят Loop = true на одноразовую анимацию. Раздражает пользователя.
  • Перетаскивают 10+ анимаций на один экран. Приложение тормозит.
  • Ищут файл анимации в обычных свойствах. Файл подключается через логику и Менеджер ресурсов.
  • Не задают ID. Логика не может обратиться к виджету.
