Менеджер представлений

Менеджер представлений — раздел меню «Настройка», через который управляются экраны приложения. Здесь создаются новые Activity, Fragment, DialogFragment, удаляются ненужные, переключаются между ними.

Представление (View) в Sketchware — это то же, что экран или Activity. Каждое представление — отдельный экран приложения со своей разметкой (XML) и логикой (Java).

Иконка в меню — прямоугольник с окном.

Что можно делать

  • Создавать новые экраны.
  • Удалять ненужные.
  • Переименовывать существующие.
  • Переключаться между экранами.
  • Просматривать список всех экранов проекта.
  • Выбирать тип — Activity, Fragment, DialogFragment.

Типы представлений

Тип Что это Когда использовать
Активность (Activity) Полноценный экран приложения. Открывается через Intent. Основной тип. Основные экраны: главный, настройки, профиль.
Fragment Часть экрана. Используется внутри Activity, обычно с ViewPager или TabLayout. Вкладки, слайды, разделы одного экрана.
DialogFragment Всплывающее окно в стиле диалога. Похож на Activity, но показывается поверх другой. Подтверждения, сложные диалоги с формой.
BottomSheetDialogFragment Всплывающая панель снизу. Современный формат для выбора, дополнительных действий. Меню опций, выбор действия, дополнительная информация.

Как создать новый экран

  1. Открой меню ⋮ → Менеджер представлений.
  2. Нажми «+ Создать новый view» или аналогичную кнопку.
  3. Откроется форма создания:
    • Превью макета слева — схема с элементами.
    • Чекбоксы: StatusBar, Toolbar, Drawer, FAB.
    • Поле «Введите имя» — имя нового экрана.
    • Тип: Активность, Fragment, DialogFragment, BottomSheetDialogFragment.
    • Ориентация экрана: Портретная, Альбомная, Оба.
    • Настройки клавиатуры: Не указано, Видимый, Скрытый.
  4. Заполни параметры.
  5. Нажми «Сохранить» — экран появится в списке.

Как удалить экран

  1. Открой Менеджер представлений.
  2. Найди нужный экран.
  3. Используй контекстное меню (долгое нажатие или кнопка) → «Удалить».
  4. Подтверди удаление.
⚠️ Важно: нельзя удалить MainActivity. Это первый экран приложения, он создаётся автоматически и всегда нужен.
⚠️ Важно: при удалении экрана удаляются и его разметка, и логика, и все связанные ресурсы. Восстановить их нельзя.
⚠️ Важно: имя экрана используется в коде и при переходах через Intent. Не переименовывай без необходимости — придётся менять все ссылки.
⚠️ Важно: Fragment нельзя открыть через Intent. Он используется только внутри Activity. Если попытаться — приложение упадёт.
💡 Совет: для основных экранов используй Активность (Activity). Для вкладок и слайдов — Fragment. Для всплывающих окон — DialogFragment.
💡 Совет: не создавай много экранов заранее. Добавляй по мере необходимости. С каждым экраном проект растёт, становится сложнее.
💡 Совет: для онбординга используй Fragment + ViewPager. Три-пять фрагментов — оптимально.
💡 Совет: для настроек используй отдельную Activity. Это классический паттерн Android.
💡 Совет: для подтверждений используй Dialog (компонент), а не DialogFragment. Диалог проще и легче.
❌ Частая ошибка: путать Activity и Fragment. Activity — самостоятельный экран, Fragment — часть экрана.
❌ Частая ошибка: удалять экраны, не проверив, где они используются. Приложение перестаёт собираться.
❌ Частая ошибка: создавать десятки экранов заранее. Проект становится запутанным.
❌ Частая ошибка: переименовывать экраны без обновления ссылок в логике. Переходы через Intent ломаются.
❌ Частая ошибка: пытаться открыть Fragment через Intent. Так нельзя.

Резюме

  • Менеджер представлений — раздел меню «Настройка» для управления экранами.
  • Позволяет создавать, удалять, переименовывать экраны.
  • Четыре типа: Activity, Fragment, DialogFragment, BottomSheetDialogFragment.
  • MainActivity удалить нельзя — это первый экран приложения.
  • При удалении экрана удаляются и разметка, и логика.
  • Fragment нельзя открыть через Intent — только внутри Activity.
  • Не создавай много экранов заранее — по мере необходимости.
  • Переименование требует обновления всех ссылок в логике.

Частые ошибки новичков

  • Путают Activity и Fragment. Разные уровни вложенности.
  • Удаляют используемые экраны. Проект не собирается.
  • Создают десятки экранов. Проект становится сложным.
  • Переименовывают без обновления ссылок. Переходы ломаются.
  • Пытаются открыть Fragment через Intent. Приложение падает.
  • Удаляют MainActivity. Так нельзя.
  • Используют DialogFragment для простых диалогов. Избыточно — хватит Dialog.
