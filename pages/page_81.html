Категория Списки

Списки — четвёртая категория в палитре виджетов. В ней собраны компоненты для отображения множества однотипных элементов: строк, плиток, карточек, страниц. Вместо того чтобы вручную добавлять сотню TextView друг под другом, ты используешь один компонент-список, а данные подставляешь в логике.

Это ключевая категория для приложений с лентами, каталогами, чатами, новостями, настройками — всем, где содержимое представлено повторяющимися блоками.

Из чего состоит категория

В категории Списки пять компонентов:

  • ListView — вертикальный список строк. Классический компонент для отображения простых списков.
  • GridView — сетка элементов. Раскладывает содержимое по колонкам и строкам.
  • RecyclerView — современный список с гибкой настройкой. Замена ListView в новых приложениях.
  • Spinner — выпадающий список. Пользователь тапает — открывается меню с вариантами.
  • ViewPager — горизонтальная прокрутка страниц. Используется для свайпа между экранами.

Зачем нужны списки

  • Производительность. Список создаёт только видимые элементы, а остальные «подгружает» по мере прокрутки. Сотни TextView так не работают.
  • Динамические данные. Содержимое задаётся в логике — из базы, из сети, из файла.
  • Единый шаблон. Все элементы списка выглядят одинаково — меняется только содержимое.
  • Реакция на тапы. У списков есть встроенные события: onItemClick, onItemSelected.

Что важно понимать

  • Все компоненты этой категории работают только вместе с логикой. Без настройки адаптера список будет пустым.
  • Adapter (адаптер) — посредник между данными и списком. Он превращает массив данных в строки/плитки/карточки.
  • У каждого компонента свой адаптер: у ListView — ArrayAdapter, у RecyclerView — RecyclerView.Adapter.
  • Элементы списка не задаются в Дизайнере — они формируются в логике через шаблон (Layout) или стандартный вид Android.

⚠️ Важно: для большинства списков нужна логика. Просто добавить ListView в разметку недостаточно — он будет пустым, пока в него не загрузят данные.

💡 Совет: для простых списков (одна строка текста) используй ListView — минимум логики. Для сложных карточек — RecyclerView. Для сетки — GridView. Для выбора одного варианта — Spinner.

❌ Частая ошибка: добавлять ListView и RecyclerView на один и тот же экран. Они конфликтуют по прокрутке и мешают друг другу.
