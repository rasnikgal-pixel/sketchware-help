AutoCompleteTextView — автоподсказки

AutoCompleteTextView — поле ввода с автодополнением. Работает как обычный EditText, но по мере ввода показывает выпадающий список подсказок — вариантов, которые начинаются с введённых символов.

Иконка в палитре — поле с треугольником-выпадающим списком справа.

Как работает

  • Пользователь начинает вводить текст.
  • Sketchware сверяет введённые символы со списком подсказок, который ты задал.
  • Под полем появляется выпадающий список — варианты, подходящие под ввод.
  • Пользователь может тапнуть по подсказке — и она автоматически подставится в поле.
  • Можно продолжать вводить текст вручную, не выбирая подсказку.

Когда использовать

  • Поиск города — «Мо…» → «Москва», «Мурманск».
  • Выбор страны — из длинного списка.
  • Ввод email — подсказки популярных доменов (@gmail.com, @yandex.ru).
  • Выбор категории — когда вариантов много, но вводить не обязательно.
  • Формы с историческими данными — например, часто вводимые имена.

Из чего состоит

  • AutoCompleteTextView — само поле.
  • Список подсказок — массив строк, который задаётся в логике через блок setAdapter или setSimpleItems.
  • Выпадающий список — появляется автоматически при вводе.

Основные свойства

  • Hint — подсказка внутри поля.
  • Text — начальное значение.
  • InputType — тип ввода.
  • TextColor / TextSize — цвет и размер текста.
  • Threshold — минимальное число символов, после которого начинается автодополнение (обычно 1 или 2).
  • DropDownWidth — ширина выпадающего списка.
  • DropDownBackground — цвет фона списка.
  • Width / Height — match_parent или wrap_content.

Как добавить

  • Выбери контейнер, в который хочешь положить поле.
  • Тап по AutoCompleteTextView в палитре — виджет добавится внутрь.
  • Задай Hint и Threshold в свойствах.
  • Присвой виджету id — он понадобится в логике.
  • Открой вкладку «События» и добавь логику: блок setSimpleItems для этого виджета — в него впиши список подсказок.
  • Для события onTextChanged можно задавать логику, если нужно фильтровать список вручную.

⚠️ Важно: без указания списка подсказок в логике виджет будет выглядеть как обычный EditText. Автодополнение не появится само по себе.

⚠️ Важно: список подсказок задаётся в логике, а не в свойствах виджета. В Дизайнере ты только настраиваешь внешний вид — а сами данные для подсказок подставляешь в событиях.

💡 Совет: для списка городов, стран или email-доменов используй блок setSimpleItems — там можно перечислить до 20–30 вариантов через запятую.

💡 Совет: если подсказок очень много (например, база на тысячи записей) — используй ListView + фильтрация в логике. AutoCompleteTextView рассчитан на небольшой список.

💡 Совет: для выбора одного из фиксированного списка (когда пользователь не должен вводить своё) — используй Spinner, а не AutoCompleteTextView. Спиннер запрещает ввод произвольного текста.

❌ Частая ошибка: ждать, что автодополнение появится без настройки списка. Виджет молчит, потому что не знает, какие варианты показывать.

❌ Частая ошибка: использовать AutoCompleteTextView для одного конкретного выбора из списка. Для этой задачи подходит Spinner — он лучше и удобнее.
