AutoCompleteTextView — автоподсказки

AutoCompleteTextView — поле ввода с автодополнением. Работает как обычный EditText, но по мере ввода показывает выпадающий список подсказок — вариантов, которые начинаются с введённых символов.

Иконка в палитре — поле с треугольником-выпадающим списком справа.

Как работает

  • Пользователь начинает вводить текст.
  • Sketchware сверяет введённые символы со списком подсказок, который ты задал.
  • Под полем появляется выпадающий список — варианты, подходящие под ввод.
  • Пользователь может тапнуть по подсказке — и она автоматически подставится в поле.
  • Можно продолжать вводить текст вручную, не выбирая подсказку.

Когда использовать

  • Поиск города — «Мо…» → «Москва», «Мурманск».
  • Выбор страны — из длинного списка.
  • Ввод email — подсказки популярных доменов (@gmail.com, @yandex.ru).
  • Выбор категории — когда вариантов много, но вводить не обязательно.
  • Формы с историческими данными — например, часто вводимые имена.

Из чего состоит

  • AutoCompleteTextView — само поле.
  • Список подсказок — массив строк, который задаётся в логике через блок setAdapter или setSimpleItems.
  • Выпадающий список — появляется автоматически при вводе.

Настройки

Настройка Что делает Значения
Hint Подсказка внутри поля. Любая строка.
Text Начальное значение. Любая строка.
InputType Тип ввода. text, number, textEmailAddress, phone и другие.
TextColor / TextSize Цвет и размер текста. HEX, число в sp.
Threshold Минимальное число символов, после которого начинается автодополнение. Число. Обычно 1 или 2.
DropDownWidth Ширина выпадающего списка. Число в dp.
DropDownBackground Цвет фона списка. HEX или выбор из палитры.
Width / Height Ширина и высота. match_parent или wrap_content.

Как перетащить AutoCompleteTextView на макет

AutoCompleteTextView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V), Linear(H) или RelativeLayout.
  3. Раскрой категорию Widgets в палитре слева.
  4. Зажми AutoCompleteTextView и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — поле появится в разметке.
  6. Тапни по нему и задай Подсказку и Порог.
  7. Присвой осмысленный ID — он понадобится для логики.
  8. Открой вкладку «События» и в блоке onCreate добавь блок setSimpleItems для этого виджета — в него впиши список подсказок.
  9. Для события onTextChanged можно задать логику, если нужно фильтровать список вручную.
⚠️ Важно: обычный тап по AutoCompleteTextView в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: без указания списка подсказок в логике виджет будет выглядеть как обычный EditText. Автодополнение не появится само по себе.
⚠️ Важно: список подсказок задаётся в логике, а не в свойствах виджета. В Дизайнере ты только настраиваешь внешний вид — а сами данные для подсказок подставляешь в событиях.
💡 Совет: для списка городов, стран или email-доменов используй блок setSimpleItems — там можно перечислить до 20–30 вариантов через запятую.
💡 Совет: если подсказок очень много (например, база на тысячи записей) — используй ListView + фильтрация в логике. AutoCompleteTextView рассчитан на небольшой список.
💡 Совет: для выбора одного из фиксированного списка (когда пользователь не должен вводить своё) — используй Spinner, а не AutoCompleteTextView. Спиннер запрещает ввод произвольного текста.
❌ Частая ошибка: ждать, что автодополнение появится без настройки списка. Виджет молчит, потому что не знает, какие варианты показывать.
❌ Частая ошибка: использовать AutoCompleteTextView для одного конкретного выбора из списка. Для этой задачи подходит Spinner — он лучше и удобнее.

Резюме

  • AutoCompleteTextView — поле ввода с автодополнением по мере ввода.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • В панели свойств задаётся только внешний вид (Подсказка, Цвет подсказки, размер текста и т. д.).
  • Список подсказок задаётся в логике — через блок setSimpleItems или setAdapter.
  • Есть свойство Порог — сколько символов нужно ввести, чтобы появились подсказки.
  • Для выбора из фиксированного списка лучше использовать Spinner, а не это поле.
  • Для больших списков (сотни и тысячи записей) используйте ListView + фильтрацию.

Частые ошибки новичков

  • Тапают по AutoCompleteTextView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Ждут автодополнения без настройки списка. Виджет выглядит как обычный EditText, потому что не знает вариантов.
  • Ищут список подсказок в свойствах. Его задают только в логике через setSimpleItems.
  • Используют для одного конкретного выбора. Нужен Spinner.
  • Пытаются загрузить тысячи вариантов. Виджет рассчитан на небольшой список.
  • Не задают ID. В логике невозможно привязать список подсказок к полю.
  • Путают с EditText. Внешне похожи, но AutoCompleteTextView работает с выпадающим списком.
