Timer — таймер

Timer — компонент для работы с таймером. Позволяет выполнять действия через определённые интервалы времени или через заданную задержку. Используется для отсчёта, обновления интерфейса, повторяющихся задач.

Иконка в диалоге добавления — часы с секундной стрелкой.

Как работает

  • Запускает отсчёт времени с заданным интервалом.
  • Может повторяться (например, каждые 1000 мс) или сработать один раз.
  • На каждом «тике» срабатывает событие onTimerTick — там описывается, что делать.
  • При завершении срабатывает событие onTimerFinished.
  • Может быть остановлен вручную через блок cancel или stop.

Когда использовать

  • Обратный отсчёт — «Осталось 30 секунд».
  • Секундомер — увеличение счётчика каждую секунду.
  • Периодическое обновление — обновление данных каждые N секунд.
  • Анимация — смена кадров через равные интервалы.
  • Напоминания — «Показать сообщение через 5 секунд».
  • Игровой цикл — обновление состояния игры.
  • Имитация загрузки — показ прогресса через интервалы.

Настройки при добавлении

Настройка Что задаёт Пример
Имя компонента Идентификатор для вызова в логике. timer1, myTimer.
Interval Интервал срабатывания в миллисекундах. 1000 мс = 1 секунда.
Repeat Повторять ли таймер или сработать один раз. true — повторять; false — один раз.

Основные блоки в логике

Блок Что делает
start Запустить таймер.
cancel Остановить таймер.
pause / resume Пауза и продолжение (в некоторых версиях).

События таймера

Событие Когда срабатывает
onTimerTick Срабатывает каждый интервал. Основное событие для логики.
onTimerFinished Срабатывает при завершении (если Repeat = false).

Как использовать

  1. Подключи компонент Timer на вкладке «Компонент».
  2. Задай имя — например, myTimer.
  3. Задай Interval — например, 1000 для одной секунды.
  4. Задай Repeat — true, если таймер должен идти, пока не остановишь.
  5. В категории «Компонент» вкладки «События» добавь событие onTimerTick для этого таймера.
  6. Внутри onTimerTick опиши логику: увеличь счётчик, обнови TextView, проверь условия остановки.

Пример: секундомер

  • В onCreate инициализируй переменную seconds = 0.
  • В onClick кнопки «Старт» вызови myTimer.start().
  • В onTimerTick:
    • увеличь seconds на 1;
    • установи в TextView значение seconds;
    • если seconds >= 60, останови таймер: myTimer.cancel().
⚠️ Важно: интервал измеряется в миллисекундах. 1000 — это 1 секунда, а не 1 миллисекунда. Частая путаница.
⚠️ Важно: Timer работает, пока приложение активно. При сворачивании или закрытии он останавливается. Для работы в фоне нужен AlarmManager или ForegroundService — но они сложнее и требуют дополнительных разрешений.
⚠️ Важно: не делай интервал слишком маленьким (например, 10 мс). Это перегружает устройство и быстро разряжает батарею.
⚠️ Важно: не забывай останавливать таймер, когда он больше не нужен. Иначе он продолжит работать впустую.
⚠️ Важно: логика внутри onTimerTick должна быть быстрой. Если она занимает больше времени, чем интервал — таймер будет «догонять» и создавать очередь.
💡 Совет: для обратного отсчёта заведи переменную с числом секунд. В каждом тике уменьшай её на 1 и обновляй TextView. При нуле — останови таймер и выполни действие.
💡 Совет: для секундомера — наоборот, увеличивай переменную. Обновляй TextView каждую секунду.
💡 Совет: для анимации используй интервал 16 мс (это ~60 кадров в секунду). Но помни, что для плавной анимации лучше использовать ObjectAnimator, а не Timer.
💡 Совет: для периодического обновления данных с сервера используй интервал 10 000–60 000 мс (10–60 секунд). Не чаще — иначе устройство будет перегружено.
💡 Совет: останавливай таймер в onPause или onStop, чтобы он не работал, когда пользователь ушёл с экрана.
❌ Частая ошибка: путать единицы измерения. Interval = 1 — это 1 миллисекунда, а не 1 секунда. Таймер сработает слишком быстро.
❌ Частая ошибка: не останавливать таймер. Он продолжает срабатывать, обновляя интерфейс, даже когда это не нужно.
❌ Частая ошибка: слишком маленький интервал. Устройство перегружается, батарея садится.
❌ Частая ошибка: тяжёлая логика в onTimerTick. Таймер не успевает, срабатывания «наслаиваются».
❌ Частая ошибка: ожидать, что таймер работает в фоне. Timer останавливается при сворачивании приложения.

Резюме

  • Timer — компонент для периодических действий и отсчёта времени.
  • Основные настройки: Interval (мс), Repeat (да / нет).
  • Основные блоки: start, cancel, pause / resume.
  • Основное событие — onTimerTick, срабатывает каждый интервал.
  • Событие onTimerFinished — при завершении, если Repeat = false.
  • Работает только пока приложение активно.
  • Не делай слишком маленький интервал — устройство перегружается.
  • Останавливай таймер, когда он больше не нужен.

Частые ошибки новичков

  • Путают миллисекунды и секунды. Interval = 1 — это 1 мс, а не 1 с.
  • Не останавливают таймер. Он продолжает срабатывать впустую.
  • Ставят слишком маленький интервал. Перегрузка устройства.
  • Тяжёлая логика в onTimerTick. Наслоение срабатываний.
  • Ждут работу в фоне. Timer останавливается при сворачивании.
  • Забывают остановить в onPause. Таймер работает вхолостую.
  • Используют Timer для плавной анимации. Лучше ObjectAnimator.
