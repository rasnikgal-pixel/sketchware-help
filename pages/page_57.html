TabLayout — вкладки

TabLayout — панель вкладок. Компонент, который показывает горизонтальный ряд вкладок — как в браузере или мессенджере. Пользователь тапает по вкладке, и содержимое экрана меняется.

Иконка в палитре — прямоугольник с полосой вкладок сверху.

Как работает

  • Сверху — ряд вкладок с текстом и/или иконками.
  • Активная вкладка подчёркнута цветом colorAccent из темы.
  • При тапе по вкладке — срабатывает событие, и приложение показывает соответствующий контент.
  • Вкладки можно прокручивать вбок, если их больше, чем помещается по ширине.

Из чего состоит

  • Вкладки (Tab) — каждая с текстом или иконкой.
  • Индикатор — подчёркивание активной вкладки.
  • Слушатель (OnTabSelectedListener) — реагирует на смену вкладки в логике.

Когда использовать

  • Разделы одного экрана — например, «Новости», «Популярное», «Избранное».
  • Переключение между фильтрами — «Все», «Активные», «Завершённые».
  • Разбивка содержимого по категориям без перехода на новый экран.
  • Парное использование с ViewPager — тогда контент под вкладками можно листать свайпом.

Настройки

  • TabMode — fixed (вкладки одинаковой ширины) или scrollable (прокрутка вбок).
  • TabGravity — fill (растянуть по ширине) или center (по центру).
  • Background — цвет фона панели.
  • TabIndicatorColor — цвет подчёркивания активной вкладки.
  • TabTextColor — цвет текста вкладок (обычно задаётся вручную).
  • Width / Height — match_parent по ширине, wrap_content по высоте.

Как добавить

  • Тап по TabLayout в палитре — компонент добавится в текущий выбранный контейнер.
  • В свойствах задай базовые параметры: TabMode, цвет индикатора, цвет текста.
  • Открой вкладку «События» — и добавь события для вкладок: onTabSelected, onTabUnselected, onTabReselected.
  • В каждом событии добавь блоки, которые будут выполняться при выборе вкладки.

⚠️ Важно: TabLayout сам по себе не переключает контент. Он только показывает вкладки и сообщает логике, какая из них выбрана. Что именно показывать — описывается в блоках событий вручную.

💡 Совет: связка TabLayout + ViewPager даёт самый удобный результат: пользователь может переключать разделы и тапом по вкладке, и свайпом. Это классический паттерн Android-приложений.

💡 Совет: не делай больше 5–6 вкладок без необходимости. На узких экранах они становятся слишком мелкими. Если разделов больше — используй BottomNavigationView или боковое меню.

❌ Частая ошибка: добавить TabLayout и забыть про события. Вкладки отображаются, но ничего не делают — пользователь тапает, а экран не меняется.
