TabLayout — вкладки

TabLayout — панель вкладок. Компонент, который показывает горизонтальный ряд вкладок — как в браузере или мессенджере. Пользователь тапает по вкладке, и содержимое экрана меняется.

Иконка в палитре — прямоугольник с полосой вкладок сверху.

Как работает

  • Сверху — ряд вкладок с текстом и/или иконками.
  • Активная вкладка подчёркнута цветом colorAccent из темы.
  • При тапе по вкладке — срабатывает событие, и приложение показывает соответствующий контент.
  • Вкладки можно прокручивать вбок, если их больше, чем помещается по ширине.

Из чего состоит

  • Вкладки (Tab) — каждая с текстом или иконкой.
  • Индикатор — подчёркивание активной вкладки.
  • Слушатель (OnTabSelectedListener) — реагирует на смену вкладки в логике.

Когда использовать

  • Разделы одного экрана — например, «Новости», «Популярное», «Избранное».
  • Переключение между фильтрами — «Все», «Активные», «Завершённые».
  • Разбивка содержимого по категориям без перехода на новый экран.
  • Парное использование с ViewPager — тогда контент под вкладками можно листать свайпом.

Настройки

Настройка Что делает Значения
TabMode Режим отображения вкладок. fixed — вкладки одинаковой ширины;
scrollable — прокрутка вбок.
TabGravity Расположение вкладок по ширине панели. fill — растянуть по ширине;
center — по центру.
Background Цвет фона панели. HEX или выбор из палитры.
TabIndicatorColor Цвет подчёркивания активной вкладки. HEX или выбор из палитры.
TabTextColor Цвет текста вкладок (обычно задаётся вручную). HEX или выбор из палитры.
Width / Height Ширина и высота компонента. По умолчанию match_parent по ширине и wrap_content по высоте.

Свойства контейнера

Открой панель свойств, тапнув по TabLayout в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — tablayout2).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя компонента. По этому имени он виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — tablayout1, tablayout2 и т. д. Переименуй в mainTabs, если это основные вкладки экрана.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». На скриншоте заданы app:tabGravity="fill" и app:tabMode="fixed".
Конвертировать Показывает полный класс компонента: com.google.android.material.tabs.TabLayout. TabLayout (Material) и другие. Обычно менять не нужно.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широкой будет панель вкладок по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent, чтобы панель заняла весь экран по ширине.
Высота
Height		 Насколько высокой будет панель по вертикали. match_parent, wrap_content, число в dp. wrap_content — стандарт для панели вкладок.
Внутренний отступ
Padding		 Отступ внутри компонента — от краёв до вкладок. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 0 со всех сторон.
Внешний отступ
Margin		 Отступ снаружи компонента — от него до соседних элементов и краёв родителя. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin bottom 8 — панель сдвинется на 8 dp вверх от следующего элемента.
Гравитация макета
Layout gravity		 Как компонент выравнивается внутри родителя. none — по умолчанию;
например, center_horizontal, right.		 Обычно оставляют none.
Вес
Weight		 Доля свободного места родителя, которую займёт этот компонент. Работает только внутри родителя с весом. Число. 0 — вес не задан. 0 — стандарт, менять не нужно.

Свойства изображения

Свойство (рус / англ) Что делает Значения Пример
Ресурс фона
Background resource		 Картинка-фон компонента из ресурсов проекта. NONE — без фона;
любой drawable-ресурс.		 Обычно оставляют NONE и задают цвет.
Цвет фона
Background color		 Заливка панели вкладок сплошным цветом. NONE — без цвета;
HEX или выбор из палитры.		 На скриншоте установлен синий цвет фона.
Enabled
Включено		 Реагирует ли панель на тапы по вкладкам. Переключатель: вкл — активна;
выкл — заблокирована.		 На скриншоте — включено.
Вращение
Rotation		 Поворот компонента вокруг центра. Градусы. 0 — без поворота. Обычно оставляют 0.
Прозрачность
Alpha		 Насколько компонент и его содержимое прозрачны. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.
TranslationX Сдвиг компонента по горизонтали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. 20.0 — визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг компонента по вертикали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.
ScaleX Масштаб по горизонтали — растягивает или сжимает компонент по ширине. Число. 1.0 — исходный размер. 1.5 — ширина увеличится в 1,5 раза.
ScaleY Масштаб по вертикали — растягивает или сжимает компонент по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: на первых порах достаточно свойств Ширина, Высота, Цвет фона и пользовательских атрибутов app:tabMode и app:tabGravity. Остальные оставь по умолчанию.

Как перетащить TabLayout на макет

TabLayout, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Раскрой категорию AndroidX в палитре слева.
  3. Зажми TabLayout и, не отпуская, перетащи его на макет (лучше внутрь Linear(V) или прямо в корневой контейнер).
  4. Отпусти в нужном месте — панель вкладок появится в разметке.
  5. Тапни по ней и в панели свойств задай базовые параметры: TabMode, TabGravity, Цвет фона, TabIndicatorColor, TabTextColor.
  6. Открой вкладку «События» и добавь события для вкладок: onTabSelected, onTabUnselected, onTabReselected.
  7. В каждом событии добавь блоки, которые будут выполняться при выборе вкладки.
⚠️ Важно: обычный тап по TabLayout в палитре ничего не делает. Панель попадает на макет только перетаскиванием.
⚠️ Важно: TabLayout сам по себе не переключает контент. Он только показывает вкладки и сообщает логике, какая из них выбрана. Что именно показывать — описывается в блоках событий вручную.
💡 Совет: связка TabLayout + ViewPager даёт самый удобный результат: пользователь может переключать разделы и тапом по вкладке, и свайпом. Это классический паттерн Android-приложений.
💡 Совет: не делай больше 5–6 вкладок без необходимости. На узких экранах они становятся слишком мелкими. Если разделов больше — используй BottomNavigationView или боковое меню.
❌ Частая ошибка: перетащить TabLayout и забыть про события. Вкладки отображаются, но ничего не делают — пользователь тапает, а экран не меняется.

Резюме

  • TabLayout — горизонтальная панель вкладок в стиле Material Design.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Ключевые настройки: TabMode (fixed / scrollable) и TabGravity (fill / center).
  • Сам по себе не переключает контент — нужно добавлять события onTabSelected и т. д. на вкладке «События».
  • Лучше всего работает в связке с ViewPager: вкладки + свайп.
  • Оптимальное количество вкладок — 3–5.

Частые ошибки новичков

  • Тапают по TabLayout в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетащили панель, но не добавили события. Вкладки видны, но не работают — при тапе ничего не меняется.
  • Не задали TabMode и TabGravity. Вкладки могут выглядеть неровно или растянуто — параметры нужно настроить.
  • Делают слишком много вкладок. 7–8 вкладок на узком экране нечитаемы — используйте другой способ навигации.
  • Забывают про подключение Material-библиотеки. Без неё TabLayout не отобразится (или отобразится без стиля).
  • Путают TabLayout с BottomNavigationView. TabLayout — панель сверху; BottomNavigationView — меню снизу.
