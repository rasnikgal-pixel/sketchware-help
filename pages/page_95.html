MapView — карта Google

MapView — карта Google Maps внутри приложения. Отображает карту, позволяет пользователю двигать её, приближать, ставить маркеры, строить маршруты.

Иконка в палитре — прямоугольник с картой и меткой.

Как работает

  • Отображает интерактивную карту Google Maps.
  • Пользователь может двигать, масштабировать (жестом «щипок»), вращать карту.
  • Показывает текущее местоположение (если включено и есть разрешение).
  • Можно добавлять маркеры — точки с подписями.
  • Поддерживает режимы отображения: обычная карта, спутник, гибрид, рельеф.
  • Может показывать маршруты, зоны, полигоны.

Когда использовать

  • Приложения доставки — показать адрес, курьера.
  • Такси — маршрут от точки А до точки Б.
  • Путешествия — карта достопримечательностей.
  • Поиск магазинов — ближайшие отделения.
  • Спорт — маршруты пробежек, велосипедные треки.
  • Недвижимость — расположение объектов.
  • Социальные приложения — где находятся друзья.

Настройки

Настройка Что делает Значения
ApiKey API-ключ Google Maps (получается в Google Cloud Console). Строка формата AIza....
MapType Тип карты. normal — обычная;
satellite — спутник;
hybrid — гибрид;
terrain — рельеф;
none — пустая.
Zoom Масштаб. Число от 2 до 21.
Latitude / Longitude Координаты центра карты. Числа.
MyLocationEnabled Показывать текущее местоположение. Переключатель: вкл / выкл.
ZoomControlsEnabled Показывать кнопки «+» и «−» для зума. Переключатель: вкл / выкл.
CompassEnabled Показывать компас. Переключатель: вкл / выкл.
MapToolbarEnabled Показывать панель инструментов Google Maps. Переключатель: вкл / выкл.
Width / Height Ширина и высота. Обычно match_parent для обоих.

Свойства виджета

Открой панель свойств, тапнув по MapView в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — mapview1).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — mapview1, mapview2 и т. д. Переименуй в deliveryMap, если это карта доставки.
Пользовательские атрибуты Дополнительные XML-атрибуты. Здесь задаётся API-ключ и параметры карты. Пары «атрибут = значение». Например, app:mapType="normal", app:cameraZoom="15".
Конвертировать Показывает полный класс компонента: com.google.android.gms.maps.MapView. MapView и другие типы виджетов. Оставь как есть.

💡 Совет для новичков: ключевые параметры (ApiKey, MapType, Zoom, Latitude, Longitude, MyLocationEnabled) задаются через Пользовательские атрибуты — app:apiKey, app:cameraZoom. В обычной панели свойств доступен только Enabled.

Как перетащить MapView на макет

MapView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Зарегистрируйся в Google Cloud Console (console.cloud.google.com).
  2. Включи Maps SDK for Android для своего проекта.
  3. Создай API-ключ и ограничь его по имени пакета приложения.
  4. В Sketchware Pro 7 подключи библиотеку Google Maps через Менеджер библиотек.
  5. Добавь разрешения в Менеджере разрешений: INTERNET, ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION.
  6. Открой вкладку «Дизайнер». Убедись, что на макете уже есть контейнер — Linear(V) или RelativeLayout.
  7. Раскрой категорию Google в палитре слева.
  8. Зажми MapView и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  9. Отпусти в нужном месте — карта появится в разметке.
  10. Через Пользовательские атрибуты задай app:apiKey, app:cameraZoom, координаты.
  11. Присвой осмысленный ID — он нужен для логики.
  12. В событиях используй блоки для маркеров, перемещения карты, геолокации.
⚠️ Важно: обычный тап по MapView в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: без API-ключа карта не загрузится — вместо неё будет серый фон или логотип Google. Ключ обязателен.
⚠️ Важно: API-ключ привязан к имени пакета приложения. Если пакет изменится — ключ перестанет работать, потребуется новый.
⚠️ Важно: биллинг Google Cloud обязателен для Maps SDK, даже если ты не превышаешь бесплатный лимит. Без привязанной карты ключ не активируется.
⚠️ Важно: для показа текущего местоположения нужны разрешения ACCESS_FINE_LOCATION и ACCESS_COARSE_LOCATION. Без них MyLocationEnabled не сработает.
⚠️ Важно: пользователь может отказать в разрешении на геолокацию. Приложение должно корректно обрабатывать такой случай — не падать, а показывать понятное сообщение.
💡 Совет: задавай Zoom = 15 для городского масштаба. Это оптимально для отображения улиц и районов.
💡 Совет: для текущего местоположения используй блок moveCamera с координатами из LocationManager. Плавно перемещай карту к пользователю.
💡 Совет: не открывай карту сразу с запросом геолокации. Сначала покажи экран с пояснением, зачем нужно местоположение. Пользователь охотнее даст разрешение, если понимает причину.
💡 Совет: для маркеров используй блок addMarker с координатами и заголовком. Клик по маркеру покажет подпись.
💡 Совет: для снижения расходов используй MapType = none в фоне, если карта нужна только как «заглушка». Полноценный MapType = normal расходует квоту API.
❌ Частая ошибка: забыть про API-ключ. Карта не отображается, а причина не видна в логах.
❌ Частая ошибка: использовать ключ без ограничения по пакету. Такой ключ могут украсть и использовать в других приложениях.
❌ Частая ошибка: не привязать биллинг в Google Cloud. Ключ не активируется, карта не работает.
❌ Частая ошибка: запрашивать местоположение без объяснения. Пользователь отказывает — и функция не работает.
❌ Частая ошибка: открывать карту на весь экран без кнопки закрытия. Пользователь не понимает, как вернуться.

Резюме

  • MapView — интерактивная карта Google Maps внутри приложения.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Требует API-ключ из Google Cloud Console с включённым Maps SDK и привязанным биллингом.
  • Нужны разрешения: INTERNET, ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION.
  • Ключевые параметры (ApiKey, MapType, Zoom, координаты) задаются через Пользовательские атрибуты.
  • Обязательно ограничивай ключ по имени пакета — защита от кражи.
  • Не запрашивай геолокацию без объяснения — это снижает доверие пользователя.
  • Маркеры и перемещение карты — через блоки логики.

Частые ошибки новичков

  • Тапают по MapView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Забывают API-ключ. Карта не загружается.
  • Не ограничивают ключ по пакету. Ключ могут украсть.
  • Не привязывают биллинг в Google Cloud. Ключ не активируется.
  • Не добавляют разрешения на геолокацию. MyLocationEnabled не работает.
  • Открывают карту без пояснения. Пользователь отказывает в доступе.
  • Ищут ApiKey и MapType в обычных свойствах. Через «Пользовательские атрибуты».
  • Не задают ID. Логика не может обратиться к карте.
