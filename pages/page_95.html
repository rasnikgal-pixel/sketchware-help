MapView — карта Google

MapView — карта Google Maps внутри приложения. Отображает карту, позволяет пользователю двигать её, приближать, ставить маркеры, строить маршруты.

Иконка в палитре — прямоугольник с картой и меткой.

Как работает

  • Отображает интерактивную карту Google Maps.
  • Пользователь может двигать, масштабировать (жестом «щипок»), вращать карту.
  • Показывает текущее местоположение (если включено и есть разрешение).
  • Можно добавлять маркеры — точки с подписями.
  • Поддерживает режимы отображения: обычная карта, спутник, гибрид, рельеф.
  • Может показывать маршруты, зоны, полигоны.

Когда использовать

  • Приложения доставки — показать адрес, курьера.
  • Такси — маршрут от точки А до точки Б.
  • Путешествия — карта достопримечательностей.
  • Поиск магазинов — ближайшие отделения.
  • Спорт — маршруты пробежек, велосипедные треки.
  • Недвижимость — расположение объектов.
  • Социальные приложения — где находятся друзья.

Основные свойства

  • ApiKey — API-ключ Google Maps (получается в Google Cloud Console).
  • MapType — тип карты: normal, satellite, hybrid, terrain, none.
  • Zoom — масштаб (от 2 до 21).
  • Latitude / Longitude — координаты центра карты.
  • MyLocationEnabled — показывать текущее местоположение.
  • ZoomControlsEnabled — показывать кнопки «+» и «−» для зума.
  • CompassEnabled — показывать компас.
  • MapToolbarEnabled — показывать панель инструментов Google Maps.
  • Width / Height — обычно match_parent.

Как добавить

  • Зарегистрируйся в Google Cloud Console (console.cloud.google.com).
  • Включи Maps SDK for Android для своего проекта.
  • Создай API-ключ и ограничь его по имени пакета приложения.
  • В Sketchware Pro 7 подключи библиотеку Google Maps через Менеджер библиотек.
  • Добавь разрешения в Менеджере разрешений: INTERNET, ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION.
  • В свойствах MapView укажи ApiKey.
  • Задай стартовые Latitude, Longitude и Zoom.
  • Присвой id — для работы в логике.
  • В событиях используй блоки для маркеров, перемещения карты, геолокации.

⚠️ Важно: без API-ключа карта не загрузится — вместо неё будет серый фон или логотип Google. Ключ обязателен.

⚠️ Важно: API-ключ привязан к имени пакета приложения. Если пакет изменится — ключ перестанет работать, потребуется новый.

⚠️ Важно: биллинг Google Cloud обязателен для Maps SDK, даже если ты не превышаешь бесплатный лимит. Без привязанной карты ключ не активируется.

⚠️ Важно: для показа текущего местоположения нужны разрешения ACCESS_FINE_LOCATION и ACCESS_COARSE_LOCATION. Без них MyLocationEnabled не сработает.

⚠️ Важно: пользователь может отказать в разрешении на геолокацию. Приложение должно корректно обрабатывать такой случай — не падать, а показывать понятное сообщение.

💡 Совет: задавай Zoom = 15 для городского масштаба. Это оптимально для отображения улиц и районов.

💡 Совет: для текущего местоположения используй блок moveCamera с координатами из LocationManager. Плавно перемещай карту к пользователю.

💡 Совет: не открывай карту сразу с запросом геолокации. Сначала покажи экран с пояснением, зачем нужно местоположение. Пользователь охотнее даст разрешение, если понимает причину.

💡 Совет: для маркеров используй блок addMarker с координатами и заголовком. Клик по маркеру покажет подпись.

💡 Совет: для снижения расходов используй MapType = none в фоне, если карта нужна только как «заглушка». Полноценный MapType = normal расходует квоту API.

❌ Частая ошибка: забыть про API-ключ. Карта не отображается, а причина не видна в логах.

❌ Частая ошибка: использовать ключ без ограничения по пакету. Такой ключ могут украсть и использовать в других приложениях.

❌ Частая ошибка: не привязать биллинг в Google Cloud. Ключ не активируется, карта не работает.

❌ Частая ошибка: запрашивать местоположение без объяснения. Пользователь отказывает — и функция не работает.

❌ Частая ошибка: открывать карту на весь экран без кнопки закрытия. Пользователь не понимает, как вернуться.
