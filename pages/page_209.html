Проект 5. Погода (интернет + API)

Пятый проект — учимся работать с интернетом и API. Делаем приложение погоды: пользователь вводит город, приложение запрашивает данные с сервера и показывает температуру, описание и иконку.

После этого проекта ты поймёшь:

  • как делать запросы через RequestNetwork;
  • как работать с JSON;
  • как отображать данные из интернета;
  • как обрабатывать ошибки сети.

Что будем делать

  • Создать проект.
  • Добавить EditText для ввода города.
  • Добавить Button для запроса.
  • Добавить TextView для отображения погоды.
  • Добавить ImageView для иконки.
  • Подключить RequestNetwork.
  • Запрашивать данные с OpenWeatherMap API.

Про API

OpenWeatherMap — бесплатный сервис погоды. Даёт данные по API.

  • Регистрация: openweathermap.org.
  • После регистрации получи API-ключ (AppID).
  • Бесплатный тариф: 1000 запросов в день — для тестов хватает.
  • Формат ответа — JSON.

Пример URL: https://api.openweathermap.org/data/2.5/weather?q=Москва&appid=ТВОЙ_КЛЮЧ&units=metric&lang=ru

  • q — город.
  • appid — ключ.
  • units=metric — температура в Цельсиях.
  • lang=ru — описание на русском.

EditText для города

  • Создай новый проект:
    • Имя: Погода.
    • Пакет: com.example.weather.
    • Проект: WeatherApp.
  • В Дизайнере:
    • Основной контейнер — Linear(V).
    • Добавь EditText, id cityInput.
    • Hint: «Введите город».
    • InputType: text.

RequestNetwork

  • Открой вкладку «Компонент».
  • Нажми «+» → RequestNetwork.
  • Имя: weatherRequest.
  • Сохрани.
  • В Менеджере разрешений включи INTERNET — иначе запрос не уйдёт.

Логика запроса:

  • При нажатии кнопки «Найти»:
    • Получить текст из cityInput.
    • Проверить, что город не пустой.
    • Собрать URL: https://api.openweathermap.org/data/2.5/weather?q= + город + &appid=ТВОЙ_КЛЮЧ&units=metric&lang=ru.
    • setUrl для weatherRequest.
    • setRequestMethod = GET.
    • startRequestNetwork.
  • В событии onResponse:
    • Получи response — текст ответа в JSON.
    • Парси JSON.
  • В событии onErrorResponse:
    • Toast «Не удалось загрузить погоду. Проверьте интернет».

Парсинг JSON

Что приходит от API:

{
  "main": {
    "temp": 15.5,
    "feels_like": 14.2,
    "humidity": 65
  },
  "weather": [
    {
      "description": "облачно",
      "icon": "04d"
    }
  ],
  "name": "Москва"
}

Что парсим:

  • main.temp — температура.
  • main.feels_like — ощущается как.
  • main.humidity — влажность.
  • weather[0].description — описание.
  • weather[0].icon — код иконки.
  • name — название города.

В блоке onResponse:

  • String temp = response.getDouble("main.temp")
  • String desc = response.getString("weather[0].description")
  • String city = response.getString("name")

💡 Совет: структура JSON в Sketchware Pro 7 зависит от версии. Если блоки не работают напрямую — используй getString с путём или разбивай ответ на части.

TextView + ImageView для отображения

Добавь в макет:

  • TextView для города, id cityText.
  • TextView для температуры, id tempText.
  • TextView для описания, id descText.
  • ImageView для иконки, id weatherIcon.

В onResponse:

  • setText для cityText = city
  • setText для tempText = temp + "°C"
  • setText для descText = desc
  • Иконка: загрузи по URL https://openweathermap.org/img/wn/ + icon + @2x.png.

💡 Совет: иконка загружается через RequestNetwork в формате изображения. Или можно использовать готовые иконки из ресурсов проекта.

Запуск

  • Нажми «Сохранить».
  • Нажми «▶ Запустить».
  • Введи город (Москва, Лондон, Токио).
  • Нажми «Найти» — данные появятся на экране.

Что ты увидишь:

  • Поле ввода города.
  • Кнопка «Найти».
  • Название города, температура, описание, иконка.

Если что-то не работает:

  • Проверь INTERNET в Менеджере разрешений.
  • Проверь, что API-ключ правильный.
  • Проверь, что URL собран корректно.
  • Открой Logcat — там видно, что вернул сервер.
  • Проверь, что город написан правильно (на английском или русском).

Что можно улучшить

  • Прогноз на 5 дней — используй /forecast вместо /weather.
  • Определение города по GPS — через LocationManager.
  • Сохранение последнего города — через SharedPreferences.
  • Автообновление — через Timer каждые 30 минут.
  • Иконки погоды — загрузи готовый набор PNG в проект.
  • Красивый дизайн — CardView, градиенты, крупный шрифт.

⚠️ Важно: API-ключ не должен быть в открытом виде в APK. StringFog поможет, но лучше — проксировать через сервер.

⚠️ Важно: проверяй, что response не пустой. Если сервер вернул ошибку — не парси дальше.

⚠️ Важно: обрабатывай ошибки сети. Если интернета нет — покажи сообщение, а не пустые поля.

⚠️ Важно: следи за лимитами API. OpenWeatherMap — 1000 запросов в день бесплатно. При частом обновлении лимит исчерпается.

⚠️ Важно: проверяй код ответа. Если сервер вернул 404 (город не найден) — покажи «Город не найден».

💡 Совет: для отладки добавь временный Toast в onResponse — покажи первые 200 символов response. Так увидишь, что приходит от сервера.

💡 Совет: для работы с иконками используй статичные PNG из проекта. Загрузить картинку из интернета сложнее, чем подставить готовую.

💡 Совет: не отправляй запрос при каждом нажатии клавиши — только по кнопке. Иначе лимит API исчерпается быстро.

❌ Частая ошибка: не включить INTERNET. Запрос не уходит, ошибка не видна.

❌ Частая ошибка: неправильный API-ключ. Сервер возвращает ошибку 401.

❌ Частая ошибка: город на неправильном языке. OpenWeatherMap понимает и русский, и английский, но иногда требует транслитерации.

❌ Частая ошибка: не парсить JSON корректно. Данные приходят, но не отображаются.

❌ Частая ошибка: не обрабатывать onErrorResponse. При ошибке приложение молчит.
