RadioGroup — группа радиокнопок

RadioGroup — контейнер для группы радиокнопок (RadioButton). Его задача — гарантировать, что одновременно выбрана только одна радиокнопка из группы. При выборе другой — предыдущая автоматически снимается.

Иконка в палитре — круг с точкой внутри.

Как работает

  • Внутрь RadioGroup перетаскиваются только RadioButton.
  • Каждая радиокнопка имеет свой идентификатор (id).
  • При тапе по одной — остальные автоматически снимаются.
  • Через логику можно узнать, какая именно кнопка выбрана сейчас, и получить её текст или id.

Когда использовать

  • Выбор одного варианта из нескольких: пол, возрастная категория, способ оплаты.
  • Анкеты и опросы — где нужен один ответ на вопрос.
  • Настройки — переключение между взаимоисключающими режимами.
  • Фильтры — сортировка «по цене», «по дате», «по популярности» (только один активен).

Что можно и нельзя перетаскивать внутрь

  • Можно: только RadioButton.
  • Нельзя: TextView, Button, ImageView, EditText и любые другие виджеты. Android не позволит им корректно работать в группе.

Если нужно подписать группу — используй отдельный TextView над RadioGroup, а не внутри.

Как перетащить RadioGroup на макет

  1. Открой вкладку «Дизайнер».
  2. Раскрой категорию Layouts в палитре слева.
  3. Зажми RadioGroup и, не отпуская, перетащи его на макет.
  4. Отпусти в нужном месте — контейнер появится в разметке.
  5. Перетащи внутрь RadioGroup две или более RadioButton (они находятся в категории Widgets).
  6. Каждой RadioButton задай уникальный id через панель свойств — иначе логика не сможет их различить.
⚠️ Важно: обычный тап по RadioGroup в палитре ничего не делает. Контейнер попадает на макет только перетаскиванием. То же правило — для RadioButton внутри группы.

Свойства контейнера

Открой панель свойств, тапнув по контейнеру в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — radiogroup2).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя контейнера. По этому имени контейнер виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — radiogroup1, radiogroup2 и т. д. Переименуй в genderGroup, если это выбор пола.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». Например, android:checkedButton="@id/radio2".
Конвертировать Превратить этот контейнер в другой тип (например, в LinearLayout). RadioGroup, LinearLayout и другие. Если группа больше не нужна — переключи на LinearLayout.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет контейнер по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent, чтобы группа заняла всю ширину строки.
Высота
Height		 Насколько высоким будет контейнер по вертикали. match_parent, wrap_content, число в dp. wrap_content — высота подстроится под кнопки.
Внутренний отступ
Padding		 Отступ внутри контейнера — от его краёв до кнопок. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Padding 8 со всех сторон — кнопки не липнут к краям группы.
Внешний отступ
Margin		 Отступ снаружи контейнера — от него до соседних элементов и краёв родителя. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin top 16 — группа сдвинется на 16 dp вниз от предыдущего элемента.
Ориентация
Orientation		 Направление, в котором выстраиваются дочерние радиокнопки. horizontal — кнопки в ряд;
vertical — кнопки в столбик.		 vertical — если подписи длинные, удобнее читать в столбик.
Сумма весов
Weight sum		 Общая сумма весов дочерних элементов. Нужна, если хочешь распределять свободное место между кнопками в пропорциях. Число. 0 — не используется. 2, если две кнопки с весом 1 — поделят ширину пополам.
Положение
Position		 Позиционирование контейнера внутри родителя (влияет на порядок и привязку). none — по умолчанию;
другие варианты зависят от типа родителя.		 Оставь none, если не работаешь с RelativeLayout-родителем.
Гравитация макета
Layout gravity		 Как контейнер выравнивается внутри родителя: по левому краю, центру, правому и т. п. none — по умолчанию;
например, center_horizontal, right.		 center_horizontal — группа встанет по центру родителя.
Вес
Weight		 Доля свободного места родителя, которую займёт этот контейнер. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — контейнер заберёт всё оставшееся место в родителе.

Свойства изображения

Свойство (рус / англ) Что делает Значения Пример
Ресурс фона
Background resource		 Картинка-фон контейнера из ресурсов проекта. NONE — без фона;
любой drawable-ресурс.		 Установи NONE, если фон не нужен.
Цвет фона
Background color		 Заливка контейнера сплошным цветом. NONE — без цвета;
HEX или выбор из палитры (например, #F5F5F5).		 Светло-серый фон под группой — #F5F5F5.
Enabled
Включено		 Реагирует ли группа на нажатия и тапы. Переключатель: вкл — активна;
выкл — заблокирована.		 Выключи, если хочешь показать выбор, но запретить его менять.
Вращение
Rotation		 Поворот контейнера вокруг центра. Градусы. 0 — без поворота. 90 — контейнер развернётся на 90°.
Прозрачность
Alpha		 Насколько контейнер и его содержимое прозрачны. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 0.5 — половина прозрачности.
TranslationX Сдвиг контейнера по горизонтали без изменения его места в разметке (визуальный сдвиг). Число в dp. 0.0 — без сдвига. 20.0 — контейнер визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг контейнера по вертикали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.
ScaleX Масштаб по горизонтали — растягивает или сжимает контейнер по ширине. Число. 1.0 — исходный размер. 1.5 — ширина увеличится в 1,5 раза.
ScaleY Масштаб по вертикали — растягивает или сжимает контейнер по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: на первых порах достаточно четырёх свойств — Ширина, Высота, Ориентация, Внутренний отступ. Остальные оставь по умолчанию.

Практический пример: выбор пола

  1. Перетащи на макет Linear(V) — он будет корневым.
  2. Внутрь перетащи TextView с подписью «Выберите пол».
  3. Ниже перетащи RadioGroup.
  4. Внутрь RadioGroup перетащи две RadioButton.
  5. Первой RadioButton задай текст «Мужской», второй — «Женский».
  6. Тапни по RadioGroup и поставь Ориентация = horizontal.
  7. Одной из кнопок задай Checked = вкл (через свойства), чтобы при запуске одна уже была выбрана.
  8. На вкладке «События» для RadioGroup появится событие onCheckedChanged, где можно узнать, какая кнопка выбрана.
⚠️ Важно: если у радиокнопок совпадают id — они не будут работать как группа. Sketchware автоматически присваивает id при перетаскивании, но если ты редактируешь разметку вручную, следи за уникальностью.
⚠️ Важно: RadioGroup без дочерних RadioButton бессмысленен. Это просто пустой контейнер, не выполняющий свою функцию.
💡 Совет: задай одной из кнопок свойство Checked = вкл в свойствах. Тогда при запуске приложения одна из кнопок будет выбрана сразу — это удобнее для пользователя.
💡 Совет: подписывай группу TextView над ней — например, «Выберите пол». Внутри RadioGroup подпись добавить нельзя.

Резюме

  • RadioGroup — контейнер для взаимоисключающих радиокнопок: выбрана может быть только одна.
  • Перетаскивается на макет так же, как любой другой виджет — перетаскиванием, а не тапом.
  • Внутрь перетаскиваются только RadioButton. Другие виджеты внутрь недопустимы.
  • Каждой RadioButton нужен уникальный id, иначе логика не различит их.
  • Главные свойства: Ширина, Высота, Ориентация, Внутренний и Внешний отступы, Вес.
  • Дополнительное свойство изображения — Enabled: включает и выключает реакцию группы на тапы.
  • На вкладке «События» у RadioGroup есть событие onCheckedChanged.

Частые ошибки новичков

  • Тапают по RadioGroup в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетаскивают внутрь RadioGroup TextView или кнопку. Так нельзя — только RadioButton.
  • Забывают про уникальные id радиокнопок. Без уникальных id группа не работает правильно.
  • Используют RadioGroup для множественного выбора. Для этого нужны CheckBox, а не RadioGroup.
  • Пытаются добавить подпись группы внутрь RadioGroup. Подпись ставится отдельным TextView над группой.
  • Оставляют группу пустой. Без дочерних RadioButton контейнер бесполезен.
