RadioGroup — группа радиокнопок

RadioGroup — контейнер для группы радиокнопок (RadioButton). Его задача — гарантировать, что одновременно выбрана только одна радиокнопка из группы. При выборе другой — предыдущая автоматически снимается.

Иконка в палитре — круг с точкой внутри.

Как работает

  • Внутрь RadioGroup добавляются только RadioButton.
  • Каждая радиокнопка имеет свой идентификатор (id).
  • При тапе по одной — остальные автоматически снимаются.
  • Через логику можно узнать, какая именно кнопка выбрана сейчас, и получить её текст или id.

Когда использовать

  • Выбор одного варианта из нескольких: пол, возрастная категория, способ оплаты.
  • Анкеты и опросы — где нужен один ответ на вопрос.
  • Настройки — переключение между взаимоисключающими режимами.
  • Фильтры — сортировка «по цене», «по дате», «по популярности» (только один активен).

Что можно и нельзя класть внутрь

  • Можно: только RadioButton.
  • Нельзя: TextView, Button, ImageView, EditText и любые другие виджеты. Android не позволит им корректно работать в группе.

Если нужно подписать группу — используй отдельный TextView над RadioGroup, а не внутри.

Настройки

  • Orientation — horizontal (кнопки в ряд) или vertical (кнопки в столбик).
  • Width / Height — wrap_content (по содержимому) или match_parent (на всю ширину/высоту).
  • Padding / Margin — внутренние и внешние отступы.
  • CheckedButton — id кнопки, выбранной по умолчанию (можно задать в свойствах).

Как добавить

  • Тап по RadioGroup в палитре — контейнер добавится в текущий выбранный элемент.
  • Внутрь RadioGroup добавь две или более RadioButton.
  • Каждой RadioButton задай уникальный id — иначе логика не сможет их различить.

⚠️ Важно: если у радиокнопок совпадают id — они не будут работать как группа. Sketchware автоматически присваивает id при добавлении, но если ты редактируешь разметку вручную, следи за уникальностью.

⚠️ Важно: RadioGroup без дочерних RadioButton бессмысленен. Это просто пустой контейнер, не выполняющий свою функцию.

💡 Совет: задай одной из кнопок свойство Checked = true в свойствах. Тогда при запуске приложения одна из кнопок будет выбрана сразу — это удобнее для пользователя.

💡 Совет: подписывай группу TextView над ней — например, «Выберите пол». Внутри RadioGroup подпись добавить нельзя.

❌ Частая ошибка: использовать RadioGroup для выбора нескольких вариантов. Для множественного выбора нужны CheckBox — они не связаны друг с другом.
