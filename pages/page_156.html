Google Login — вход через Google

Google Login — авторизация через аккаунт Google. Пользователь тапает по кнопке — система предлагает список аккаунтов на устройстве. Один тап — и он вошёл в приложение, без ввода пароля.

Иконка в диалоге добавления — логотип Firebase.

Как работает

  • Открывает диалог выбора аккаунта Google.
  • Пользователь выбирает аккаунт — приложение получает токен авторизации.
  • Firebase проверяет токен и создаёт сессию.
  • Приложение получает UID, email, имя, фото профиля.
  • Аккаунт Google уже существует — регистрация не нужна.

Когда использовать

  • Быстрая авторизация — один тап вместо ввода пароля.
  • Приложения с профилем — получить имя и аватар пользователя автоматически.
  • Синхронизация с Google-сервисами — Google Drive, Calendar, Gmail.
  • Покупки — привязать к аккаунту Google.
  • Отзывы и комментарии — авторизация для публикации.
  • Облачные функции — сохранение данных в аккаунте пользователя.

Это самый удобный способ входа — меньше всего действий от пользователя.

Настройки при добавлении

Настройка Что задаёт Пример
Имя компонента Идентификатор для вызова в логике. googleLogin.

Основные блоки в логике

Блок Что делает
signIn Начать вход через Google.
signOut Выйти из аккаунта.
getDisplayName Получить имя пользователя.
getEmail Получить email.
getPhotoUrl Получить URL аватара.
getUid Получить уникальный ID.

События Google Login

Событие Когда срабатывает
onGoogleSignInSuccess Успешный вход.
onGoogleSignInFailed Ошибка входа.

Как использовать

  1. Зарегистрируйся в Firebase Console и Google Cloud Console.
  2. В Firebase → Authentication включи Google.
  3. В Google Cloud создай OAuth 2.0 Client ID для Android.
  4. Укажи имя пакета приложения и SHA-1 отпечаток сертификата.
  5. Скачай google-services.json и подключи его в Sketchware Pro 7.
  6. Подключи компонент Google Login на вкладке «Компонент».
  7. Задай имя — например, googleLogin.
  8. В логике:
    • в onClick кнопки «Войти через Google» — вызови signIn;
    • в onGoogleSignInSuccess — сохрани данные пользователя и перейди на главный экран;
    • в onGoogleSignInFailed — покажи сообщение об ошибке.

Пример: вход через Google

  • Button «Войти через Google» → signIn.
  • onGoogleSignInSuccess → сохрани getUid, getEmail, getDisplayName в Firebase DB.
  • Покажи имя пользователя на главном экране.
  • onGoogleSignInFailed → покажи «Не удалось войти. Попробуйте снова».
⚠️ Важно: SHA-1 отпечаток обязателен. Без него Google не признаёт приложение и вход не работает. Отпечаток берётся из сертификата подписи приложения.
⚠️ Важно: SHA-1 меняется между debug и release версиями. Для теста — один отпечаток, для публикации — другой. Оба нужно добавить в Google Cloud.
⚠️ Важно: не используй debug-отпечаток в релизной сборке. Приложение соберётся, но вход через Google работать не будет.
⚠️ Важно: пользователь может отказаться от входа. Приложение должно корректно обработать отказ и предложить альтернативу (например, вход по email).
⚠️ Важно: не показывай свой OAuth Client ID в коде приложения. Он может быть использован злоумышленниками для подделки запросов.
💡 Совет: для получения SHA-1 используй команду keytool -list -v -keystore <файл> или смотри его в Firebase Console → Project Settings.
💡 Совет: для отладки используй два OAuth Client ID: один для debug-сборки, другой для release. Так можно тестировать и то, и другое.
💡 Совет: для профиля пользователя сразу получи getDisplayName, getEmail, getPhotoUrl и сохрани в Firebase DB. Так у тебя есть и данные авторизации, и профиль.
💡 Совет: для аватара используй CircleImageView с URL из getPhotoUrl. Вход через Google даёт готовую круглую картинку профиля.
💡 Совет: для выхода предусмотри кнопку «Выйти из Google» в настройках. Пользователь должен иметь возможность сменить аккаунт.
💡 Совет: для обработки ошибок показывай общее сообщение: «Не удалось войти. Проверьте подключение к интернету». Конкретику пользователю знать не обязательно.
💡 Совет: для дополнительной информации после входа запроси разрешения на другие Google-сервисы: Calendar, Drive. Пользователь сам решит, что разрешить.
❌ Частая ошибка: не указать SHA-1 в Google Cloud. Вход не работает, ошибка не всегда видна.
❌ Частая ошибка: использовать debug-отпечаток в release. Кнопка нажимается, но вход не проходит.
❌ Частая ошибка: не обрабатывать onGoogleSignInFailed. Пользователь тапает, ничего не происходит, ошибки не видно.
❌ Частая ошибка: не показывать имя пользователя после входа. Пользователь не понимает, что вошёл успешно.
❌ Частая ошибка: не предусмотреть выход. Пользователь не может сменить аккаунт.
❌ Частая ошибка: путать Google Login (Firebase) и SignInButton (Google). SignInButton — просто кнопка, логику входа надо писать. Google Login — готовый компонент с Firebase.

Резюме

  • Google Login — авторизация через аккаунт Google.
  • Основные блоки: signIn, signOut, getDisplayName, getEmail, getPhotoUrl, getUid.
  • Основные события: onGoogleSignInSuccess, onGoogleSignInFailed.
  • Требует настройки OAuth 2.0 в Google Cloud с указанием пакета и SHA-1.
  • Отпечатки debug и release версии разные — оба нужны в Cloud.
  • Не показывай OAuth Client ID в коде приложения.
  • Обрабатывай отказ и ошибки входа.
  • Google Login (Firebase) ≠ SignInButton (Google) — разные вещи.

Частые ошибки новичков

  • Не указывают SHA-1. Вход не работает.
  • Используют debug-отпечаток в release. Вход не проходит у пользователей.
  • Не обрабатывают onGoogleSignInFailed. Ошибки не видны.
  • Не показывают имя пользователя. Непонятно, что вход выполнен.
  • Не предусматривают выход. Нельзя сменить аккаунт.
  • Путают с SignInButton. Разные компоненты.
  • Показывают OAuth Client ID в коде. Уязвимость безопасности.
