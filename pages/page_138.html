SpeechToText — распознавание речи

SpeechToText — компонент для распознавания речи. Превращает голос пользователя в текст: пользователь говорит, а приложение получает написанные слова.

Иконка в диалоге добавления — микрофон.

Как работает

  • Открывает микрофон устройства.
  • Пользователь говорит — приложение слушает.
  • После окончания речи — распознаёт её и возвращает текст.
  • Результат можно использовать в логике: показать, сохранить, отправить.
  • Работает через Google Speech Recognition или системный распознаватель.

Когда использовать

  • Голосовой ввод — вместо клавиатуры.
  • Голосовой поиск — поиск по фразе.
  • Диктовка заметок — запись текста голосом.
  • Голосовые команды — «Открой настройки», «Сделай фото».
  • Приложения для слабовидящих — ввод без экрана.
  • Чат-боты — голосовой диалог.
  • Переводчики — голосовой ввод для перевода.

Настройки при добавлении

Настройка Что задаёт Пример
Имя компонента Идентификатор для вызова в логике. voiceInput, voice.

Основные блоки в логике

Блок Что делает
startListening Начать слушать микрофон.
stopListening Остановить слушание.
getResult Получить распознанный текст.
setLanguage Задать язык распознавания.

Событие SpeechToText

Событие Когда срабатывает
onSpeechResult Срабатывает при получении распознанного текста. Здесь обрабатываешь результат.

Как использовать

  1. Подключи компонент SpeechToText на вкладке «Компонент».
  2. Задай имя — например, voice.
  3. Добавь разрешение RECORD_AUDIO в Менеджере разрешений.
  4. Убедись, что на устройстве есть интернет — распознавание работает через сервер Google.
  5. В логике вызови блок startListening — например, по нажатию кнопки с микрофоном.
  6. В категории «Компонент» добавь событие onSpeechResult — обработку распознанного текста.
  7. Внутри события: покажи текст в TextView, сохрани, отправь на сервер — по задаче.

Пример: голосовой ввод в EditText

  • EditText для ввода.
  • Button с иконкой микрофона.
  • В onClick — startListening.
  • В onSpeechResult — setText для EditText с распознанным текстом.
  • Пользователь говорит — текст появляется в поле.

Пример: голосовая команда

  • В onSpeechResult получи текст.
  • Сравни с ожидаемыми командами: «Открой настройки», «Сделай фото».
  • Выполни соответствующее действие через Intent.
⚠️ Важно: требуется разрешение RECORD_AUDIO. Без него приложение не получит доступ к микрофону.
⚠️ Важно: для распознавания нужен интернет. Если сети нет — функция не сработает. Обрабатывай эту ситуацию.
⚠️ Важно: точность распознавания зависит от качества микрофона, шума вокруг и чёткости речи. Не жди 100% результата.
⚠️ Важно: пользователь может отказать в разрешении. Приложение должно корректно обработать отказ и показать сообщение.
⚠️ Важно: не включай микрофон постоянно. Слушание быстро разряжает батарею и вызывает вопросы приватности.
💡 Совет: для заметок используй SpeechToText вместе с EditText. Пользователь нажимает микрофон, говорит — текст появляется в поле, он может его отредактировать.
💡 Совет: для голосового поиска используй SearchView + SpeechToText. Результат распознавания сразу подставляй в поле поиска.
💡 Совет: для обратной связи показывай пользователю, что идёт слушание: анимация микрофона, надпись «Говорите…». Это помогает понять, что приложение работает.
💡 Совет: для точности задавай язык явно через setLanguage. Иначе распознавание может идти на английском, даже если пользователь говорит по-русски.
💡 Совет: для длинных фраз делай паузы. Речь должна быть чёткой, без спешки. Приложение не всегда распознаёт быструю речь.
💡 Совет: для команд используй короткие фразы. «Сделай фото» распознается лучше, чем «Не мог бы ты сделать фотографию, пожалуйста».
❌ Частая ошибка: не запрашивать разрешение RECORD_AUDIO. Микрофон не открывается, ошибка не видна.
❌ Частая ошибка: не проверять интернет. Без сети распознавание не работает, а пользователь не понимает почему.
❌ Частая ошибка: слушать микрофон постоянно. Это быстро разряжает батарею и нарушает приватность.
❌ Частая ошибка: не задавать язык распознавания. Английский по умолчанию даст неточный результат для русской речи.
❌ Частая ошибка: не обрабатывать onSpeechResult. Пользователь говорит, но ничего не происходит.

Резюме

  • SpeechToText — компонент для распознавания речи.
  • Превращает голос пользователя в текст.
  • Основные блоки: startListening, stopListening, getResult, setLanguage.
  • Основное событие: onSpeechResult — при получении распознанного текста.
  • Требует разрешения RECORD_AUDIO и наличия интернета.
  • Работает через сервис Google Speech Recognition.
  • Задавай язык явно — иначе результат будет неточным.
  • Показывай пользователю, что идёт слушание — для обратной связи.

Частые ошибки новичков

  • Не запрашивают RECORD_AUDIO. Микрофон не открывается.
  • Не проверяют интернет. Распознавание не работает без сети.
  • Слушают микрофон постоянно. Батарея садится, приватность под вопросом.
  • Не задают язык. Русская речь распознаётся плохо.
  • Не обрабатывают onSpeechResult. Результат не используется.
  • Используют для длинных команд без пауз. Точность падает.
  • Не показывают обратной связи. Пользователь не понимает, что происходит.
