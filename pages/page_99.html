AnalogClock — аналоговые часы

AnalogClock — аналоговые часы со стрелками. Виджет, который показывает текущее время в классическом виде: круглый циферблат, часовая и минутная стрелки.

Иконка в палитре — циферблат со стрелками.

Как работает

  • Отображает круглый циферблат с двумя стрелками: часовой и минутной.
  • Стрелки двигаются автоматически — отражают системное время устройства.
  • Пользователь не может взаимодействовать с виджетом — это только отображение.
  • Секундной стрелки обычно нет — только часы и минуты.
  • Обновляется автоматически каждую минуту.
  • Может быть любого размера: маленький — как иконка, большой — как часы на главном экране.

Когда использовать

  • Главный экран приложения — декоративные часы.
  • Экран блокировки — часы в стиле классических.
  • Виджет на рабочем столе — если приложение само является виджетом.
  • Приложения-органайзеры — где нужно показать время.
  • Игры или приложения в ретро-стиле — аналоговые часы добавляют атмосферу.

В большинстве современных приложений используются цифровые часы. AnalogClock — скорее декоративный выбор.

Настройки

Настройка Что делает Значения
Width / Height Размеры виджета. Должны быть равны, чтобы получился ровный круг. Число в dp. Например, 120dp × 120dp.
Background Фон под часами. HEX, drawable-ресурс или NONE.
Padding / Margin Внутренние и внешние отступы. Число в dp.
Visibility Показывать/скрывать. visible, invisible, gone.

Свойства виджета

Открой панель свойств, тапнув по AnalogClock в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — analogclock1).

Основные

Свойство (рус / англ) Что делает Значения Пример

Padding		 Отступ внутри виджета. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 8 со всех сторон.
Внешний отступ
Margin		 Отступ снаружи виджета. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin top 16 — отступ от заголовка экрана.
Гравитация макета
Layout gravity		 Как виджет выравнивается внутри родителя. none — по умолчанию;

Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 0 — стандарт.

💡 Совет для новичков: у AnalogClock нет настроек времени или стиля стрелок — только размер и положение. Часы работают сразу после перетаскивания, без логики.

Как перетащить AnalogClock на макет

AnalogClock, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V) или RelativeLayout.
  3. Раскрой категорию Дата и время в палитре слева.
  4. Зажми AnalogClock и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — часы появятся в разметке.
  6. Задай Ширину и Высоту одинаковыми — например, 150dp × 150dp.
  7. Задай Внешний отступ — например, Margin top 16.
  8. Логика для отображения не нужна — часы работают сразу после добавления.
  9. Если часы должны показываться только при определённых условиях — управляй через setVisibility в событиях.
⚠️ Важно: обычный тап по AnalogClock в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: AnalogClock не даёт программно установить время. Он всегда показывает системное время устройства. Если нужно показать другое время — используй TextView с форматированием через Calendar.
⚠️ Важно: при Width ≠ Height циферблат будет выглядеть сплюснутым. Задавай одинаковые значения.
💡 Совет: для декора на главном экране используй AnalogClock размером 150dp × 150dp. Это оптимальный размер, чтобы стрелки были различимы и циферблат не занимал пол-экрана.
💡 Совет: для ретро-стиля используй AnalogClock в сочетании с деревянным фоном или старинными шрифтами. Отлично смотрится в приложениях-органайзерах.
💡 Совет: если приложение требует точного времени (например, для будильника или напоминания), AnalogClock недостаточен — нужен TimePicker или Calendar.
❌ Частая ошибка: использовать AnalogClock там, где нужно выбрать время. Для этого есть TimePicker — пользователь двигает стрелки сам.
❌ Частая ошибка: задавать разные Width и Height и удивляться, почему часы сплюснутые.
❌ Частая ошибка: пытаться изменить время на часах через логику. AnalogClock этого не позволяет — только системное время.

Резюме

  • AnalogClock — аналоговые часы со стрелками, показывающие системное время устройства.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Работает автоматически — логика для отображения не нужна.
  • Не позволяет установить время вручную — только отображение.
  • Ключевые параметры: Ширина и Высота (равные, для ровного круга), Отступы.
  • Для декора — размер 150dp; для иконки — 80dp; для крупного — 200dp+.
  • Для выбора времени используй TimePicker, а не AnalogClock.
  • Показывает только часы и минуты, без секунд.

Частые ошибки новичков

  • Тапают по AnalogClock в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Используют там, где нужен выбор времени. Для этого TimePicker.
  • Задают разные Width и Height. Получается сплюснутый циферблат.
  • Пытаются установить своё время. AnalogClock показывает только системное.
  • Добавляют часы на весь экран. Слишком громоздко — 150dp достаточно.
  • Ищут настройки стиля стрелок. Их нет — только размер и положение.
  • Пытаются сделать через них будильник. Нужен TimePicker + AlarmManager.
