Менеджер звуков

Менеджер звуков — раздел меню «Настройка», через который добавляются аудиофайлы в проект: музыка, звуковые эффекты, клики, уведомления.

Иконка в меню — нотный знак.

Что можно делать

  • Добавлять аудиофайлы из памяти устройства.
  • Просматривать список загруженных звуков.
  • Удалять ненужные.
  • Использовать в MediaPlayer и SoundPool через имя файла.

Какие звуки загружать

  • Короткие клики — для обратной связи на нажатие (50–500 мс).
  • Звуковые эффекты — выстрелы, всплески, победа (0.5–2 сек).
  • Фоновую музыку — для игр или медитаций (1–5 мин).
  • Уведомления — звук нового сообщения (1–3 сек).
  • Озвучку — короткие фразы для интерфейса.

Форматы

  • MP3 — универсальный, работает везде.
  • OGG — лучший для коротких звуков, легче MP3.
  • WAV — без сжатия, качественный, но большой.
  • M4A / AAC — современный формат, компактный.

Для Sketchware рекомендуется MP3 или OGG.

Как добавить

  • Открой меню ⋮ → Менеджер звуков.
  • Нажми кнопку «+» или «Добавить».
  • Выбери аудиофайл из памяти устройства.
  • Дай ему имя — латиницей, без пробелов.
  • Нажми «Сохранить» — звук появится в списке.

Как использовать

  • MediaPlayer — для длинных треков:
    • setSource → выбери звук;
    • prepare → подготовь;
    • start → воспроизведи.
  • SoundPool — для коротких звуков:
    • load в onCreate → загрузи звук;
    • play → воспроизведи.

Как удалить

  • Открой Менеджер звуков.
  • Найди нужный звук.
  • Используй контекстное меню → «Удалить».
  • Подтверди удаление.

⚠️ Важно: не используй кириллицу в именах файлов. Android может не найти такой звук.

⚠️ Важно: не загружай большие аудио. Трек 5 МБ серьёзно увеличит APK. Для длинной музыки используй поток из интернета через MediaPlayer с URL.

⚠️ Важно: не удаляй используемый звук. Приложение перестанет воспроизводить его или упадёт.

⚠️ Важно: следи за лицензией на музыку. Нельзя использовать чужие треки без разрешения. Для коммерческих проектов — только лицензированные или свободные (Creative Commons).

💡 Совет: для кликов используй OGG — маленький размер и мгновенное воспроизведение.

💡 Совет: для фоновой музыки в игре загрузи один трек и установи setLooping = true. Он будет играть по кругу.

💡 Совет: для эффектов используй короткие файлы (до 2 секунд). Всё, что длиннее — уже музыка, для неё MediaPlayer.

💡 Совет: не используй MP3 для коротких кликов — есть задержка в начале. Для коротких звуков лучше OGG.

💡 Совет: оптимизируй звуки — уменьшай битрейт до 96–128 kbps. Для большинства приложений этого достаточно.

💡 Совет: для бесплатных звуков используй сервисы: Freesound, Zapsplat, Mixkit. Там есть библиотеки бесплатных эффектов.

❌ Частая ошибка: загружать музыку в MP3 высокого качества (320 kbps). Это лишний вес без слышимой разницы.

❌ Частая ошибка: использовать MP3 для кликов. Задержка в начале делает звук «запоздалым».

❌ Частая ошибка: кириллица в именах файлов. Android не находит их.

❌ Частая ошибка: использовать чужие треки без лицензии. Для Google Play — только свободные или купленные.

❌ Частая ошибка: удалять используемые звуки. Приложение перестаёт работать.
