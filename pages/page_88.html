WaveSideBar — алфавитный указатель

WaveSideBar — боковая панель с волновой анимацией. Располагается вертикально по правому краю экрана и позволяет быстро перейти к нужному разделу списка — обычно по алфавиту. При касании буква «выныривает» волной и показывает выбранный символ.

Иконка в палитре — вертикальная полоса с буквами.

Как работает

  • Отображается вдоль правого края экрана — узкая вертикальная полоса.
  • Содержит набор символов: A, B, C, … Z, # (или кириллицу, цифры — в зависимости от настройки).
  • При тапе по символу срабатывает волновая анимация, и логика может прокрутить список до нужной группы.
  • Обычно используется вместе с ListView или RecyclerView — для быстрой навигации по большому алфавитному списку.

Когда использовать

  • Список контактов — навигация по алфавиту.
  • Список городов или стран — большие алфавитные списки.
  • Каталог товаров — если он организован по буквам.
  • Музыкальный плеер — переход по первой букве исполнителя.
  • Список терминов или статей — справочники с алфавитным порядком.

WaveSideBar бесполезен, если список маленький или не отсортирован по алфавиту.

Настройки

Настройка Что делает Значения
TextColor Цвет символов на панели. HEX или выбор из палитры.
TextSize Размер символов. Число в sp.
TextAlign Выравнивание символов. left, center, right.
SideBarPosition Положение панели. left или right.
MaxOffset Величина «волны» — насколько далеко выносится активный символ. Число в dp.
Background Фон панели. HEX или drawable-ресурс.
Width / Height Ширина и высота. Обычно wrap_content по ширине, match_parent по высоте.

💡 Совет для новичков: ключевые параметры (SideBarPosition, TextAlign, MaxOffset) задаются через Пользовательские атрибуты — в виде app:sidebar_position="right", app:sidebar_text_alignment="center". В обычной панели свойств доступны только Размер текста и Цвет текста.

Как перетащить WaveSideBar на макет

WaveSideBar, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — лучше всего RelativeLayout, чтобы панель прижалась к правому краю.
  3. Раскрой категорию Библиотеки в палитре слева.
  4. Зажми WaveSideBar и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — панель появится в разметке.
  6. В свойствах задай Размер текста и Цвет текста.
  7. Через Пользовательские атрибуты задай app:sidebar_position="right", app:sidebar_text_alignment="center", при необходимости app:max_offset.
  8. Для RelativeLayout задай панели alignParentRight и centerVertical.
  9. Присвой осмысленный ID — он нужен для логики.
  10. Открой вкладку «События» — добавь событие выбора символа и опиши логику прокрутки списка.
⚠️ Важно: обычный тап по WaveSideBar в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: WaveSideBar не работает сам по себе. Он только показывает символы и сообщает логике, какой из них выбран. Прокрутка списка — твоя задача.
⚠️ Важно: для RelativeLayout задавай панели привязку к правому краю (alignParentRight) и по центру по вертикали (centerVertical). Иначе она окажется в левом верхнем углу.
💡 Совет: используй WaveSideBar только в тех случаях, где список действительно длинный. Для 5–10 элементов он не нужен.
💡 Совет: для списка с русскими названиями задай кириллический алфавит в свойствах (А–Я) — так пользователю привычнее.
💡 Совет: не нагружай WaveSideBar лишними символами. Стандарт — 26–33 буквы. Цифры и знаки добавляй только при реальной необходимости.
❌ Частая ошибка: перетащить WaveSideBar и ждать, что список сам будет прокручиваться. Компонент только сообщает о выборе — логику прокрутки пиши сам.
❌ Частая ошибка: использовать WaveSideBar со списком без алфавитной сортировки. Символы будут, но пользы от них ноль.

Резюме

  • WaveSideBar — боковая панель с алфавитным указателем и волновой анимацией.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Обычно используется в связке с ListView или RecyclerView — для быстрой навигации по большому списку.
  • Располагается у правого или левого края — задаётся через app:sidebar_position в «Пользовательских атрибутах».
  • Сам не прокручивает список — нужно описывать логику в событиях.
  • Имеет смысл только для больших отсортированных списков (контакты, города, справочники).
  • Основные свойства: Размер текста, Цвет текста, SideBarPosition, TextAlign.

Частые ошибки новичков

  • Тапают по WaveSideBar в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Ждут, что список будет прокручиваться сам. Логику прокрутки нужно написать в событиях.
  • Используют для короткого или не отсортированного списка. Панель бесполезна.
  • Забывают задать привязку к краю в RelativeLayout. Панель оказывается в левом верхнем углу.
  • Ищут SideBarPosition в обычных свойствах. Через «Пользовательские атрибуты» — app:sidebar_position.
  • Не задают ID. Логика не может обратиться к панели.
  • Пишут слишком много символов на панели. Мелко и неудобно — лучше только буквы алфавита.
