WaveSideBar — алфавитный указатель

WaveSideBar — боковая панель с волновой анимацией. Располагается вертикально по правому краю экрана и позволяет быстро перейти к нужному разделу списка — обычно по алфавиту. При касании буква «выныривает» волной и показывает выбранный символ.

Иконка в палитре — вертикальная полоса с буквами.

Как работает

  • Отображается вдоль правого края экрана — узкая вертикальная полоса.
  • Содержит набор символов: A, B, C, … Z, # (или кириллицу, цифры — в зависимости от настройки).
  • При тапе по символу срабатывает волновая анимация, и логика может прокрутить список до нужной группы.
  • Обычно используется вместе с ListView или RecyclerView — для быстрой навигации по большому алфавитному списку.

Когда использовать

  • Список контактов — навигация по алфавиту.
  • Список городов или стран — большие алфавитные списки.
  • Каталог товаров — если он организован по буквам.
  • Музыкальный плеер — переход по первой букве исполнителя.
  • Список терминов или статей — справочники с алфавитным порядком.

WaveSideBar бесполезен, если список маленький или не отсортирован по алфавиту.

Основные свойства

  • TextColor — цвет символов на панели.
  • TextSize — размер символов.
  • TextAlign — выравнивание символов.
  • SideBarPosition — положение панели: слева или справа.
  • MaxOffset — величина «волны» — насколько далеко выносится активный символ.
  • Background — фон панели.
  • Width / Height — обычно wrap_content по ширине, match_parent по высоте.

Как добавить

  • Выбери контейнер — обычно RelativeLayout, чтобы панель прижалась к правому краю.
  • Тап по WaveSideBar в палитре — компонент добавится внутрь.
  • В свойствах задай TextColor, TextSize и SideBarPosition.
  • Присвой id — для работы в логике.
  • Открой вкладку «События» — добавь событие выбора символа.
  • Внутри события опиши логику: прокрутить ListView или RecyclerView до нужной группы.

⚠️ Важно: WaveSideBar не работает сам по себе. Он только показывает символы и сообщает логике, какой из них выбран. Прокрутка списка — твоя задача.

⚠️ Важно: для RelativeLayout задавай панели привязку к правому краю (alignParentRight) и по центру по вертикали (centerVertical). Иначе она окажется в левом верхнем углу.

💡 Совет: используй WaveSideBar только в тех случаях, где список действительно длинный. Для 5–10 элементов он не нужен.

💡 Совет: для списка с русскими названиями задай кириллический алфавит в свойствах (А–Я) — так пользователю привычнее.

💡 Совет: не нагружай WaveSideBar лишними символами. Стандарт — 26–33 буквы. Цифры и знаки добавляй только при реальной необходимости.

❌ Частая ошибка: добавить WaveSideBar и ждать, что список сам будет прокручиваться. Компонент только сообщает о выборе — логику прокрутки пиши сам.

❌ Частая ошибка: использовать WaveSideBar со списком без алфавитной сортировки. Символы будут, но пользы от них ноль.
