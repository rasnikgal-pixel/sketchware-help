CollapsingToolbar — съезжающая панель

CollapsingToolbar — «сворачивающийся» тулбар. Это шапка экрана, которая плавно уменьшается при прокрутке содержимого. В развёрнутом виде — большая панель с картинкой и крупным заголовком, при прокрутке — компактная строка с мелким заголовком.

Иконка в палитре — прямоугольник с полосой сверху и стрелкой вниз.

Как работает

  • Сверху экрана — большая панель с изображением и текстом.
  • Пользователь начинает прокручивать содержимое вниз.
  • Панель плавно сворачивается: изображение уходит, заголовок сжимается и «прилипает» к верху.
  • В свёрнутом состоянии это обычный тулбар с мелким текстом.

Типичный пример — карточка профиля в мессенджере или страница товара в интернет-магазине.

Из чего состоит

  • AppBarLayout — контейнер для всей шапки. Управляет поведением при прокрутке.
  • CollapsingToolbarLayout — сам сворачивающийся элемент.
  • Toolbar — тулбар внутри, который становится компактным.
  • ImageView — фоновое изображение шапки (опционально).
  • CoordinatorLayout — корневой контейнер, обеспечивающий взаимодействие шапки и содержимого.

Когда использовать

  • Экран профиля — большая аватарка сверху, при прокрутке сворачивается.
  • Страница товара — фото товара во всю ширину, при прокрутке превращается в маленький тулбар.
  • Статья или пост — обложка сверху, сжимается при чтении.
  • Карточка события — изображение и название, плавно уменьшаются.

Настройки

Настройка Что делает Значения
CollapsedTitleText Заголовок в свёрнутом состоянии (мелкий, в тулбаре). Любая строка.
ExpandedTitleText Заголовок в развёрнутом состоянии (крупный, на картинке). Любая строка.
ContentScrimColor Цвет фона шапки после сворачивания. HEX или выбор из палитры.
StatusBarScrimColor Цвет строки статуса при сворачивании. HEX или выбор из палитры.
CollapsedTitleTextColor / ExpandedTitleTextColor Цвета текста заголовков в свёрнутом и развёрнутом состоянии. HEX или выбор из палитры.
ScrimAnimationDuration Длительность анимации сворачивания. Число в миллисекундах.

Свойства контейнера

Открой панель свойств, тапнув по CollapsingToolbar в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — collapsingtoolbar1).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя компонента. По этому имени он виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — collapsingtoolbar1, collapsingtoolbar2 и т. д. Переименуй в profileHeader, если это шапка профиля.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». На скриншоте заданы android:fitsSystemWindows="true" и app:layout_scrollFlags="scroll|exitUntilCollapsed" — обязательные для корректной работы.
Конвертировать Показывает полный класс компонента: com.google.android.material.appbar.CollapsingToolbarLayout. CollapsingToolbarLayout (Material) и другие. Обычно менять не нужно.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широкой будет панель по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent — стандарт.
Высота
Height		 Насколько высокой будет панель по вертикали. match_parent, wrap_content, число в dp. wrap_content — типично, но при желании можно задать фиксированную высоту, например 200dp.
Внутренний отступ
Padding		 Отступ внутри панели — от краёв до содержимого. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 8 со всех сторон.
Внешний отступ
Margin		 Отступ снаружи панели — от неё до соседних элементов и краёв родителя. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Обычно 0 — панель должна занимать край экрана.
Гравитация макета
Layout gravity		 Как панель выравнивается внутри родителя. none — по умолчанию;
например, top, center_horizontal.		 Обычно оставляют none.
Вес
Weight		 Доля свободного места родителя, которую займёт эта панель. Работает только внутри родителя с весом. Число. 0 — вес не задан. 0 — стандарт.

выкл — заблокировано.		 На скриншоте — включено.
Вращение
Rotation		 Поворот панели вокруг центра. Градусы. 0 — без поворота. Обычно оставляют 0.
Прозрачность
Alpha		 Насколько панель прозрачна. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.
TranslationX Сдвиг панели по горизонтали без изменения её места в разметке. Число в dp. 0.0 — без сдвига. 20.0 — визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг панели по вертикали без изменения её места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.

ScaleY Масштаб по вертикали — растягивает или сжимает панель по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: в панели свойств доступны только базовые свойства. Главные параметры (заголовки, цвета scrim, длительность анимации) задаются через Пользовательские атрибуты — там нужно вручную прописать app:collapsedTitleText, app:expandedTitleText, app:contentScrim и так далее.

Как перетащить CollapsingToolbar на макет

CollapsingToolbar, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Раскрой категорию AndroidX в палитре слева.
  3. Зажми CollapsingToolbar и, не отпуская, перетащи его на макет.
  4. Отпусти в нужном месте — панель появится в разметке.
  5. В свойствах задай базовые параметры: Ширина, Высота, Пользовательские атрибуты.
  6. Внутрь панели перетащи ImageView — картинку шапки, и Toolbar — тулбар.
  7. Ниже добавь содержимое экрана внутри NestedScrollView.
⚠️ Важно: обычный тап по CollapsingToolbar в палитре ничего не делает. Панель попадает на макет только перетаскиванием.
⚠️ Важно: CollapsingToolbar не работает без CoordinatorLayout. Если он вставлен в обычный Linear(V), поведение при прокрутке не сработает — панель останется статичной.
⚠️ Важно: содержимое экрана должно быть внутри специального контейнера NestedScrollView, иначе прокрутка не будет связана с шапкой. Обычный Scroll(V) не подойдёт.
💡 Совет: не перегружай шапку содержимым. Идеально: одна картинка + один заголовок. Больше — выглядит громоздко и мешает восприятию.
💡 Совет: для первого проекта пропусти этот компонент. Он сложнее остальных AndroidX-виджетов и требует ручной настройки структуры CoordinatorLayout + AppBarLayout + NestedScrollView. Вернись к нему, когда освоишь основы.
❌ Частая ошибка: перетащить CollapsingToolbar в обычный Linear(V) и ждать анимации сворачивания. Без CoordinatorLayout она не сработает.

Резюме

  • CollapsingToolbar — «сворачивающаяся» шапка экрана: большая панель плавно уменьшается при прокрутке.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Требует специальной структуры: CoordinatorLayout → AppBarLayout → CollapsingToolbarLayout → Toolbar / ImageView.
  • Содержимое экрана оборачивается в NestedScrollView, а не в обычный Scroll(V).
  • Ключевые атрибуты (collapsedTitleText, expandedTitleText, contentScrim) задаются через «Пользовательские атрибуты».
  • Для новичков — самый сложный компонент категории AndroidX. Начинать лучше с CardView и TextInputLayout.

Частые ошибки новичков

  • Тапают по CollapsingToolbar в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетаскивают CollapsingToolbar в Linear(V). Без CoordinatorLayout сворачивание не работает.
  • Используют обычный Scroll(V) для содержимого. Нужен именно NestedScrollView.
  • Забывают про app:layout_scrollFlags. Без него панель не реагирует на прокрутку.
  • Пытаются задать заголовок через обычные свойства. Заголовки задаются только через пользовательские атрибуты.
  • Перегружают шапку содержимым. Много элементов ломают анимацию и выглядят громоздко.
  • Берутся за этот компонент в первом проекте. Он требует опыта работы с CoordinatorLayout и AppBarLayout.
