ObjectAnimator — анимации объектов

ObjectAnimator — компонент для анимации объектов. Плавно меняет свойства виджетов: прозрачность, положение, масштаб, поворот. Не требует XML-анимаций — работает из логики.

Иконка в диалоге добавления — круг с линией (движение).

Как работает

  • Анимирует свойства виджета: alpha, translationX, translationY, scaleX, scaleY, rotation.
  • Задаётся длительность анимации в миллисекундах.
  • Может повторяться определённое число раз или бесконечно.
  • Может изменяться во времени по-разному: линейно, ускоренно, замедленно.
  • Позволяет запускать несколько анимаций одновременно или последовательно.
  • При завершении срабатывает событие — можно запустить следующую анимацию.

Когда использовать

  • Появление элементов — плавное «выезжание» сбоку.
  • Исчезновение — затухание через прозрачность.
  • Внимание — покачивание кнопки.
  • Переходы — плавное смещение между экранами.
  • Игровые эффекты — прыжки, вращения, увеличение.
  • Обратная связь — подсветка, увеличение при нажатии.
  • Анимация картинок — вращение, масштабирование.

Основные настройки при добавлении

  • Имя компонента — идентификатор для вызова. Например, fadeIn.

Основные блоки в логике

  • setTarget — задать виджет, который будет анимирован.
  • setPropertyName — какое свойство менять: alpha, translationX, translationY, scaleX, scaleY, rotation.
  • setFloatValues — значения от и до (например, 0f и 1f для прозрачности).
  • setDuration — длительность в миллисекундах.
  • setRepeatCount — количество повторов (-1 — бесконечно).
  • setRepeatMode — режим повтора: с начала или в обратную сторону.
  • setInterpolator — тип ускорения: линейный, ease-in, ease-out, bounce.
  • start — запустить анимацию.
  • cancel — отменить анимацию.

Основные свойства для анимации

  • alpha — прозрачность: 0f (невидим) → 1f (полностью видим).
  • translationX — горизонтальное смещение в пикселях.
  • translationY — вертикальное смещение в пикселях.
  • scaleX / scaleY — масштаб: 1f (оригинал), 1.5f (увеличение).
  • rotation — поворот в градусах: 0f → 360f.
  • rotationX / rotationY — поворот в 3D.

Как использовать

  • Подключи компонент ObjectAnimator на вкладке «Компонент».
  • Задай имя — например, fadeAnimator.
  • В логике:
    • setTarget — какой виджет анимировать;
    • setPropertyName — какое свойство;
    • setFloatValues — от какого значения к какому;
    • setDuration — длительность;
    • start — запуск.
  • Для цепочки анимаций используй событие onAnimationEnd или комбинируй несколько ObjectAnimator.

Пример: плавное появление кнопки

  • Кнопка Button с id = myButton.
  • ObjectAnimator: alpha от 0f до 1f, длительность 500 мс.
  • В onCreate — вызов start.
  • Кнопка плавно появляется за полсекунды.

Пример: подпрыгивание иконки

  • ObjectAnimator 1: translationY от 0f до -30f, длительность 150 мс.
  • ObjectAnimator 2: translationY от -30f до 0f, длительность 150 мс.
  • Запуск второго в событии завершения первого.
  • Результат — иконка подпрыгивает.

⚠️ Важно: значения задаются с суффиксом f (float). Например, 0f, 1f, -30f. Без суффикса блоки могут не принимать значения.

⚠️ Важно: координаты translationX / translationY — в пикселях, а не в dp. На разных экранах одно и то же значение выглядит по-разному.

⚠️ Важно: alpha работает только с виджетами, у которых есть фон. Если у TextView нет фона, прозрачность текста будет, но фон не увидишь.

⚠️ Важно: не запускай слишком много анимаций одновременно. На слабых устройствах это вызывает подтормаживание.

💡 Совет: для плавного появления используй alpha от 0f до 1f, длительность 300–500 мс.

💡 Совет: для «внимания» используй scaleX / scaleY от 1f до 1.1f и обратно. Эффект «пульсации».

💡 Совет: для сдвига сбоку используй translationX от -300f до 0f. Элемент «выезжает» слева.

💡 Совет: для вращения используй rotation от 0f до 360f. Полезно для индикаторов загрузки.

💡 Совет: для отскока используй setInterpolator со значением bounce. Движение будет пружинистым.

💡 Совет: не злоупотребляй анимациями. Много одновременных эффектов раздражает пользователя и замедляет устройство.

❌ Частая ошибка: забыть про f при задании значений. Без суффикса блок не примет значение.

❌ Частая ошибка: использовать большие значения translation без учёта размеров экрана. На маленьких устройствах элемент уходит за пределы.

❌ Частая ошибка: анимировать сразу 10+ виджетов. Устройство не справляется.

❌ Частая ошибка: не отменять анимацию при уходе с экрана. Анимация может продолжиться в фоне и расходовать батарею.

❌ Частая ошибка: путать alpha и видимость. alpha = 0f — прозрачность, но виджет всё ещё занимает место. setVisibility = gone — полностью скрывает.
