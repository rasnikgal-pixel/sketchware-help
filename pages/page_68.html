Button — кнопка

Button — обычная кнопка. Виджет, на который пользователь нажимает, чтобы выполнить действие: отправить форму, запустить вычисление, перейти на другой экран.

Иконка в палитре — закруглённый прямоугольник с текстом.

Как работает

  • Отображает текст или иконку (или и то, и другое).
  • При нажатии срабатывает событие onClick — ты задаёшь, что должно произойти.
  • Имеет состояния: обычное, нажатое, отключённое.
  • При нажатии появляется подсветка — стандартный ripple-эффект Android.

Когда использовать

  • Отправка форм — «Войти», «Зарегистрироваться», «Отправить».
  • Действия с данными — «Сохранить», «Удалить», «Обновить».
  • Переходы между экранами — «Открыть», «Далее».
  • Запуск вычислений — «Посчитать», «Конвертировать».
  • Любое действие по нажатию.

Настройки

Настройка Что делает Значения
Text Текст на кнопке. Любая строка.
TextColor Цвет текста. HEX или выбор из палитры.
TextSize Размер текста. Число в sp.
Background Фон кнопки — цвет или изображение. HEX, drawable-ресурс или NONE.
TextStyle Начертание текста. normal, bold, italic.
Gravity Выравнивание текста внутри кнопки. left, center, right.
Enabled Активна ли кнопка. Если false — серая и не нажимается. Переключатель: вкл / выкл.
Clickable Реагирует ли на нажатие. Переключатель: вкл / выкл.
Padding / Margin Внутренние и внешние отступы. Число в dp для каждой стороны.
Width / Height Ширина и высота. wrap_content или match_parent.
AllCaps Показывать текст заглавными буквами. Переключатель: вкл / выкл. По умолчанию Android делает это автоматически.

Свойства виджета

Открой панель свойств, тапнув по Button в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — button1).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Без ID кнопка не появится в списке событий. Любая строка без пробелов. По умолчанию — button1, button2 и т. д. Переименуй в submitButton, если это кнопка отправки.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». Например, android:textAllCaps="false" — отключить автоматический капс.
Конвертировать Показывает тип виджета — Button. Обычно менять не нужно. Button и другие типы виджетов. Оставь как есть.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широкой будет кнопка по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent — для широкой кнопки «Войти» в форме.
Высота
Height		 Насколько высокой будет кнопка по вертикали. match_parent, wrap_content, число в dp. wrap_content — стандарт.
Внутренний отступ
Padding		 Отступ внутри кнопки — от краёв до текста. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 8 со всех сторон.
Внешний отступ
Margin		 Отступ снаружи кнопки — от неё до соседних элементов и краёв родителя. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin top 16 — кнопка сдвинется на 16 dp вниз от предыдущего элемента.
Положение
Position		 Позиционирование виджета внутри родителя (для RelativeLayout). none — по умолчанию;
например, center, alignParentBottom.		 Оставь none для Linear-контейнеров.
Гравитация макета
Layout gravity		 Как виджет выравнивается внутри родителя. none — по умолчанию;
например, center_horizontal, right.		 center_horizontal — кнопка встанет по центру родителя.
Вес
Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — кнопка заберёт всё оставшееся место.

Свойство (рус / англ) Что делает Значения Пример
Ресурс фона
Background resource		 Картинка-фон кнопки из ресурсов проекта. NONE — без фона;
любой drawable-ресурс.		 Обычно оставляют NONE — фон задают цветом.
Цвет фона
Background color		 Заливка кнопки сплошным цветом. NONE — без цвета (фон из темы);
HEX или выбор из палитры.		 Синий #2196F3 — для основной кнопки.
Enabled
Включено		 Активна ли кнопка. Если выкл — серая, не нажимается. Переключатель: вкл — активна;
выкл — заблокирована.		 На скриншоте — включено.
Вращение
Rotation		 Поворот кнопки вокруг центра. Градусы. 0 — без поворота. Обычно оставляют 0.
Прозрачность
Alpha		 Насколько кнопка прозрачна. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.

ScaleY Масштаб по вертикали — растягивает или сжимает кнопку по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: на первых порах достаточно свойств Текст, Размер текста, Цвет текста и Цвет фона. Не забудь задать ID и добавить onClick в событиях.

Как перетащить Button на макет

Button, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V), Linear(H) или RelativeLayout.
  3. Раскрой категорию Widgets в палитре слева.
  4. Зажми Button и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — кнопка появится в разметке.
  6. Тапни по кнопке и задай Текст — например, «Отправить».
  7. Присвой осмысленный ID — он нужен, чтобы кнопка появилась в списке событий.
  8. Открой вкладку «События» — добавь событие onClick для этой кнопки.
  9. Внутри onClick опиши блоки, которые должны выполниться при нажатии.
⚠️ Важно: обычный тап по Button в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: без onClick кнопка нажимается, но ничего не делает. Внешне реагирует (подсветка), но логики нет.
⚠️ Важно: без ID кнопка не появится в списке событий вкладки «События». Не забудь задать уникальный ID.
💡 Совет: для современного вида используй MaterialButton (следующий подпункт) — он умеет скруглённые углы, цвета фона и текста в стиле Material Design. Обычный Button выглядит устаревшим.
💡 Совет: отключай кнопку (Enabled = false), если действие сейчас недоступно. Например, кнопка «Отправить» неактивна, пока пользователь не заполнил форму. Это лучше, чем позволить нажать и выдать ошибку.
💡 Совет: текст на кнопке делай коротким: 1–2 слова. Длинные надписи «Нажмите здесь, чтобы отправить» выглядят плохо.
❌ Частая ошибка: использовать TextView как кнопку (с Clickable = true). Работает, но не имеет стиля кнопки — пользователь не понимает, что это можно нажать.
❌ Частая ошибка: задавать размер в dp вместо sp. При системном шрифте крупнее текст на кнопке останется мелким.

Резюме

  • Button — обычная кнопка, на которую пользователь нажимает для выполнения действия.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Размещается внутри контейнера — Linear(V), Linear(H), RelativeLayout.
  • Ключевые свойства: Текст, Размер текста, Цвет текста, Цвет фона, Enabled.
  • Для работы обязательно нужно событие onClick и осмысленный ID.
  • Если действие недоступно, отключай кнопку через Enabled = false.
  • Для современного вида используй MaterialButton из категории AndroidX.

Частые ошибки новичков

  • Тапают по Button в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Забывают про onClick. Кнопка нажимается, но ничего не происходит.
  • Не задают ID. Кнопка не появляется в списке событий на вкладке «События».
  • Пишут длинный текст на кнопке. «Нажмите здесь, чтобы отправить» — плохо. Лучше «Отправить».
  • Задают размер в dp вместо sp. Текст не масштабируется под системный шрифт.
  • Используют TextView с Clickable вместо Button. Пользователь не понимает, что это кнопка.
  • Не отключают кнопку, когда действие недоступно. Пользователь жмёт, получает ошибку — лучше Enabled = false.
