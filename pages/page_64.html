TextView — текст

TextView — базовый виджет для отображения текста. Самый часто используемый элемент интерфейса: заголовки, подписи, описания, метки — всё это TextView.

Иконка в палитре — буква T в квадрате.

Как работает

  • Отображает статичный текст, который ты задаёшь в свойствах.
  • Текст можно менять в логике — через блок setText в событиях.
  • Может содержать ссылку, HTML-разметку, несколько строк.
  • Поддерживает цвет, размер, начертание (жирный, курсив), выравнивание.
  • Может быть кликабельным — если включить Clickable.

Когда использовать

  • Заголовки экранов — крупный текст сверху.
  • Подписи к полям — что нужно ввести в EditText.
  • Описания — пояснения под кнопками.
  • Метки в списках — имя, дата, сумма.
  • Вывод результатов — например, результат вычисления в калькуляторе.
  • Любой статичный или динамически меняющийся текст на экране.

Основные свойства

  • Text — сам текст. Может содержать кириллицу, эмодзи, спецсимволы.
  • TextColor — цвет текста.
  • TextSize — размер (в sp).
  • TextStyle — normal, bold, italic, bold|italic.
  • Gravity — выравнивание: left, center, right, top, bottom.
  • MaxLines — максимальное число строк.
  • SingleLine — весь текст в одну строку (с обрезкой или многоточием).
  • Ellipsize — как обрезать длинный текст: end, start, middle, marquee.
  • Padding / Margin — внутренние и внешние отступы.
  • Width / Height — wrap_content или match_parent.
  • Clickable — реагирует ли на нажатие.
  • Background — цвет или изображение фона.

Как добавить

  • Выбери контейнер, в который хочешь положить текст.
  • Тап по TextView в палитре — виджет добавится внутрь.
  • Тап по TextView в рабочей области — откроется панель свойств.
  • Задай Text — например, «Привет, мир!».
  • Настрой размер, цвет и выравнивание.

⚠️ Важно: текст в TextView не переносится автоматически, если задан SingleLine = true. Длинный текст обрежется или превратится в бегущую строку при Ellipsize = marquee.

💡 Совет: для заголовков используй TextSize = 20–24sp, TextStyle = bold. Для основного текста — 14–16sp. Для подписей — 12–13sp и серый цвет.

💡 Совет: если текст должен меняться при работе приложения (результат вычислений, данные из сети), оставь поле Text пустым или поставь заглушку вроде «—». Реальное значение задавай в логике через блок setText.

💡 Совет: не делай слишком длинные тексты в TextView без переноса строк. Пользователю тяжело читать. Лучше несколько коротких TextView друг под другом.

❌ Частая ошибка: задавать размер в dp вместо sp. В dp текст не будет масштабироваться при изменении системного шрифта — пользователи с крупным шрифтом увидят мелкий текст.
