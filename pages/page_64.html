TextView — текст

TextView — базовый виджет для отображения текста. Самый часто используемый элемент интерфейса: заголовки, подписи, описания, метки — всё это TextView.

Иконка в палитре — буква T в квадрате.

Как работает

  • Отображает статичный текст, который ты задаёшь в свойствах.
  • Текст можно менять в логике — через блок setText в событиях.
  • Может содержать ссылку, HTML-разметку, несколько строк.
  • Поддерживает цвет, размер, начертание (жирный, курсив), выравнивание.
  • Может быть кликабельным — если включить Clickable.

Когда использовать

  • Заголовки экранов — крупный текст сверху.
  • Подписи к полям — что нужно ввести в EditText.
  • Описания — пояснения под кнопками.
  • Метки в списках — имя, дата, сумма.
  • Вывод результатов — например, результат вычисления в калькуляторе.
  • Любой статичный или динамически меняющийся текст на экране.

Настройки

Настройка Что делает Значения
Text Сам текст. Любая строка: кириллица, эмодзи, спецсимволы.
TextColor Цвет текста. HEX или выбор из палитры.
TextSize Размер текста. Число в sp (12–24 — обычный диапазон).
TextStyle Начертание текста. normal, bold, italic, bold|italic.
Gravity Выравнивание текста внутри виджета. left, center, right, top, bottom.
MaxLines Максимальное число строк. Число. 0 — без ограничения.
SingleLine (Однострочный) Весь текст в одну строку. Переключатель: вкл / выкл. На скриншоте — выкл.
Ellipsize Как обрезать длинный текст. end, start, middle, marquee.
Padding / Margin Внутренние и внешние отступы. Число в dp для каждой стороны.
Width / Height Ширина и высота виджета. wrap_content или match_parent.
Clickable Реагирует ли на нажатие. Переключатель: вкл / выкл.
Background Цвет или изображение фона. HEX, drawable-ресурс или NONE.

💡 Совет для новичков: на первых порах достаточно свойств Текст, Размер текста, Стиль текста и Цвет текста. Остальные оставь по умолчанию и трогай при необходимости.

Как перетащить TextView на макет

TextView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V), Linear(H) или RelativeLayout.
  3. Раскрой категорию Widgets в палитре слева.
  4. Зажми TextView и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — TextView появится в разметке.
  6. Тапни по нему в рабочей области — откроется панель свойств.
  7. Задай Текст — например, «Привет, мир!».
  8. Настрой Размер текста, Стиль текста, Цвет текста и выравнивание.
⚠️ Важно: обычный тап по TextView в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: текст в TextView не переносится автоматически, если задан SingleLine = true. Длинный текст обрежется или превратится в бегущую строку при Ellipsize = marquee.
💡 Совет: для заголовков используй TextSize = 20–24sp, TextStyle = bold. Для основного текста — 14–16sp. Для подписей — 12–13sp и серый цвет.
💡 Совет: если текст должен меняться при работе приложения (результат вычислений, данные из сети), оставь поле Text пустым или поставь заглушку вроде «—». Реальное значение задавай в логике через блок setText.
💡 Совет: не делай слишком длинные тексты в TextView без переноса строк. Пользователю тяжело читать. Лучше несколько коротких TextView друг под другом.
❌ Частая ошибка: задавать размер в dp вместо sp. В dp текст не будет масштабироваться при изменении системного шрифта — пользователи с крупным шрифтом увидят мелкий текст.

Резюме

  • TextView — базовый виджет для отображения текста.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Размещается внутри контейнера — Linear(V), Linear(H), RelativeLayout.
  • Ключевые свойства: Текст, Размер текста, Стиль текста, Цвет текста.
  • Размер текста указывается в sp, а не в dp.
  • Текст можно менять в логике через блок setText.
  • Для заголовков — 20–24sp bold; для основного текста — 14–16sp; для подписей — 12–13sp.

Частые ошибки новичков

  • Тапают по TextView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Задают размер в dp вместо sp. Текст не масштабируется под системный шрифт.
  • Ставят SingleLine = true, а потом удивляются, что текст обрезан. Нужно либо выключить, либо задать Ellipsize.
  • Пытаются отцентрировать текст через Layout gravity. Для центрирования текста внутри виджета нужно свойство Gravity, а не Layout gravity.
  • Забывают про ID. Если текст будет меняться из логики — задай осмысленный ID.
  • Пишут длинные тексты в один TextView. Читать неудобно — лучше разбить на несколько.
  • Хотят сделать текст кликабельным, но забывают включить Clickable. Без этого события onClick не сработают.
