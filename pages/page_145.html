Notification — уведомления

Notification — компонент для показа системных уведомлений. Отображает сообщения в шторке уведомлений Android: вне приложения, поверх других окон, с иконкой и текстом.

Иконка в диалоге добавления — колокольчик.

Как работает

  • Создаёт системное уведомление — как у мессенджеров и почтовых клиентов.
  • Отображается в шторке — пользователь видит его при свайпе сверху вниз.
  • Может содержать заголовок, текст, иконку.
  • Может открывать Activity при тапе по уведомлению.
  • Может звучать, вибрировать — с настройкой по каналу.
  • Требует разрешения POST_NOTIFICATIONS на Android 13+.

Когда использовать

  • Напоминания — «Пора пить воду».
  • Будильник — сигнал в заданное время.
  • Сообщения — новое сообщение в чате.
  • Обновления — «Доступна новая версия».
  • События в приложении — «Ваш заказ готов».
  • Задачи — «У вас 3 новых задания».
  • Оповещения — о чём угодно, что требует внимания пользователя.

Основные настройки при добавлении

  • Имя компонента — идентификатор для вызова. Например, myNotification.
  • Канал — группа уведомлений (например, «Напоминания», «Сообщения»).

Основные блоки в логике

  • setTitle — заголовок уведомления.
  • setMessage — текст уведомления.
  • setSmallIcon — иконка (маленькая).
  • setLargeIcon — большая иконка (опционально).
  • setSound — звук при показе.
  • setVibrate — вибрация при показе.
  • show — показать уведомление.
  • cancel — убрать уведомление.

Как использовать

  • Подключи компонент Notification на вкладке «Компонент».
  • Задай имя — например, alarmNotif.
  • Настрой канал — например, «Напоминания» с высоким приоритетом (звук + вибрация).
  • Добавь разрешение POST_NOTIFICATIONS для Android 13+.
  • В логике:
    • задай setTitle и setMessage;
    • задай setSmallIcon — иконку из ресурсов;
    • при необходимости — звук и вибрацию;
    • вызови show — уведомление появится в шторке.
  • Для открытия Activity по тапу — настрой Intent внутри уведомления.

Пример: напоминание

  • Пользователь установил время через TimePickerDialog.
  • При наступлении времени — Notification.show() с заголовком «Напоминание» и текстом «Пора пить воду».
  • Уведомление появляется в шторке, звучит и вибрирует.
  • Пользователь тапает — открывается приложение.

Пример: будильник

  • Задай канал с высоким приоритетом.
  • Установи звук и вибрацию.
  • show в нужное время — уведомление будит пользователя.

⚠️ Важно: для Android 13+ нужно разрешение POST_NOTIFICATIONS. Без него уведомления не показываются.

⚠️ Важно: канал уведомлений создаётся при первом использовании. Пользователь может его отключить в настройках Android — тогда уведомления не приходят.

⚠️ Важно: не спамь уведомлениями. Каждое уведомление — это внимание пользователя. Если приложение шлёт их десятками, пользователь отключит их или удалит приложение.

⚠️ Важно: для работы в фоне (например, напоминание через час, когда приложение закрыто) нужен AlarmManager. Простой Timer не сработает в фоне.

⚠️ Важно: иконка уведомления должна быть монохромной (одноцветной). Цветные иконки Android отображает как белый квадрат.

💡 Совет: для напоминаний используй канал с высоким приоритетом — звук, вибрация, всплывающее окно. Для информационных сообщений — канал с низким приоритетом.

💡 Совет: для открытия приложения по тапу — настрой Intent в уведомлении. Пользователь тапает — приложение открывается на нужном экране.

💡 Совет: для группировки уведомлений используй один канал для однотипных сообщений. Так пользователь может отключить их всех сразу.

💡 Совет: для будильника используй канал с максимальным приоритетом — он пробьётся через режим «Не беспокоить», если разрешено.

💡 Совет: не используй уведомления для рекламы. Пользователь быстро устаёт и отключает их.

💡 Совет: для тестирования сначала проверь уведомление с задержкой в несколько секунд, потом — с реальным временем.

❌ Частая ошибка: не запрашивать POST_NOTIFICATIONS для Android 13+. Уведомления не показываются.

❌ Частая ошибка: использовать цветную иконку. Android показывает её как белый квадрат — уведомление выглядит некрасиво.

❌ Частая ошибка: спамить уведомлениями. Пользователь отключает их или удаляет приложение.

❌ Частая ошибка: ожидать, что Timer сработает в фоне. При закрытом приложении Timer останавливается. Для фоновых напоминаний нужен AlarmManager.

❌ Частая ошибка: не настраивать Intent в уведомлении. Пользователь тапает — ничего не происходит.
