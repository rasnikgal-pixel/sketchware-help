FilePicker — выбор файла

FilePicker — компонент для выбора файла из памяти устройства. Открывает системный файловый менеджер, пользователь выбирает файл — приложение получает путь к нему.

Иконка в диалоге добавления — папка с файлом.

Как работает

  • Открывает системный файловый менеджер Android.
  • Пользователь выбирает файл из памяти: документ, картинку, видео, музыку.
  • Приложение получает путь к файлу (или URI).
  • Выбранный файл можно прочитать, отобразить, загрузить — в зависимости от типа.
  • Пользователь может отменить выбор — тогда вернётся пустой результат.

Когда использовать

  • Загрузка изображения — выбор аватарки или картинки.
  • Открытие документа — просмотр PDF, DOC, TXT.
  • Загрузка на сервер — выбор файла для отправки через RequestNetwork.
  • Импорт данных — выбор JSON, CSV, XML для парсинга.
  • Установка обоев — выбор картинки.
  • Работа с музыкой — выбор трека для воспроизведения.

Настройки при добавлении

Настройка Что задаёт Пример
Имя компонента Идентификатор для вызова в логике. fileChooser, picker.

Основные блоки в логике

Блок Что делает
openFilePicker Открыть системный выбор файла.
getFilePath Получить путь выбранного файла.
getFileName Получить имя файла.
getFileExtension Получить расширение (pdf, jpg, mp3).

Как использовать

  1. Подключи компонент FilePicker на вкладке «Компонент».
  2. Задай ему имя — например, picker.
  3. В логике добавь:
    • событие onFilePicked (если есть в версии) — срабатывает после выбора;
    • блок openFilePicker — запускает выбор;
    • блок getFilePath — читает путь.
  4. При отмене выбора проверяй, что путь не пустой, и не выполняй дальнейшие действия.
  5. Внутри события обрабатывай файл: показывай в ImageView, читай содержимое, отправляй на сервер.
⚠️ Важно: для работы с файлами часто нужны разрешения: READ_EXTERNAL_STORAGE. Без них выбор файла может не сработать.
⚠️ Важно: путь к файлу может быть недоступен для прямого чтения — в новых версиях Android используется URI вместо пути. Проверяй, что возвращает компонент.
⚠️ Важно: не пытайся читать файлы по пути без проверки разрешений. Приложение упадёт с SecurityException.
💡 Совет: для выбора картинки используй FilePicker вместе с ImageView. После выбора загружай картинку в ImageView через блок setImage.
💡 Совет: для загрузки на сервер используй FilePicker + RequestNetwork с Multipart. Файл передаётся в теле запроса.
💡 Совет: проверяй расширение файла перед обработкой. Пользователь может выбрать не тот тип — приложение должно корректно отреагировать.
💡 Совет: не заставляй пользователя искать файл наугад. Покажи подсказку: «Выберите изображение в формате JPG или PNG».
💡 Совет: для простого выбора изображения рассмотри альтернативу — Intent с ACTION_PICK для галереи. Иногда он проще, чем FilePicker.
❌ Частая ошибка: не запрашивать разрешения на чтение памяти. FilePicker открывается, но файл не читается.
❌ Частая ошибка: не проверять отмену выбора. Если пользователь закрыл диалог без выбора — путь пустой, и приложение может упасть.
❌ Частая ошибка: пытаться читать файл по пути в новых версиях Android. Там используется URI — путь может быть недоступен напрямую.
❌ Частая ошибка: не проверять тип файла. Пользователь выбирает видео, а приложение ждёт картинку — возможна ошибка.

Резюме

  • FilePicker — компонент для выбора файла из памяти устройства.
  • Открывает системный файловый менеджер Android.
  • Возвращает путь (или URI) к выбранному файлу.
  • Основные блоки: openFilePicker, getFilePath, getFileName, getFileExtension.
  • Обычно используется вместе с событиями onFilePicked или подобными.
  • Для работы часто нужны разрешения на чтение памяти.
  • Обрабатывай отмену выбора — путь может быть пустым.
  • Проверяй тип файла перед обработкой.

Частые ошибки новичков

  • Не запрашивают разрешения на память. Файл не читается.
  • Не проверяют отмену выбора. Приложение падает при пустом пути.
  • Используют путь в новых версиях Android. Нужен URI.
  • Не проверяют тип файла. Ошибки при обработке.
  • Не подсказывают формат. Пользователь выбирает что попало.
  • Используют FilePicker для простой галереи. Можно проще — через Intent.
  • Не обрабатывают onFilePicked. Выбор файла ничего не делает.
