CircleImageView — круглая картинка

CircleImageView — ImageView, который отображает изображение в круглой форме. Автоматически обрезает картинку по кругу, независимо от её исходных пропорций.

Иконка в палитре — круг с изображением внутри.

Как работает

  • Отображает картинку по кругу.
  • Любое изображение обрезается по форме круга.
  • Не нужно вручную делать круглую маску, использовать ShapeDrawable или библиотеки — всё встроено.
  • При одинаковой ширине и высоте круг получается идеальным.
  • Может быть кликабельным.
  • Поддерживает рамку вокруг картинки через BorderWidth и BorderColor.

Когда использовать

  • Аватарки пользователей — в профиле, чатах, комментариях.
  • Иконки в списках — например, логотипы брендов.
  • Контакты — телефонная книга, мессенджеры.
  • Подписки и подписчики — списки пользователей.
  • Любое место, где нужна круглая картинка с аккуратным краем.

Круглые аватарки — стандарт современных приложений. Квадратные уже не в моде.

Основные свойства

  • Image / Src — ссылка на изображение из Менеджера изображений.
  • BorderWidth — толщина рамки вокруг круга (в dp).
  • BorderColor — цвет рамки.
  • ScaleType — способ масштабирования картинки внутри круга. Обычно centerCrop.
  • Alpha — прозрачность.
  • Padding / Margin — внутренние и внешние отступы.
  • Width / Height — должны быть равны для идеального круга (например, 64dp на 64dp).
  • Clickable — реагирует ли на нажатие.

Как добавить

  • Выбери контейнер, куда хочешь положить аватарку.
  • Тап по CircleImageView в палитре — виджет добавится внутрь.
  • Задай Image / Src — выбери картинку из Менеджера изображений.
  • Задай Width и Height одинаковыми — например, 64dp и 64dp.
  • Задай ScaleType = centerCrop, чтобы картинка заняла весь круг.
  • Опционально: настрой BorderWidth и BorderColor для рамки.

⚠️ Важно: если Width ≠ Height, круг превратится в овал. Для ровного круга стороны должны быть равны.

⚠️ Важно: без ScaleType = centerCrop картинка может не заполнить круг полностью — по краям останутся пустые области.

💡 Совет: для аватарки пользователя в списке используй 48dp × 48dp. В профиле — 96dp × 96dp или больше.

💡 Совет: рамка BorderWidth = 2dp, BorderColor из темы — добавляет аккуратный стиль. Особенно хорошо смотрится на белых фонах.

💡 Совет: если картинка не круглая, а ты хочешь круг — обязательно centerCrop. Если оставить fitCenter, картинка впишется внутрь, а по краям круга появится фон.

❌ Частая ошибка: задавать разные значения Width и Height. Получится овал, а не круг.

❌ Частая ошибка: забыть про ScaleType. Картинка будет вписана в квадрат, а не заполнит круг.
