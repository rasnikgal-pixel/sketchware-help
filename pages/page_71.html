CircleImageView — круглая картинка

CircleImageView — ImageView, который отображает изображение в круглой форме. Автоматически обрезает картинку по кругу, независимо от её исходных пропорций.

Иконка в палитре — круг с изображением внутри.

Как работает

  • Отображает картинку по кругу.
  • Любое изображение обрезается по форме круга.
  • Не нужно вручную делать круглую маску, использовать ShapeDrawable или библиотеки — всё встроено.
  • При одинаковой ширине и высоте круг получается идеальным.
  • Может быть кликабельным.
  • Поддерживает рамку вокруг картинки через BorderWidth и BorderColor.

Когда использовать

  • Аватарки пользователей — в профиле, чатах, комментариях.
  • Иконки в списках — например, логотипы брендов.
  • Контакты — телефонная книга, мессенджеры.
  • Подписки и подписчики — списки пользователей.
  • Любое место, где нужна круглая картинка с аккуратным краем.

Круглые аватарки — стандарт современных приложений. Квадратные уже не в моде.

Настройки

Настройка Что делает Значения
Image / Src Ссылка на изображение из Менеджера изображений. Drawable-ресурс.
BorderWidth Толщина рамки вокруг круга. Число в dp. 0dp — без рамки. На скриншоте — 3dp.
BorderColor Цвет рамки. HEX или выбор из палитры. На скриншоте — #000000.
ScaleType Способ масштабирования картинки внутри круга. centerCrop — заполнить круг, обрезая лишнее (рекомендуется);
fitCenter — вписать, по краям может остаться фон.
Alpha Прозрачность. Число от 0 до 1.
Padding / Margin Внутренние и внешние отступы. Число в dp для каждой стороны.
Width / Height Ширина и высота. Должны быть равны для идеального круга. Число в dp. Например, 64dp и 64dp.
Clickable Реагирует ли на нажатие. Переключатель: вкл / выкл.

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — circleimageview1, circleimageview2 и т. д. Переименуй в avatarImage, если это аватарка.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Здесь задаётся рамка вокруг круга. Пары «атрибут = значение». На скриншоте заданы app:civ_border_width="3dp" и app:civ_border_color="#000000".
Конвертировать Показывает полный класс компонента: de.hdodenhof.circleimageview.CircleImageView. CircleImageView и другие типы виджетов. Оставь как есть.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет виджет по горизонтали. match_parent, wrap_content, число в dp. 64dp — стандартный размер аватарки в списке.
Высота
Height		 Насколько высоким будет виджет по вертикали. match_parent, wrap_content, число в dp. 64dp — должно совпадать с шириной для ровного круга.
Внутренний отступ
Padding		 Отступ внутри виджета — от краёв до картинки. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 0 со всех сторон.
Внешний отступ
Margin		 Отступ снаружи виджета — от него до соседних элементов. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin end 12 — между аватаркой и текстом.
Гравитация макета
Layout gravity		 Как виджет выравнивается внутри родителя. none — по умолчанию;
например, center_horizontal, right.		 center_horizontal — по центру родителя.
Вес
Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 0 — стандарт для аватарки.

Свойства изображения

Свойство (рус / англ) Что делает Значения Пример
Изображение
Image / Src		 Ссылка на изображение из Менеджера изображений проекта. Drawable-ресурс. По умолчанию — default_image. Выбери загруженную аватарку.
Тип масштабирования
ScaleType		 Как картинка масштабируется под размер круга. CENTER_CROP — заполнить круг, обрезая лишнее (рекомендуется);
FIT_CENTER — вписать, по краям может остаться фон. На скриншоте — CENTER.		 CENTER_CROP — заполнит круг полностью.
Ресурс фона
Background resource		 Картинка-фон виджета из ресурсов проекта. NONE — без фона;
любой drawable-ресурс.		 Обычно оставляют NONE.
Цвет фона
Background color		 Заливка виджета сплошным цветом. NONE — без цвета;
HEX или выбор из палитры.		 Серый фон под аватаркой — #CCCCCC.
Enabled
Включено		 Реагирует ли виджет на нажатия (если Clickable = true). Переключатель: вкл — активно;
выкл — заблокировано.		 На скриншоте — включено.
Вращение
Rotation		 Поворот виджета вокруг центра. Градусы. 0 — без поворота. Обычно оставляют 0.
Прозрачность
Alpha		 Насколько виджет прозрачен. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.
TranslationX Сдвиг виджета по горизонтали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. 20.0 — визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг виджета по вертикали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.
ScaleX Масштаб по горизонтали — растягивает или сжимает виджет по ширине. Число. 1.0 — исходный размер. 1.5 — ширина увеличится в 1,5 раза.
ScaleY Масштаб по вертикали — растягивает или сжимает виджет по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: ключевые параметры (BorderWidth, BorderColor) задаются через Пользовательские атрибуты — их нужно вручную прописать в виде app:civ_border_width="3dp", app:civ_border_color="#000000".

Как перетащить CircleImageView на макет

CircleImageView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V), Linear(H) или RelativeLayout.
  3. Раскрой категорию Widgets в палитре слева.
  4. Зажми CircleImageView и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — круглая картинка появится в разметке.
  6. Задай Ширину и Высоту одинаковыми — например, 64dp и 64dp.
  7. Задай Изображение — выбери картинку из Менеджера изображений.
  8. Задай Тип масштабирования = CENTER_CROP, чтобы картинка заняла весь круг.
  9. Через Пользовательские атрибуты задай app:civ_border_width и app:civ_border_color, если нужна рамка.
⚠️ Важно: обычный тап по CircleImageView в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: если Width ≠ Height, круг превратится в овал. Для ровного круга стороны должны быть равны.
⚠️ Важно: без ScaleType = centerCrop картинка может не заполнить круг полностью — по краям останутся пустые области.
💡 Совет: для аватарки пользователя в списке используй 48dp × 48dp. В профиле — 96dp × 96dp или больше.
💡 Совет: рамка BorderWidth = 2dp, BorderColor из темы — добавляет аккуратный стиль. Особенно хорошо смотрится на белых фонах.
💡 Совет: если картинка не круглая, а ты хочешь круг — обязательно centerCrop. Если оставить fitCenter, картинка впишется внутрь, а по краям круга появится фон.
❌ Частая ошибка: задавать разные значения Width и Height. Получится овал, а не круг.
❌ Частая ошибка: забыть про ScaleType. Картинка будет вписана в квадрат, а не заполнит круг.

Резюме

  • CircleImageView — ImageView, который автоматически обрезает картинку по кругу.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Для ровного круга Ширина должна быть равна Высоте.
  • Для заполнения круга задавай Тип масштабирования = CENTER_CROP.
  • Рамка задаётся через Пользовательские атрибуты: app:civ_border_width и app:civ_border_color.
  • Стандартные размеры: 48dp — в списке, 96dp+ — в профиле.
  • Для круглых аватарок CircleImageView удобнее обычного ImageView.

Частые ошибки новичков

  • Тапают по CircleImageView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Задают разные Width и Height. Получается овал, а не круг.
  • Оставляют ScaleType = CENTER. Картинка не заполняет круг — по краям виден фон.
  • Ищут BorderWidth и BorderColor в обычных свойствах. Их нужно задавать через «Пользовательские атрибуты».
  • Забывают про библиотеку CircleImageView. Без неё виджет не отобразится.
  • Используют CircleImageView для квадратной картинки. Обрежет по кругу — но если квадрат нужен, берите ImageView.
  • Ставят огромные размеры (200dp+) для аватарки в списке. Выглядит громоздко, лучше 48–64dp.
