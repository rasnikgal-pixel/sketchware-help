WebView — мини-браузер

WebView — встроенный браузер внутри приложения. Позволяет отображать веб-страницы без перехода в отдельный браузер: пользователь остаётся внутри твоего приложения.

Иконка в палитре — прямоугольник с глобусом или окном браузера.

Как работает

  • Отображает HTML-страницу по указанному URL.
  • Поддерживает HTML, CSS, JavaScript, изображения, формы.
  • Может загружать как внешние сайты (https://example.com), так и локальные HTML-файлы из ресурсов приложения.
  • Может взаимодействовать с JavaScript — вызывать функции на странице и получать ответы в логику.
  • Имеет встроенную историю навигации — кнопки «назад» и «вперёд».

Когда использовать

  • Отображение сайта внутри приложения — например, страница «О нас».
  • Пользовательское соглашение — HTML-текст.
  • Онлайн-помощь и FAQ — с сервера.
  • Интеграция с веб-сервисами — например, оплата, карта, чат поддержки.
  • Мини-игры на HTML5 — обёрнутые в приложение.
  • Просмотр PDF онлайн — через специальные сервисы.

Настройки

Настройка Что делает Значения
Url Адрес страницы (можно задать и в логике через loadUrl). URL сайта или путь к локальному файлу.
JavaScriptEnabled Разрешить выполнение JavaScript на странице. Переключатель: вкл / выкл.
DomStorageEnabled Разрешить локальное хранилище (localStorage). Переключатель: вкл / выкл.
BuiltInZoomControls Показывать элементы управления масштабом. Переключатель: вкл / выкл.
DisplayZoomControls Показывать или скрывать кнопки зума. Переключатель: вкл / выкл.
SupportZoom Разрешить масштабирование. Переключатель: вкл / выкл.
BackgroundColor Цвет фона WebView. HEX или выбор из палитры.
Width / Height Размеры. match_parent или wrap_content.

Свойства виджета

Открой панель свойств, тапнув по WebView в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — webview1).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — webview1, webview2 и т. д. Переименуй в helpView, если это страница помощи.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». Например, android:scrollbars="vertical".
Конвертировать Показывает тип виджета — WebView. Обычно менять не нужно. WebView и другие типы виджетов. Оставь как есть.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет WebView по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent — стандарт.
Высота
Height		 Насколько высоким будет WebView по вертикали. match_parent, wrap_content, число в dp. match_parent — чтобы страница занимала весь экран.
Внутренний отступ
Padding		 Отступ внутри виджета. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 0 со всех сторон.
Внешний отступ
Margin		 Отступ снаружи виджета — от него до соседних элементов. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Обычно 0 — WebView занимает весь экран.
Гравитация макета
Layout gravity		 Как виджет выравнивается внутри родителя. none — по умолчанию;
например, center.		 Обычно оставляют none.
Вес
Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — WebView заберёт всё оставшееся место.

Свойства изображения

Свойство (рус / англ) Что делает Значения Пример
Ресурс фона
Background resource		 Картинка-фон виджета из ресурсов проекта. NONE — без фона;
любой drawable-ресурс.		 Обычно оставляют NONE.
Цвет фона
Background color		 Заливка виджета сплошным цветом. NONE — без цвета;
HEX или выбор из палитры.		 Белый фон — #FFFFFF.
Enabled
Включено		 Реагирует ли виджет на тапы и ввод. Переключатель: вкл — активен;
выкл — заблокирован.		 На скриншоте — включено.
Вращение
Rotation		 Поворот виджета вокруг центра. Градусы. 0 — без поворота. Обычно оставляют 0.
Прозрачность
Alpha		 Насколько виджет прозрачен. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.
TranslationX Сдвиг виджета по горизонтали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. 20.0 — визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг виджета по вертикали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.
ScaleX Масштаб по горизонтали — растягивает или сжимает виджет по ширине. Число. 1.0 — исходный размер. 1.5 — ширина увеличится в 1,5 раза.
ScaleY Масштаб по вертикали — растягивает или сжимает виджет по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: в панели свойств задаётся только внешний вид. URL и включение JavaScript обычно задаются через логику — блоки loadUrl и getSettings().setJavaScriptEnabled(true) в событиях вкладки «События».

Как перетащить WebView на макет

WebView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V), Linear(H) или RelativeLayout.
  3. Раскрой категорию Widgets в палитре слева.
  4. Зажми WebView и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — WebView появится в разметке.
  6. Задай Ширину = match_parent, Высоту = match_parent — стандарт.
  7. Присвой осмысленный ID — он нужен для управления из логики.
  8. Открой вкладку «События» и добавь логику:
    • включи JavaScript через getSettings().setJavaScriptEnabled(true);
    • загрузи страницу через loadUrl или loadData;
    • для навигации — goBack, goForward, reload, canGoBack.
⚠️ Важно: обычный тап по WebView в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: для загрузки внешних сайтов требуется разрешение INTERNET в Менеджере разрешений. Без него WebView покажет ошибку.
⚠️ Важно: для HTTPS-сайтов с проблемными сертификатами WebView может заблокировать загрузку. Не отключай проверку сертификатов — это небезопасно.
⚠️ Важно: WebView очень сильно увеличивает вес APK — на 10–30 МБ в зависимости от настроек. Добавляй его только если действительно нужен.
💡 Совет: для навигации «Назад» кнопкой смартфона переопредели событие onBackPressed и внутри проверь canGoBack. Если история есть — вызывай goBack, иначе — finish для выхода из экрана.
💡 Совет: для локальных HTML-страниц положи файл в папку assets через Менеджер ресурсов. Путь в loadUrl — file:///android_asset/index.html.
💡 Совет: JavaScriptEnabled = true нужен почти всегда — без него современные сайты не работают. Но не включай его для страниц, которым ты не доверяешь: JS может выполнять нежелательные действия.
💡 Совет: для простой справки или соглашения используй loadData с готовым HTML-кодом. Это быстрее, чем грузить целый сайт.
❌ Частая ошибка: забыть про разрешение INTERNET. WebView показывает пустую страницу или ошибку, а причина не видна.
❌ Частая ошибка: заворачивать весь сайт в WebView и публиковать приложение в Google Play. Магазин отклоняет такие приложения как «недостаточно функциональные».
❌ Частая ошибка: отключать проверку SSL для удобства. Это открывает путь атакам «человек посередине» — данные пользователя можно перехватить.

Резюме

  • WebView — встроенный браузер для отображения HTML-страниц внутри приложения.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • URL и включение JavaScript обычно задаются в логике — через loadUrl и настройки WebView.
  • Для загрузки внешних сайтов нужно разрешение INTERNET.
  • Сильно увеличивает вес APK — добавляй только при необходимости.
  • Для локального HTML — папка assets, путь file:///android_asset/....
  • Не отключай проверку SSL и не заворачивай в WebView целый сайт для публикации в Google Play.

Частые ошибки новичков

  • Тапают по WebView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Забывают разрешение INTERNET. Внешние сайты не загружаются.
  • Не включают JavaScript. Современные сайты показываются криво или вообще не работают.
  • Ищут URL в свойствах. Адрес обычно задаётся в логике через loadUrl.
  • Отключают проверку SSL. Небезопасно, данные можно перехватить.
  • Заворачивают целый сайт в приложение. Google Play отклоняет такие приложения.
  • Не обрабатывают onBackPressed. Кнопка «Назад» закрывает приложение вместо перехода по истории WebView.
