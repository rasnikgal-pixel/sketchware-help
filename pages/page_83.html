GridView — сетка

GridView — сетка элементов. Раскладывает содержимое по колонкам и строкам, как плитку: несколько элементов в ряд, следующий ряд ниже.

Иконка в палитре — прямоугольник с квадратной сеткой внутри.

Как работает

  • Отображает элементы в виде таблицы: несколько колонок, неограниченное число строк.
  • Количество колонок задаётся в свойствах (NumColumns).
  • Прокручивается вертикально.
  • Создаёт только видимые элементы — работает быстро даже с сотнями плиток.
  • Реагирует на тап по элементу — событие onItemClick.
  • Внутри каждой ячейки может быть текст, картинка, кнопка — в зависимости от адаптера.

Когда использовать

  • Галерея изображений — фотографии в сетке.
  • Каталог товаров — товары плитками.
  • Меню приложения — плитки с иконками и подписями.
  • Портфолио — работы в виде плитки.
  • Игры-головоломки — игровое поле.
  • Выбор цвета или иконки — из набора вариантов.
  • Любое отображение элементов «плитками».

Основные свойства

  • NumColumns — количество колонок. По умолчанию 2 или auto_fit.
  • ColumnWidth — ширина одной колонки (при auto_fit).
  • HorizontalSpacing — отступ по горизонтали между колонками.
  • VerticalSpacing — отступ по вертикали между строками.
  • StretchMode — как растягивать колонки при auto_fit:
    • columnWidth — по ширине колонки;
    • spacingWidth — распределяется между колонками;
    • none — не растягивать.
  • Gravity — выравнивание всей сетки в контейнере.
  • Background — фон сетки.
  • Width / Height — match_parent обычно.

Как добавить

  • Выбери контейнер, куда хочешь положить сетку.
  • Тап по GridView в палитре — компонент добавится внутрь.
  • Задай NumColumns — обычно 2, 3 или 4.
  • Задай HorizontalSpacing и VerticalSpacing — например, 8dp для аккуратных отступов.
  • Присвой id — для работы в логике.
  • Открой вкладку «События» и добавь в onCreate блок setListData или setAdapter — задай элементы сетки.
  • Добавь событие onItemClick для реакции на тап.

⚠️ Важно: без адаптера в логике GridView — пустая область. Данные нужно задавать вручную.

⚠️ Важно: NumColumns не влияет на размер самих элементов. Если ячейки слишком широкие или узкие, задавай их размеры в Layout, который используется как шаблон элемента.

⚠️ Важно: как и ListView, GridView не вкладывается в Scroll(V). Собственная прокрутка конфликтует с родительской.

💡 Совет: для галереи фото используй NumColumns = 3 и Spacing = 4dp. Плотная сетка выглядит аккуратно и экономно использует экран.

💡 Совет: для плиток меню используй NumColumns = 2 и Spacing = 8–12dp. Ячейки больше по размеру, помещается текст и иконка.

💡 Совет: для каталога товаров используй NumColumns = 2 — каждая карточка с картинкой, названием и ценой.

💡 Совет: в ячейке не размещай много контента. GridView подразумевает компактные элементы. Для больших карточек лучше RecyclerView с разметкой в одну колонку.

❌ Частая ошибка: задавать NumColumns = auto_fit без ColumnWidth. Тогда колонки могут стать слишком узкими или широкими.

❌ Частая ошибка: использовать GridView для списка с разной высотой строк. Все ячейки будут одинаковыми по высоте — самая высокая определит размер остальных.

❌ Частая ошибка: вкладывать GridView в Scroll(V). Прокрутка работает нестабильно.
