GridView — сетка

GridView — сетка элементов. Раскладывает содержимое по колонкам и строкам, как плитку: несколько элементов в ряд, следующий ряд ниже.

Иконка в палитре — прямоугольник с квадратной сеткой внутри.

Как работает

  • Отображает элементы в виде таблицы: несколько колонок, неограниченное число строк.
  • Количество колонок задаётся в свойствах (NumColumns).
  • Прокручивается вертикально.
  • Создаёт только видимые элементы — работает быстро даже с сотнями плиток.
  • Реагирует на тап по элементу — событие onItemClick.
  • Внутри каждой ячейки может быть текст, картинка, кнопка — в зависимости от адаптера.

Когда использовать

  • Галерея изображений — фотографии в сетке.
  • Каталог товаров — товары плитками.
  • Меню приложения — плитки с иконками и подписями.
  • Портфолио — работы в виде плитки.
  • Игры-головоломки — игровое поле.
  • Выбор цвета или иконки — из набора вариантов.
  • Любое отображение элементов «плитками».

Настройки

Настройка Что делает Значения
NumColumns Количество колонок в сетке. Число (например, 2, 3, 4) или auto_fit.
ColumnWidth Ширина одной колонки (при auto_fit). Число в dp.
HorizontalSpacing Отступ по горизонтали между колонками. Число в dp.
VerticalSpacing Отступ по вертикали между строками. Число в dp.
StretchMode Как растягивать колонки при auto_fit. columnWidth — по ширине колонки;
spacingWidth — распределяется между колонками;
none — не растягивать.
Gravity Выравнивание всей сетки в контейнере. left, center, right.
Background Фон сетки. HEX или drawable-ресурс.
Width / Height Ширина и высота. Обычно match_parent.

Свойства виджета

Открой панель свойств, тапнув по GridView в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — gridview1).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — gridview1, gridview2 и т. д. Переименуй в productGrid, если это каталог товаров.
Пользовательские атрибуты Дополнительные XML-атрибуты. Через них задаются ключевые параметры сетки. Пары «атрибут = значение». На скриншоте заданы android:numColumns="3" и android:stretchMode="columnWidth".
Конвертировать Показывает тип виджета — GridView. Обычно менять не нужно. GridView и другие типы виджетов. Оставь как есть.
Пользовательский вид
Custom view		 Свой Layout для элемента сетки (вместо стандартного текста). none — стандартный вид; любой XML-макет элемента. Укажи здесь свой макет для плиток с картинкой и текстом.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широкой будет сетка по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent — стандарт.
Высота
Height		 Насколько высокой будет сетка по вертикали. match_parent, wrap_content, число в dp. match_parent — чтобы сетка занимала весь экран.
Внутренний отступ
Padding		 Отступ внутри виджета. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 8 со всех сторон.
Внешний отступ
Margin		 Отступ снаружи виджета — от него до соседних элементов. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Обычно 0 — сетка занимает всё свободное место.
Гравитация макета
Layout gravity		 Как виджет выравнивается внутри родителя. none — по умолчанию;
например, center_horizontal.		 Обычно оставляют none.
Вес
Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — сетка заберёт всё оставшееся место.

Свойство (рус / англ) Что делает Значения Пример
Ресурс фона
Background resource		 Картинка-фон виджета из ресурсов проекта. NONE — без фона;
любой drawable-ресурс.		 Обычно оставляют NONE.
Цвет фона
Background color		 Заливка виджета сплошным цветом. NONE — без цвета;
HEX или выбор из палитры.		 Светло-серый фон — #F5F5F5.
Enabled
Включено		 Реагирует ли виджет на тапы. Переключатель: вкл — активен;
выкл — заблокирован.		 На скриншоте — включено.
Вращение
Rotation		 Поворот виджета вокруг центра. Градусы. 0 — без поворота. Обычно оставляют 0.
Прозрачность
Alpha		 Насколько виджет прозрачен. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.
TranslationX Сдвиг виджета по горизонтали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. 20.0 — визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг виджета по вертикали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.
ScaleX Масштаб по горизонтали — растягивает или сжимает виджет по ширине. Число. 1.0 — исходный размер. 1.5 — ширина увеличится в 1,5 раза.
ScaleY Масштаб по вертикали — растягивает или сжимает виджет по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: ключевые параметры сетки (NumColumns, StretchMode, ColumnWidth) задаются через Пользовательские атрибуты — в виде android:numColumns="3", android:stretchMode="columnWidth", android:columnWidth="100dp".

Как перетащить GridView на макет

GridView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V) или RelativeLayout.
  3. Раскрой категорию Списки в палитре слева.
  4. Зажми GridView и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — сетка появится в разметке.
  6. Через Пользовательские атрибуты задай android:numColumns, android:horizontalSpacing, android:verticalSpacing, android:stretchMode.
  7. Присвой осмысленный ID — он нужен для логики.
  8. Открой вкладку «События» и добавь в onCreate блок setListData или setAdapter — задай элементы сетки.
  9. Добавь событие onItemClick для реакции на тап.
⚠️ Важно: обычный тап по GridView в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: без адаптера в логике GridView — пустая область. Данные нужно задавать вручную.
⚠️ Важно: NumColumns не влияет на размер самих элементов. Если ячейки слишком широкие или узкие, задавай их размеры в Layout, который используется как шаблон элемента.
⚠️ Важно: как и ListView, GridView не вкладывается в Scroll(V). Собственная прокрутка конфликтует с родительской.
💡 Совет: для галереи фото используй NumColumns = 3 и Spacing = 4dp. Плотная сетка выглядит аккуратно и экономно использует экран.
💡 Совет: для плиток меню используй NumColumns = 2 и Spacing = 8–12dp. Ячейки больше по размеру, помещается текст и иконка.
💡 Совет: для каталога товаров используй NumColumns = 2 — каждая карточка с картинкой, названием и ценой.
💡 Совет: в ячейке не размещай много контента. GridView подразумевает компактные элементы. Для больших карточек лучше RecyclerView с разметкой в одну колонку.
❌ Частая ошибка: задавать NumColumns = auto_fit без ColumnWidth. Тогда колонки могут стать слишком узкими или широкими.
❌ Частая ошибка: использовать GridView для списка с разной высотой строк. Все ячейки будут одинаковыми по высоте — самая высокая определит размер остальных.
❌ Частая ошибка: вкладывать GridView в Scroll(V). Прокрутка работает нестабильно.

Резюме

  • GridView — сетка элементов: несколько колонок, неограниченное число строк.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Ключевые параметры (NumColumns, StretchMode, ColumnWidth) задаются через Пользовательские атрибуты.
  • Работает только через адаптер в логике — без него пустая область.
  • Для галереи — 3 колонки; для плиток меню и товаров — 2 колонки.
  • Все ячейки одной высоты — они определяются самой высокой.
  • Не вкладывай GridView в Scroll(V) — прокрутка конфликтует.

Частые ошибки новичков

  • Тапают по GridView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетащили сетку, но не подключили адаптер. Область пустая.
  • Ищут NumColumns в обычных свойствах. Через «Пользовательские атрибуты» — android:numColumns.
  • Используют auto_fit без ColumnWidth. Колонки слишком узкие или широкие.
  • Вкладывают GridView в Scroll(V). Прокрутка работает нестабильно.
  • Делают ячейки разной высоты. Все подтянутся к самой высокой.
  • Не задают ID. В событиях не появляется, логика не подключается.
