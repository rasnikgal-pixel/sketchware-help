ImageView — изображение

ImageView — виджет для отображения изображений. Показывает картинку из ресурсов проекта или загруженную по сети. Используется для иконок, логотипов, аватарок, обложек, иллюстраций.

Иконка в палитре — прямоугольник с изображением гор и солнца.

Как работает

  • Отображает картинку, заданную в свойстве Image или Src.
  • Картинка берётся из Менеджера изображений проекта.
  • Может масштабироваться под размер виджета разными способами (ScaleType).
  • Может менять картинку в логике — например, при нажатии кнопки.
  • Может быть кликабельным — реагирует на нажатие как кнопка.

Когда использовать

  • Иконки рядом с текстом.
  • Логотипы приложений на экране «О программе».
  • Аватарки пользователей.
  • Обложки карточек и статей.
  • Иллюстрации на пустых экранах («Нет данных»).
  • Фоны для баннеров и шапок.

Настройки

Настройка Что делает Значения
Image / Src Ссылка на изображение из ресурсов проекта. Drawable-ресурс из Менеджера изображений.
ScaleType Способ масштабирования картинки. fitCenter — вписать, сохраняя пропорции, по центру;
centerCrop — заполнить виджет, обрезая лишнее;
center — по центру без масштабирования;
fitXY — растянуть по ширине и высоте (может искажать);
fitStart / fitEnd — вписать с прижатием к краю.
AdjustViewBounds Подстраивать границы виджета под пропорции картинки. Переключатель: вкл / выкл.
Background Фон виджета — цвет или изображение. HEX, drawable-ресурс или NONE.
ColorFilter Наложить цветовой фильтр (оттенок) на картинку. HEX-цвет.
Alpha Прозрачность картинки. Число от 0 до 1.
Padding / Margin Внутренние и внешние отступы. Число в dp для каждой стороны.
Width / Height Ширина и высота. wrap_content, match_parent или число в dp.
Clickable Реагирует ли на нажатие. Переключатель: вкл / выкл.

Свойства виджета

Открой панель свойств, тапнув по ImageView в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — imageview1).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — imageview1, imageview2 и т. д. Переименуй в avatarImage, если это аватарка.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». Например, android:tint="#888888" — обесцветить картинку.
Конвертировать Показывает тип виджета — ImageView. Обычно менять не нужно. ImageView и другие типы виджетов. Оставь как есть.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет виджет по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 48dp — стандарт для иконки; match_parent — для обложки.
Высота
Height		 Насколько высоким будет виджет по вертикали. match_parent, wrap_content, число в dp. 48dp — для иконки; 180dp — для обложки.
Внутренний отступ
Padding		 Отступ внутри виджета — от краёв до картинки. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 0 со всех сторон.
Внешний отступ
Margin		 Отступ снаружи виджета — от него до соседних элементов и краёв родителя. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin end 8 — картинка сдвинется на 8 dp влево от правого элемента.
Гравитация макета
Layout gravity		 Как виджет выравнивается внутри родителя. none — по умолчанию;
например, center_horizontal, right.		 center_horizontal — картинка по центру.
Вес
Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — виджет заберёт всё оставшееся место.

Свойства изображения

Свойство (рус / англ) Что делает Значения Пример
Изображение
Image / Src		 Ссылка на изображение из Менеджера изображений проекта. Drawable-ресурс. По умолчанию — default_image. Выбери загруженную картинку — например, logo, avatar.
Тип масштабирования
ScaleType		 Как картинка масштабируется под размер виджета. CENTER — по центру без масштабирования (значение по умолчанию);
CENTER_CROP — заполнить, обрезая лишнее;
FIT_CENTER — вписать, сохраняя пропорции;
FIT_XY — растянуть (искажает);
FIT_START / FIT_END — вписать с прижатием к краю.		 Для аватарок — CENTER_CROP, для иконок — FIT_CENTER.
Ресурс фона
Background resource		 Картинка-фон виджета из ресурсов проекта. NONE — без фона;
любой drawable-ресурс.		 Обычно оставляют NONE.
Цвет фона
Background color		 Заливка виджета сплошным цветом. NONE — без цвета;
HEX или выбор из палитры.		 Серая плашка под иконкой — #EEEEEE.
Enabled
Включено		 Реагирует ли виджет на нажатия (если Clickable = true). Переключатель: вкл — активно;
выкл — заблокировано.		 На скриншоте — включено.
Вращение
Rotation		 Поворот виджета вокруг центра. Градусы. 0 — без поворота. Обычно оставляют 0.
Прозрачность
Alpha		 Насколько виджет прозрачен. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 0.5 — полупрозрачная картинка.
TranslationX Сдвиг виджета по горизонтали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. 20.0 — визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг виджета по вертикали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.
ScaleX Масштаб по горизонтали — растягивает или сжимает виджет по ширине. Число. 1.0 — исходный размер. 1.5 — ширина увеличится в 1,5 раза.
ScaleY Масштаб по вертикали — растягивает или сжимает виджет по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: на первых порах достаточно свойств Изображение, Тип масштабирования, Ширина и Высота. Остальные оставь по умолчанию.

Как перетащить ImageView на макет

ImageView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V), Linear(H) или RelativeLayout.
  3. Раскрой категорию Widgets в палитре слева.
  4. Зажми ImageView и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — картинка появится в разметке.
  6. Открой Менеджер изображений и загрузи нужные картинки в проект.
  7. Тапни по ImageView в рабочей области и в свойстве Изображение выбери нужный ресурс.
  8. Задай Тип масштабирования — обычно CENTER_CROP или FIT_CENTER.
  9. Задай Ширину и Высоту — например, 48dp × 48dp для иконки.
⚠️ Важно: обычный тап по ImageView в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: без загруженного изображения в Менеджере ImageView будет пустым. Сначала загрузи картинку — потом выбирай её в свойствах.
⚠️ Важно: fitXY искажает пропорции. Если картинка не совпадает по форме с виджетом, она «сплющится» или растянется. Используй centerCrop или fitCenter, если важны пропорции.
💡 Совет: для иконок и аватарок используй centerCrop и квадратные размеры (48dp, 64dp) — так они выглядят аккуратно.
💡 Совет: для обложек (картинка сверху карточки) используй centerCrop, Height = 180dp, Width = match_parent. Это стандартный приём в новостных приложениях.
💡 Совет: не используй PNG больших размеров для простых иконок. Это увеличивает вес APK. Загружай картинку нужного разрешения — не больше, чем отображается на экране.
💡 Совет: для круглых аватарок используй CircleImageView (следующий подпункт). Обычный ImageView с centerCrop даст квадратную картинку.
❌ Частая ошибка: ставить fitXY на картинки с непропорциональными размерами. Результат — искажённое изображение.
❌ Частая ошибка: добавлять ImageView с огромной картинкой без ScaleType. Картинка отображается в исходном размере и вылезает за пределы контейнера.

Резюме

  • ImageView — виджет для отображения картинок из ресурсов проекта.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Картинки сначала загружаются в Менеджер изображений, потом выбираются в свойстве Изображение.
  • Ключевые свойства: Изображение, Тип масштабирования, Ширина, Высота.
  • Для иконок — CENTER_CROP и размер 48dp; для обложек — CENTER_CROP и высота 180dp.
  • Не используй FIT_XY без необходимости — искажает картинку.
  • Для круглых аватарок используй CircleImageView.

Частые ошибки новичков

  • Тапают по ImageView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Добавляют ImageView без загрузки картинки. Виджет пустой — сначала загрузи изображение в Менеджер.
  • Ставят fitXY для пропорциональных картинок. Изображение искажается.
  • Не задают размеры. Большая картинка отображается в исходном размере и вылезает за пределы контейнера.
  • Оставляют ScaleType = CENTER по умолчанию. Маленькая картинка не заполнит виджет, большая обрежется.
  • Используют ImageView для круглой аватарки. Нужен CircleImageView.
  • Загружают гигантские PNG для иконок. Утяжеляет APK без пользы.
