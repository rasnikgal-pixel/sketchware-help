SoundPool — короткие звуки

SoundPool — компонент для воспроизведения коротких звуков. В отличие от MediaPlayer, оптимизирован под частые и быстрые звуки: клики, всплески, выстрелы, короткие эффекты. Работает быстрее и легче, но не подходит для длинных треков.

Иконка в диалоге добавления — динамик со звуковыми волнами.

Как работает

  • Воспроизводит короткие звуковые файлы — обычно до 5 секунд.
  • Может проигрывать несколько звуков одновременно — например, клики и фон.
  • Загружает звуки заранее в память — воспроизведение начинается мгновенно.
  • Позволяет управлять громкостью, скоростью, количеством повторов.
  • Не подходит для музыки и длинных треков — для них MediaPlayer.

Когда использовать

  • Игры — выстрелы, взрывы, прыжки, попадания.
  • Клики и нажатия — тактильная звуковая отдача.
  • Уведомления — короткий звук при событии.
  • Звуковые эффекты — в приложениях-инструментах (пианино, барабаны).
  • Анимации — звук при появлении элемента.
  • Сообщения в чате — звук нового сообщения.

Основные настройки при добавлении

  • Имя компонента — идентификатор для вызова. Например, soundPool.

Основные блоки в логике

  • load — загрузить звук в память (обычно в onCreate).
  • play — воспроизвести звук.
  • stop — остановить воспроизведение.
  • pause — пауза.
  • resume — продолжить.
  • setVolume — изменить громкость.
  • setRate — изменить скорость (и высоту тона).
  • setLoop — повторы: -1 — бесконечно, 0 — один раз, N — N повторов.
  • release — освободить ресурсы.

Как использовать

  • Подключи компонент SoundPool на вкладке «Компонент».
  • Задай имя — например, sfx.
  • Скопируй звуковые файлы в res/raw через Менеджер ресурсов.
  • В onCreate загрузи звуки через блок load — каждому звуку присвой ID.
  • При наступлении события (например, тап по кнопке) — вызови play с ID нужного звука.
  • При выходе с экрана — вызови release.

Пример: звук нажатия

  • В onCreate загрузи звук click.mp3 через load и получи ID.
  • В onClick кнопки вызови play с этим ID.
  • Громкость — 1.0, скорость — 1.0, повторы — 0.
  • Пользователь слышит звук клика мгновенно.

⚠️ Важно: загрузка звуков занимает время. Загружай их в onCreate, а не в момент воспроизведения. Тогда звук будет готов мгновенно.

⚠️ Важно: не используй SoundPool для длинных треков. Он рассчитан на короткие звуки (до нескольких секунд). Для музыки — MediaPlayer.

⚠️ Важно: не загружай слишком много звуков одновременно. SoundPool держит их в памяти — это расходует RAM. Оптимально — 5–15 звуков.

⚠️ Важно: не забывай про release при уходе с экрана. Иначе звуки останутся в памяти.

💡 Совет: для игры используй SoundPool для всех звуковых эффектов: выстрел, попадание, взрыв, победа. Для фоновой музыки — отдельный MediaPlayer.

💡 Совет: для кликов и нажатий загрузи один короткий звук и используй его везде. Это экономит память и упрощает логику.

💡 Совет: для изменения тона используй блок setRate. Например, 1.0 — оригинал, 1.5 — выше, 0.5 — ниже. Полезно для игровых эффектов.

💡 Совет: для нескольких звуков одновременно используй разные ID при play. SoundPool умеет микшировать каналы.

💡 Совет: для бесконечного повтора используй setLoop = -1. Например, для фонового гула в игре.

💡 Совет: загружай звуки в onCreate, но проверяй успешность загрузки. Если файл повреждён — при воспроизведении будет тишина.

❌ Частая ошибка: использовать SoundPool для музыки. Длинные треки не помещаются в память и не воспроизводятся корректно.

❌ Частая ошибка: загружать звук прямо перед воспроизведением. Первое воспроизведение будет с задержкой.

❌ Частая ошибка: загружать десятки звуков. SoundPool держит их в памяти — приложение будет тормозить.

❌ Частая ошибка: не освобождать ресурсы. Звуки остаются в памяти до закрытия приложения.

❌ Частая ошибка: не проверять, что звук загрузился. Если load вернул ошибку — при воспроизведении будет тишина, и непонятно, почему.
