Менеджер изображений

Менеджер изображений — раздел меню «Настройка», через который добавляются картинки в проект. Здесь ты загружаешь изображения для ImageView, иконок, фонов, аватарок.

Иконка в меню — рамка с картинкой.

Что можно делать

  • Добавлять изображения из памяти устройства.
  • Просматривать список загруженных картинок.
  • Удалять ненужные.
  • Заменять существующие.
  • Использовать в ImageView через свойство Image / Src.

Какие изображения загружать

Тип Формат Рекомендуемый размер
Иконки PNG с прозрачностью 48×48, 64×64, 96×96
Фоны Оптимизированные JPEG 1080×1920 (экран)
Аватарки JPEG или PNG, квадратные 200×200, 300×300
Обложки JPEG 600–800 по ширине
Иллюстрации PNG или JPG, средний размер 300–500 пикселей
Логотипы PNG с прозрачным фоном 300–500 по ширине

Форматы

Формат Когда использовать
PNG Для иконок и картинок с прозрачностью.
JPG / JPEG Для фотографий и фонов.
WEBP Современный формат, меньше весит (если поддерживается).
SVG Векторный формат (в Sketchware Pro 7 не используется напрямую).

Как добавить

  1. Открой меню ⋮ → Менеджер изображений.
  2. Нажми кнопку «+» или «Добавить».
  3. Выбери изображение из памяти устройства.
  4. Дай ему имя — латиницей, без пробелов.
  5. Нажми «Сохранить» — изображение появится в списке.
  6. Теперь его можно выбрать в свойствах ImageView.

Как использовать

  1. Добавь изображение в Менеджер.
  2. В Дизайнере тапни по ImageView.
  3. В свойствах выбери Image / Src → укажи нужную картинку.
  4. Задай ScaleType — centerCrop или fitCenter.
  5. Настрой размеры.

Как удалить

  1. Открой Менеджер изображений.
  2. Найди нужное изображение.
  3. Используй контекстное меню или кнопку «Удалить».
  4. Подтверди удаление.
⚠️ Важно: не используй кириллицу в именах файлов. Android не всегда корректно обрабатывает такие имена.
⚠️ Важно: не загружай большие картинки (больше 500 КБ). Каждая картинка увеличивает APK. Лучше оптимизировать до загрузки.
⚠️ Важно: не удаляй изображение, которое используется в проекте. Приложение перестанет собираться.
⚠️ Важно: имена файлов должны быть уникальными. Два файла с одинаковым именем — конфликт.
💡 Совет: для иконок используй PNG с прозрачным фоном. Размер — 48×48, 64×64 или 96×96 пикселей. Больше не нужно.
💡 Совет: для обложек карточек используй JPEG с шириной 600–800 пикселей. Этого достаточно для большинства экранов.
💡 Совет: для аватарок используй квадратные картинки 200×200 или 300×300. CircleImageView обрежет их по кругу.
💡 Совет: оптимизируй картинки на сервисах типа TinyPNG или Squoosh перед загрузкой. Вес уменьшается в 2–3 раза без потери качества.
💡 Совет: для повторяющихся элементов (иконка в списке) загрузи одну картинку и используй её везде. Дубликаты не нужны.
💡 Совет: загружай иконку приложения отдельно — через экран «Настроить иконку» при создании проекта. Не путай с Менеджером изображений.
❌ Частая ошибка: использовать большие фотографии без сжатия. Одна картинка 3 МБ может удвоить размер APK.
❌ Частая ошибка: кириллица в именах файлов. Названия не отображаются корректно, могут возникнуть ошибки.
❌ Частая ошибка: дублировать картинки — загружать одну и ту же много раз. Достаточно одной.
❌ Частая ошибка: удалять используемые картинки. Проект не собирается.
❌ Частая ошибка: забывать про ScaleType. Картинка растягивается или обрезается неправильно.

Резюме

  • Менеджер изображений — раздел для загрузки картинок в проект.
  • Поддерживает PNG, JPG, WEBP.
  • Используется для иконок, фонов, аватарок, обложек.
  • Имена файлов — латиница, без пробелов.
  • Оптимизируй картинки перед загрузкой — экономия веса APK.
  • Не удаляй используемые изображения — проект сломается.
  • Размеры подбирай под задачу: иконки 48–96 px, обложки 600–800 px.
  • Иконку приложения загружай отдельно, не через этот менеджер.

Частые ошибки новичков

  • Загружают большие фото. APK раздувается.
  • Кириллица в именах. Проблемы с Android.
  • Дублируют картинки. Мусор в проекте.
  • Удаляют используемые. Сборка падает.
  • Забывают про ScaleType. Картинка искажена.
  • Не оптимизируют. Вес APK растёт.
  • Путают с иконкой приложения. Не тот раздел.
