Верхняя панель

Верхняя панель на вкладке «События» — это шапка, которая остаётся видимой на всех экранах логики. Она отличается от панели «Дизайнера» — здесь появляются дополнительные кнопки, нужные для работы с блоками.

Разберём элементы слева направо.

Элементы верхней панели

Элемент Где находится Что делает
Стрелка назад Слева в шапке. Выход из проекта и возврат на главный экран со списком проектов.
Имя проекта и номер папки Под стрелкой назад. Показывают имя проекта и внутренний ID (например, 601).
Отменить Справа в шапке. Откатывает последнее действие (перемещение блока, удаление, вставку).
Повторить Справа в шапке. Возвращает отменённое действие.
Сохранить Справа в шапке. Вручную сохраняет изменения проекта.
Поиск (лупа) Справа в шапке. Появляется только на вкладке «События». Открывает строку поиска по событиям и блокам текущего экрана.
Меню (⋮) Три точки вертикально, в правом верхнем углу. Открывает меню «Настройка» — работа с ресурсами, разрешениями, Logcat и другими разделами.

Стрелка назад

  • Слева в шапке.
  • Тап — выход из проекта и возврат на главный экран со списком проектов.
  • Работает так же, как и на других вкладках.
⚠️ Важно: если ты находишься внутри блочного полотна (открыто событие), стрелка назад сначала вернёт тебя к списку событий, а не на главный экран. Повторный тап — выход из проекта.

Имя проекта и номер папки

  • Под стрелкой назад.
  • Имя проекта — то, что ты задал при создании.
  • Номер папки — внутренний ID проекта, например 601.

Кнопки «Отменить», «Повторить», «Сохранить»

  • Уже разобраны в пункте 30 «Верхняя панель проекта».
  • Работают на вкладке «События» так же, как в «Дизайнере»:
    • «Отменить» — откатывает последнее действие (перемещение блока, удаление, вставку).
    • «Повторить» — возвращает отменённое.
    • «Сохранить» — вручную сохраняет изменения проекта.

Кнопка «Поиск» (лупа)

  • Появляется только на вкладке «События» — на «Дизайнере» и «Компоненте» её нет.
  • Тап открывает строку поиска по событиям и блокам текущего экрана.
  • В строке вводится запрос — Sketchware фильтрует список событий по названию.
  • Полезна в больших проектах, где событий десятки, и нужно быстро найти нужное.
💡 Совет: используй поиск, если забыл, где именно ты добавил какое-то событие. Например, вводишь onClick — и видишь все события этого типа.

Кнопка меню (⋮)

  • Три точки вертикально в правом верхнем углу.
  • Тап открывает меню «Настройка» — то же самое, что и на других вкладках.
  • Содержит разделы для работы с проектом: менеджеры ресурсов, разрешений, AppCompat, AndroidManifest, Logcat и другие.

Разбор пунктов меню — в пункте 30 и разделе 7 «Меню "Настройка" внутри проекта».

Особенности панели на вкладке «Логика»

  • Дополнительная иконка лупы — поиск по событиям.
  • Отмена/повтор работают не с разметкой, а с блоками. Одно нажатие «Отменить» убирает последнее действие с блочного полотна.
  • Кнопка «Сохранить» критически важна — логика редко сохраняется автоматически при выходе из события. Если закрыть проект без сохранения — блоки могут пропасть.
⚠️ Важно: выход из блочного полотна в список событий — это ещё не сохранение. Блоки сохраняются при закрытии полотна или при ручном нажатии «Сохранить» в шапке.
⚠️ Важно: не выходи из проекта через стрелку назад сразу после добавления блоков. Сначала вернись из полотна в список событий, затем — на главный экран. Так надёжнее.
💡 Совет: если случайно удалил блок — сразу жми «Отменить». История отмены ограничена (несколько последних действий), и после других операций удалённый блок уже не вернётся.
💡 Совет: сохраняй проект после каждого крупного изменения в логике. Не полагайся на автосохранение — оно не всегда срабатывает при выходе из приложения.
❌ Частая ошибка: закрыть приложение, не выйдя из блочного полотна. При следующем открытии часть блоков может отсутствовать.
❌ Частая ошибка: думать, что отмена работает бесконечно. История отмены — несколько действий, дальше изменения фиксируются.
❌ Частая ошибка: использовать поиск для поиска блоков внутри события. Лупа ищет только по списку событий — не по содержимому блочного полотна.

Резюме

  • Верхняя панель на вкладке «События» содержит: стрелку назад, имя проекта, кнопки отмены/повтора/сохранения, поиск, меню ⋮.
  • Стрелка назад выходит из проекта или возвращает из блочного полотна.
  • Имя проекта и номер папки — идентификация текущего проекта.
  • Отменить / Повторить / Сохранить работают с блоками, так же как с разметкой в Дизайнере.
  • Поиск (лупа) — уникальная кнопка вкладки «События». Ищет события по названию.
  • Меню ⋮ открывает «Настройку» — работа с ресурсами, разрешениями, Logcat.
  • Кнопка «Сохранить» — критически важна: логика редко сохраняется автоматически.
  • Отмена работает ограниченно — не бесконечно.

Частые ошибки новичков

  • Закрывают проект без сохранения. Часть блоков теряется.
  • Выходят из полотна сразу стрелкой назад. Сначала нужно вернуться в список событий, потом — на главный экран.
  • Думают, что отмена бесконечна. Она работает только с последними действиями.
  • Используют поиск для поиска блоков. Лупа ищет только события, не содержимое полотна.
  • Не проверяют имя проекта в шапке. Легко перепутать проекты, особенно если их несколько.
  • Не используют поиск в больших проектах. Ручной просмотр десятков событий занимает время.
  • Не заходят в меню ⋮, когда нужно. Там есть Logcat, разрешения, ресурсы — самые нужные разделы.
