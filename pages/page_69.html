MaterialButton — современная кнопка

MaterialButton — кнопка в стиле Material Design. Это современная версия обычного Button: скруглённые углы, тонкая настройка цвета фона и текста, встроенный ripple-эффект, поддержка иконок.

Иконка в палитре — прямоугольник с закруглёнными углами и текстом.

Как работает

  • По поведению полностью совпадает с обычным Button — реагирует на onClick, имеет состояния.
  • Отличается внешним видом: скруглённые углы, аккуратные отступы, поддержка стилей Material.
  • Может быть filled (залитая цветом), outlined (с рамкой) или text (только текст).
  • Умеет показывать иконку слева, справа или сверху от текста.
  • Ripple-эффект при нажатии встроен и выглядит мягче, чем у обычного Button.

Когда использовать

  • Современные приложения — везде, где хочешь выглядеть актуально.
  • Формы — кнопки «Войти», «Отправить», «Сохранить».
  • Карточки — «Купить», «Подробнее».
  • Диалоги — кнопки подтверждения и отмены.
  • Панели действий — группы кнопок с разными стилями.

MaterialButton — стандарт для новых Android-приложений. Если сомневаешься, что использовать — выбирай его.

Настройки

Настройка Что делает Значения
Text Текст на кнопке. Любая строка.
TextColor Цвет текста. HEX или выбор из палитры.
BackgroundTint Цвет фона кнопки (задаётся именно тинтом). HEX или выбор из палитры.
CornerRadius Радиус скругления углов. Число в dp. На скриншоте — 8dp.
StrokeWidth Толщина рамки (для outlined-стиля). Число в dp. 0dp — без рамки.
StrokeColor Цвет рамки. HEX или выбор из палитры.
Icon Иконка рядом с текстом. Drawable-ресурс.
IconGravity Положение иконки относительно текста. start, end, top, textStart.
RippleColor Цвет подсветки при нажатии. HEX или выбор из палитры.
AllCaps Автоматический перевод текста в верхний регистр. У MaterialButton по умолчанию false. Переключатель: вкл / выкл.
Enabled Активна ли кнопка. Переключатель: вкл / выкл.
Padding / Margin Внутренние и внешние отступы. Число в dp для каждой стороны.
Width / Height Ширина и высота. wrap_content или match_parent.

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — materialbutton1, materialbutton2 и т. д. Переименуй в submitButton, если это кнопка отправки.

Ширина
Width		 Насколько широкой будет кнопка по горизонтали. match_parent — на всю ширину родителя;

например, center_horizontal, right.		 center_horizontal — кнопка встанет по центру родителя.
Вес
Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — кнопка заберёт всё оставшееся место.

Прозрачность
Alpha		 Насколько кнопка прозрачна. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.

💡 Совет для новичков: ключевые параметры MaterialButton (CornerRadius, BackgroundTint, StrokeWidth, StrokeColor) задаются через Пользовательские атрибуты — их нужно вручную прописать в виде app:cornerRadius="8dp", app:backgroundTint="#2196F3", app:strokeWidth="1dp".

Как перетащить MaterialButton на макет

MaterialButton, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V), Linear(H) или RelativeLayout.
  3. Раскрой категорию Widgets в палитре слева.
  4. Зажми MaterialButton и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — кнопка появится в разметке.
  6. Тапни по кнопке и задай Текст — например, «Войти».
  7. Через Пользовательские атрибуты задай app:cornerRadius, app:backgroundTint, при необходимости app:strokeWidth и app:strokeColor.
  8. Присвой осмысленный ID — он нужен для событий.
  9. Открой вкладку «События» — добавь событие onClick для этой кнопки.
  10. Внутри onClick опиши блоки, которые должны выполниться при нажатии.
⚠️ Важно: обычный тап по MaterialButton в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: BackgroundTint работает не так, как Background у обычного Button. Если попытаться задать фон через Background, кнопка может потерять форму Material и превратиться в обычную серую. Используй именно app:backgroundTint.
⚠️ Важно: MaterialButton не поддерживает атрибут Background так же, как обычная кнопка. Для фона — app:backgroundTint, для рамки — app:strokeWidth и app:strokeColor.
💡 Совет: для главных действий (submit, подтвердить) используй залитую цветом кнопку. Для второстепенных (отмена, назад) — outlined (прозрачную с рамкой). Это стандартная визуальная иерархия Material Design.
💡 Совет: задавай CornerRadius = 8dp для мягкого современного вида. 0dp — строгие прямоугольные кнопки, 20dp+ — «таблетки».
💡 Совет: не делай все кнопки залитыми. Если все кнопки яркие, пользователь не понимает, какая из них главная. Одна залитая + одна outlined — оптимально.
❌ Частая ошибка: использовать Background вместо BackgroundTint. Кнопка теряет стиль Material или отображается некорректно.
❌ Частая ошибка: забыть про CornerRadius и оставить углы 0dp. Выглядит устаревше, теряется весь смысл MaterialButton.

Резюме

  • MaterialButton — современная кнопка в стиле Material Design с скруглёнными углами и ripple-эффектом.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • По поведению совпадает с обычным Button: реагирует на onClick, требует ID для событий.
  • Ключевые параметры (CornerRadius, BackgroundTint, StrokeWidth, StrokeColor) задаются через Пользовательские атрибуты.
  • Фон задаётся через app:backgroundTint, а не через Background.
  • Стили: filled (залитая), outlined (с рамкой), text (только текст).
  • Для главных действий — залитая кнопка, для второстепенных — outlined.

Частые ошибки новичков

  • Тапают по MaterialButton в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Задают фон через Background. Кнопка теряет стиль Material — используй app:backgroundTint.
  • Ищут CornerRadius и StrokeWidth в обычных свойствах. Их нужно прописывать через «Пользовательские атрибуты».
  • Забывают про onClick. Кнопка нажимается, но ничего не делает.
  • Не задают ID. Кнопка не появляется в списке событий на вкладке «События».
  • Оставляют CornerRadius = 0dp. Внешне MaterialButton выглядит как обычный Button — теряется смысл.
  • Делают все кнопки залитыми ярким цветом. Пользователь не понимает визуальную иерархию.
