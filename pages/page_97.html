YoutubePlayer — YouTube-плеер

YoutubePlayer — встроенный проигрыватель YouTube. Позволяет смотреть видео с YouTube прямо внутри приложения, без перехода в отдельное приложение или браузер.

Иконка в палитре — прямоугольник с логотипом YouTube.

Как работает

  • Отображает окно плеера YouTube в разметке.
  • Видео задаётся через ID видео (не полную ссылку) — например, dQw4w9WgXcQ.
  • Поддерживает воспроизведение, паузу, перемотку, полный экран.
  • Может запускаться автоматически при появлении экрана.
  • Показывает стандартные элементы YouTube: логотип, кнопки, название.
  • Может быть встроен в разные экраны: список видео, детали, онбординг.

Когда использовать

  • Обучающие приложения — уроки с YouTube.
  • Каталоги видео — подборки роликов по теме.
  • Новостные приложения — видеорепортажи.
  • Развлекательные приложения — подборки клипов и трейлеров.
  • Фитнес-приложения — видеоупражнения.
  • Кулинарные приложения — видеорецепты.

Настройки

Настройка Что делает Значения
VideoId Идентификатор видео на YouTube (не ссылка). Строка из 11 символов, например dQw4w9WgXcQ.
AutoPlay Начинать ли воспроизведение автоматически. Переключатель: вкл / выкл.
FullscreenButtonEnabled Показывать ли кнопку полного экрана. Переключатель: вкл / выкл.
ShowInfo Показывать ли информацию о видео. Переключатель: вкл / выкл.
ControlsEnabled Показывать ли стандартные элементы управления. Переключатель: вкл / выкл.
PlayerStyle Стиль плеера. default, minimal, chromeless.
Width / Height Ширина и высота. Обычно match_parent по ширине, wrap_content по высоте.

Свойства виджета

Открой панель свойств, тапнув по YoutubePlayer в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — youtube1).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — youtube1, youtube2 и т. д. Переименуй в lessonPlayer, если это плеер урока.
Пользовательские атрибуты Дополнительные XML-атрибуты. Здесь задаются AutoPlay, ControlsEnabled, FullscreenButtonEnabled. Пары «атрибут = значение». На скриншоте заданы app:autoPlay="false" и app:useWebUi="false".
Конвертировать Показывает полный класс компонента: com.pierfrancescosoffritti.androidyoutubeplayer.core.player.views.YouTubePlayerView. YouTubePlayerView и другие типы виджетов. Оставь как есть.

💡 Совет для новичков: ключевые параметры (VideoId, AutoPlay, FullscreenButtonEnabled, ControlsEnabled) задаются через Пользовательские атрибуты или через логику (loadVideo, cueVideo, play, pause). В обычной панели свойств доступен только базовый внешний вид.

Как перетащить YoutubePlayer на макет

YoutubePlayer, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Получи ID видео на YouTube. Это часть ссылки после watch?v=. Например, для https://www.youtube.com/watch?v=dQw4w9WgXcQ — ID будет dQw4w9WgXcQ.
  2. В Sketchware Pro 7 подключи библиотеку YouTube Player через Менеджер библиотек.
  3. Добавь разрешение INTERNET в Менеджере разрешений.
  4. Открой вкладку «Дизайнер». Убедись, что на макете уже есть контейнер — Linear(V) или RelativeLayout.
  5. Раскрой категорию Google в палитре слева.
  6. Зажми YoutubePlayer и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  7. Отпусти в нужном месте — плеер появится в разметке.
  8. Через Пользовательские атрибуты задай app:autoPlay, app:controlsEnabled, app:fullscreenButtonEnabled.
  9. Присвой осмысленный ID — он нужен для логики.
  10. Открой вкладку «События» и добавь в onCreate блок loadVideo или cueVideo с ID видео.
  11. Для управления используй блоки play, pause.
⚠️ Важно: обычный тап по YoutubePlayer в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: нужен ID видео, а не полная ссылка. Если вставить https://youtube.com/watch?v=..., плеер не заработает.
⚠️ Важно: для работы требуется интернет. Без подключения — плеер покажет ошибку или пустой экран.
⚠️ Важно: YouTube может требовать API-ключ для полноценной работы некоторых функций. Обычно встроенный плеер работает без ключа, но при публикации может потребоваться ключ.
⚠️ Важно: не все видео разрешают встраивание. Некоторые авторы блокируют показ в сторонних приложениях. Плеер покажет «Видео недоступно».
⚠️ Важно: монетизация YouTube-видео не переходит в твоё приложение. Если встраиваешь чужие видео — это нарушение авторских прав, если нет разрешения.
💡 Совет: для списка видео создавай RecyclerView с превью-картинками и названиями. При тапе — открывай экран с YoutubePlayer, куда передаётся VideoId.
💡 Совет: превью видео можно получить по ссылке https://img.youtube.com/vi/<VideoId>/maxresdefault.jpg. Загружай картинку через ImageView — так список видео выглядит красиво.
💡 Совет: для своего контента — используй свои видео с YouTube-канала. Так ты не нарушаешь авторские права.
💡 Совет: не делай AutoPlay = true для длинных видео. Пользователь может не хотеть, чтобы звук запускался сразу. Пусть тапнет play сам.
💡 Совет: предусмотри обработку ошибок — если видео недоступно, покажи пользователю понятное сообщение: «Видео недоступно. Попробуйте позже».
❌ Частая ошибка: вставлять полную ссылку вместо ID видео. Плеер не загрузит видео.
❌ Частая ошибка: забыть про INTERNET. Плеер пустой, ошибки не видно.
❌ Частая ошибка: встраивать чужие видео без разрешения. Это нарушение авторских прав, за которое можно получить страйк или блокировку аккаунта.
❌ Частая ошибка: открывать недоступное видео без обработки ошибки. Пользователь видит пустое окно и не понимает, что произошло.
❌ Частая ошибка: использовать YoutubePlayer для локальных видеофайлов. Для этого есть VideoView (категория Widgets).

Резюме

  • YoutubePlayer — встроенный плеер для просмотра YouTube-видео внутри приложения.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Использует ID видео (11 символов), а не полную ссылку.
  • Требует разрешение INTERNET и подключение библиотеки YouTube Player.
  • Ключевые параметры (AutoPlay, ControlsEnabled, FullscreenButtonEnabled) задаются через Пользовательские атрибуты.
  • Управление воспроизведением — через логику: loadVideo, play, pause.
  • Не используй чужие видео без разрешения — это нарушение авторских прав.
  • Для списка видео используй превью через img.youtube.com/vi/<ID>/....

Частые ошибки новичков

  • Тапают по YoutubePlayer в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Вставляют полную ссылку вместо ID. Плеер не загружает видео.
  • Забывают разрешение INTERNET. Плеер пустой.
  • Не подключают библиотеку YouTube Player. Сборка не проходит.
  • Используют AutoPlay = true без надобности. Раздражает пользователя.
  • Встраивают чужие видео без разрешения. Нарушение авторских прав.
  • Не обрабатывают ошибку «видео недоступно». Пользователь видит пустой плеер.
  • Не задают ID. Логика не может управлять плеером.
