YoutubePlayer — YouTube-плеер

YoutubePlayer — встроенный проигрыватель YouTube. Позволяет смотреть видео с YouTube прямо внутри приложения, без перехода в отдельное приложение или браузер.

Иконка в палитре — прямоугольник с логотипом YouTube.

Как работает

  • Отображает окно плеера YouTube в разметке.
  • Видео задаётся через ID видео (не полную ссылку) — например, dQw4w9WgXcQ.
  • Поддерживает воспроизведение, паузу, перемотку, полный экран.
  • Может запускаться автоматически при появлении экрана.
  • Показывает стандартные элементы YouTube: логотип, кнопки, название.
  • Может быть встроен в разные экраны: список видео, детали, онбординг.

Когда использовать

  • Обучающие приложения — уроки с YouTube.
  • Каталоги видео — подборки роликов по теме.
  • Новостные приложения — видеорепортажи.
  • Развлекательные приложения — подборки клипов и трейлеров.
  • Фитнес-приложения — видеоупражнения.
  • Кулинарные приложения — видеорецепты.

Основные свойства

  • VideoId — идентификатор видео на YouTube (не ссылка).
  • AutoPlay — начинать ли воспроизведение автоматически.
  • FullscreenButtonEnabled — показывать ли кнопку полного экрана.
  • ShowInfo — показывать ли информацию о видео.
  • ControlsEnabled — показывать ли стандартные элементы управления.
  • PlayerStyle — стиль плеера: default, minimal, chromeless.
  • Width / Height — обычно match_parent по ширине, wrap_content по высоте.

Как добавить

  • Получи ID видео на YouTube. Это часть ссылки после watch?v=. Например, для https://www.youtube.com/watch?v=dQw4w9WgXcQ — ID будет dQw4w9WgXcQ.
  • В Sketchware Pro 7 подключи библиотеку YouTube Player через Менеджер библиотек.
  • Добавь разрешение INTERNET в Менеджере разрешений.
  • Тап по YoutubePlayer в палитре — виджет добавится в контейнер.
  • В свойствах укажи VideoId — идентификатор нужного видео.
  • Задай AutoPlay, ControlsEnabled, FullscreenButtonEnabled по вкусу.
  • Присвой id — если хочешь управлять воспроизведением из логики.
  • В событиях используй блоки play, pause, loadVideo, cueVideo.

⚠️ Важно: нужен ID видео, а не полная ссылка. Если вставить https://youtube.com/watch?v=..., плеер не заработает.

⚠️ Важно: для работы требуется интернет. Без подключения — плеер покажет ошибку или пустой экран.

⚠️ Важно: YouTube может требовать API-ключ для полноценной работы некоторых функций. Обычно встроенный плеер работает без ключа, но при публикации может потребоваться ключ.

⚠️ Важно: не все видео разрешают встраивание. Некоторые авторы блокируют показ в сторонних приложениях. Плеер покажет «Видео недоступно».

⚠️ Важно: монетизация YouTube-видео не переходит в твоё приложение. Если встраиваешь чужие видео — это нарушение авторских прав, если нет разрешения.

💡 Совет: для списка видео создавай RecyclerView с превью-картинками и названиями. При тапе — открывай экран с YoutubePlayer, куда передаётся VideoId.

💡 Совет: превью видео можно получить по ссылке https://img.youtube.com/vi/<VideoId>/maxresdefault.jpg. Загружай картинку через ImageView — так список видео выглядит красиво.

💡 Совет: для своего контента — используй свои видео с YouTube-канала. Так ты не нарушаешь авторские права.

💡 Совет: не делай AutoPlay = true для длинных видео. Пользователь может не хотеть, чтобы звук запускался сразу. Пусть тапнет play сам.

💡 Совет: предусмотри обработку ошибок — если видео недоступно, покажи пользователю понятное сообщение: «Видео недоступно. Попробуйте позже».

❌ Частая ошибка: вставлять полную ссылку вместо ID видео. Плеер не загрузит видео.

❌ Частая ошибка: забыть про INTERNET. Плеер пустой, ошибки не видно.

❌ Частая ошибка: встраивать чужие видео без разрешения. Это нарушение авторских прав, за которое можно получить страйк или блокировку аккаунта.

❌ Частая ошибка: открывать недоступное видео без обработки ошибки. Пользователь видит пустое окно и не понимает, что произошло.

❌ Частая ошибка: использовать YoutubePlayer для локальных видеофайлов. Для этого есть VideoView (категория Widgets).
