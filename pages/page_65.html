EditText — поле ввода

EditText — поле ввода текста. Виджет, в который пользователь может вводить данные с клавиатуры: имя, email, пароль, сообщение, число. Самый часто используемый виджет после TextView.

Иконка в палитре — прямоугольник с вертикальной чертой курсора.

Как работает

  • Отображает поле ввода с рамкой или подчёркиванием.
  • При тапе — открывается клавиатура, курсор встаёт в поле.
  • Введённый текст можно прочитать в логике через блок getText.
  • Можно задать программно через блок setText.
  • Может принимать только определённый тип данных: текст, число, email, пароль, телефон.

Когда использовать

  • Формы ввода — имя, email, пароль.
  • Поиск — поле для запроса.
  • Чат — поле для сообщения.
  • Калькулятор — поле для числа.
  • Настройки — изменение ника, статуса, описания.
  • Любой ввод данных от пользователя.

Настройки

Настройка Что делает Значения
Text Начальный текст в поле. Любая строка. Обычно оставляют пустым.
Hint Подсказка внутри поля. Исчезает при вводе. Любая строка, например «Введите имя».
InputType Тип ввода — определяет вид клавиатуры и допустимые символы. text — обычный текст;
textPersonName — имя;
textEmailAddress — email;
textPassword — пароль (точки вместо букв);
number — только цифры;
numberDecimal — числа с точкой;
phone — телефон;
textMultiLine — многострочный текст.
TextColor Цвет вводимого текста. HEX или выбор из палитры.
TextSize Размер текста. Число в sp.
HintTextColor Цвет подсказки. HEX или выбор из палитры.
MaxLength Максимальное количество символов. Число.
MaxLines / MinLines Ограничения по строкам. Число. 0 — без ограничения.
Gravity Выравнивание текста внутри поля. left, center, right.
Padding / Margin Внутренние и внешние отступы. Число в dp для каждой стороны.
Width / Height Ширина и высота. match_parent или wrap_content.
SingleLine (Однострочный) Весь ввод в одну строку. Переключатель: вкл / выкл.
Editable Можно ли редактировать. Переключатель: вкл / выкл.
Background Цвет или изображение фона. HEX, drawable-ресурс или NONE.

Свойства виджета

Открой панель свойств, тапнув по EditText в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — edittext1).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Без ID прочитать текст из поля нельзя. Любая строка без пробелов. По умолчанию — edittext1, edittext2 и т. д. Переименуй в emailField, если это поле email.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». Например, android:digits="0123456789" — разрешены только цифры.
Конвертировать Показывает тип виджета — EditText. Обычно менять не нужно. EditText и другие типы виджетов. Оставь как есть.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет поле по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent — для формы, wrap_content — для поиска.
Высота
Height		 Насколько высоким будет поле по вертикали. match_parent, wrap_content, число в dp. wrap_content — стандарт для однострочного поля.
Внутренний отступ
Padding		 Отступ внутри поля — от краёв до текста. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 8 со всех сторон.
Внешний отступ
Margin		 Отступ снаружи поля — от него до соседних элементов и краёв родителя. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin bottom 16 — расстояние между полями формы.
Положение
Position		 Позиционирование виджета внутри родителя (для RelativeLayout). none — по умолчанию;
другие правила зависят от родителя.		 Оставь none для Linear-контейнеров.
Гравитация макета
Layout gravity		 Как виджет выравнивается внутри родителя. none — по умолчанию;
например, center_horizontal.		 Обычно оставляют none.
Вес
Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — поле заберёт всё оставшееся место (например, в строке рядом с кнопкой).

Свойства текста

Свойство (рус / англ) Что делает Значения Пример
Текст
Text		 Начальный текст в поле. Любая строка. По умолчанию — пусто. Обычно оставляют пустым.
Размер текста
Text size		 Размер вводимого текста. Число в sp. По умолчанию — 12sp. 16sp — комфортный размер для формы.
Стиль текста
Text style		 Начертание текста. normal, bold, italic. Обычно normal.
Цвет текста
Text color		 Цвет вводимых символов. NONE — по умолчанию;
HEX или выбор из палитры.		 Тёмно-серый #333333 — для читаемости.
Подсказка
Hint		 Текст-подсказка внутри поля. Исчезает при вводе. Любая строка. По умолчанию — Edit Text. «Введите email» — для поля email.
Цвет подсказки
Hint color		 Цвет текста подсказки. NONE — по умолчанию;
HEX или выбор из палитры.		 Серый #888888 — стандарт для подсказки.
Однострочный
Single line		 Весь ввод в одну строку. Переключатель: вкл / выкл. На скриншоте — выкл. Включи для коротких полей (имя, email).
Строк
Lines		 Количество строк для отображения. Число. 0 — без ограничения. 5 — для поля сообщения.
Тип ввода
Input type		 Тип данных поля — определяет вид клавиатуры. text, textPersonName, textEmailAddress, textPassword, number, numberDecimal, phone, textMultiLine. На скриншоте — text. textEmailAddress — для email;
textPassword — для пароля.
Опция Ime
Ime option		 Настройка поведения клавиатуры и кнопки «Enter». normal — по умолчанию;
actionDone — скрыть клавиатуру;
actionNext — перейти к следующему полю;
actionSearch — кнопка «Найти».		 actionNext — удобно в многострочной форме.

Свойства изображения

Свойство (рус / англ) Что делает Значения Пример
Ресурс фона
Background resource		 Картинка-фон поля из ресурсов проекта. NONE — без фона;
любой drawable-ресурс.		 Обычно оставляют NONE — фон задаётся темой.
Цвет фона
Background color		 Заливка поля сплошным цветом. NONE — без цвета;
HEX или выбор из палитры.		 Белый фон #FFFFFF — для светлой темы.
Enabled
Включено		 Реагирует ли поле на тапы и ввод. Переключатель: вкл — активно;
выкл — заблокировано.		 На скриншоте — включено.
Вращение
Rotation		 Поворот поля вокруг центра. Градусы. 0 — без поворота. Обычно оставляют 0.
Прозрачность
Alpha		 Насколько поле прозрачно. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.
TranslationX Сдвиг поля по горизонтали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. 20.0 — визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг поля по вертикали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.
ScaleX Масштаб по горизонтали — растягивает или сжимает поле по ширине. Число. 1.0 — исходный размер. 1.5 — ширина увеличится в 1,5 раза.
ScaleY Масштаб по вертикали — растягивает или сжимает поле по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: на первых порах достаточно свойств Подсказка, Тип ввода, Размер текста и Однострочный. Остальные оставь по умолчанию.

Как перетащить EditText на макет

EditText, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V), Linear(H) или RelativeLayout.
  3. Раскрой категорию Widgets в палитре слева.
  4. Зажми EditText и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — поле ввода появится в разметке.
  6. Тапни по нему в рабочей области — откроется панель свойств.
  7. Задай Подсказку — что нужно ввести.
  8. Задай Тип ввода — чтобы клавиатура была подходящей (текст, число, email, пароль, телефон).
  9. Присвой осмысленный ID — если хочешь читать текст в логике.
⚠️ Важно: обычный тап по EditText в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: без ID виджет недоступен в логике. Если планируешь читать значение через события, обязательно задай уникальный ID в свойствах.
⚠️ Важно: для паролей используй InputType = textPassword. Иначе введённый пароль будет виден на экране полностью.
⚠️ Важно: не оставляй Hint пустым. Пользователь не поймёт, что вводить. Хорошая подсказка — половина удобства формы.
💡 Совет: для современного вида используй TextInputLayout (категория AndroidX) как обёртку над EditText. Получится поле с плавающей подписью — как в топовых приложениях.
💡 Совет: для числового ввода ставь InputType = number. Тогда клавиатура покажет только цифры, и пользователь не сможет ввести буквы.
💡 Совет: в логике всегда проверяй, что введено. Если поле пустое — не выполняй действие, а покажи пользователю сообщение. Иначе будут ошибки при вычислениях.
❌ Частая ошибка: задавать размер текста в dp вместо sp. При крупном системном шрифте текст останется мелким.
❌ Частая ошибка: забыть про InputType для пароля — и пароль отображается открытым текстом.

Резюме

  • EditText — поле ввода текста от пользователя.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Размещается внутри контейнера — Linear(V), Linear(H), RelativeLayout.
  • Ключевые свойства: Подсказка, Тип ввода, Размер текста, Однострочный.
  • Без ID значение поля нельзя прочитать в логике — обязательно задавай осмысленный ID.
  • Для пароля — InputType = textPassword; для числа — number; для email — textEmailAddress.
  • Размер текста указывается в sp, а не в dp.

Частые ошибки новичков

  • Тапают по EditText в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Забывают задать ID. В логике не получается прочитать введённый текст — виджет не виден.
  • Не ставят InputType для пароля. Пароль отображается открытым текстом.
  • Задают размер в dp вместо sp.
