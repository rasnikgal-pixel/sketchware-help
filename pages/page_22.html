Менеджер компонентов (Добавление библиотек)

Это очень мощный инструмент. Он позволяет добавлять в Sketchware Pro сторонние Java-классы и библиотеки, превращая их в готовые блоки.

  • Пустой экран: надпись «If you add a component here...» означает, что у вас пока нет добавленных компонентов.
  • Кнопка «+»: открывает форму добавления нового компонента.

Форма «Добавить новый компонент»

  • Имя компонента: название, которое будет отображаться в списке компонентов.
  • ID компонента: уникальный идентификатор (обычно на английском, без пробелов).
  • Иконка компонента: картинка, которая будет отображаться рядом с компонентом.
  • Имя типа переменной: техническое имя класса (например, private MyClass name).
  • Класс сборки: имя класса, к которому будет привязан компонент.
  • Класс типа: тип данных (например, String, int, View).
  • URL документации: ссылка на описание (необязательно).
  • Дополнительные переменные: позволяет добавить свои поля в класс. Используйте ### как placeholder для имени компонента.
  • Imports: сюда вписываются Java-импорты, необходимые для работы библиотеки (например, import android.widget.Toast;).
