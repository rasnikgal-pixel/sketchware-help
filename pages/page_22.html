Менеджер компонентов (Добавление библиотек)



Это очень мощный инструмент. Он позволяет добавлять в Sketchware Pro сторонние Java-классы и библиотеки, превращая их в готовые блоки.

· Пустой экран: Надпись «If you add a component here...» означает, что у вас пока нет добавленных компонентов.

· Кнопка «+»: Открывает форму добавления нового компонента.

· Форма «Добавить новый компонент»:

· Имя компонента:
Название, которое будет отображаться в списке компонентов.

· ID компонента:
Уникальный идентификатор (обычно на английском, без пробелов).

· Иконка компонента:
Картинка, которая будет отображаться рядом с компонентом.

· Имя типа переменной:
Техническое имя класса (например, private MyClass name).

· Класс сборки:
Имя класса, к которому будет привязан компонент.

· Класс типа:
Тип данных (например, String, int, View).

· URL документации:
Ссылка на описание (необязательно).

· Дополнительные переменные:
Позволяет добавить свои поля в класс. Используйте ### как placeholder для имени компонента.

· Imports:
Сюда вписываются Java-импорты, необходимые для работы библиотеки (например, import android.widget.Toast;).
