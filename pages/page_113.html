View

View — вторая категория в левом меню вкладки «События». Здесь собраны события виджетов, добавленных в Дизайнере: кнопок, полей ввода, чекбоксов, списков, картинок и других компонентов интерфейса.

Если категория Активность отвечает за жизненный цикл экрана, то View — за взаимодействие с пользователем. Каждое событие этой категории срабатывает в ответ на конкретное действие: тап, ввод текста, переключение флажка.

Список событий категории

  • onClick — при тапе по виджету: кнопке, картинке, TextView с Clickable = true.
  • onLongClick — при долгом нажатии на виджет.
  • onCheckedChanged — при переключении CheckBox, Switch, RadioButton.
  • onTextChanged — при изменении текста в EditText.
  • onItemClick — при выборе элемента в ListView, GridView, RecyclerView.
  • onItemSelected — при выборе элемента в Spinner.
  • onItemLongClick — при долгом нажатии на элемент списка.
  • onProgressChanged — при движении SeekBar.
  • onStartTrackingTouch — при начале движения SeekBar.
  • onStopTrackingTouch — при отпускании SeekBar.
  • onRatingChanged — при изменении рейтинга в RatingBar.
  • onQueryTextSubmit — при нажатии кнопки «Поиск» в SearchView.
  • onQueryTextChange — при изменении текста в SearchView.
  • onScrollChanged — при прокрутке ScrollView.

Когда что использовать

  • onClick — основное событие для кнопок и любых кликабельных элементов.
  • onLongClick — контекстное меню, дополнительные действия по долгому нажатию.
  • onCheckedChanged — реакция на переключение настроек.
  • onTextChanged — проверка ввода в реальном времени (валидация email, длины пароля).
  • onItemClick — открытие деталей при тапе по элементу списка.
  • onItemSelected — реакция на выбор в Spinner.
  • onProgressChanged — обновление значения рядом с SeekBar.
  • onRatingChanged — сохранение оценки, показ «спасибо».

Как добавить событие

  • Тап по категории «View» в левом меню.
  • В открывшемся диалоге — список всех виджетов с id и доступных для них событий.
  • Каждый виджет показан с названием, а под ним — список событий.
  • Отметь нужные галочками.
  • Нажми «Добавить».

⚠️ Важно: категория «View» пуста, пока в проекте нет виджетов с id. Сначала добавь виджет в Дизайнере, присвой ему id — потом возвращайся сюда.

⚠️ Важно: событие не появится, если оно не применимо к виджету. Например, onCheckedChanged не появится для TextView, потому что TextView не переключается.

⚠️ Важно: id виджета должен быть уникальным в пределах экрана. Если два виджета имеют одинаковый id — события для них объединятся, и логика сработает непредсказуемо.

💡 Совет: для кнопки достаточно одного события onClick. Не добавляй onLongClick, onTouch и другие «на всякий случай».

💡 Совет: для валидации форм используй onTextChanged — проверяй правильность ввода по мере набора. Например, подсвечивай поле красным, если email введён неверно.

💡 Совет: для списка используй onItemClick — получишь позицию выбранного элемента и сможешь открыть его детали.

💡 Совет: для переключателей настроек используй onCheckedChanged — реагируй на переключение сразу, без отдельной кнопки «Сохранить».

❌ Частая ошибка: не задавать id виджетам. Без id виджет не появится в категории View, и событие для него добавить не получится.

❌ Частая ошибка: добавлять события «про запас». Каждое пустое событие — это метод в коде и лишний вес APK.

❌ Частая ошибка: путать onClick и onLongClick. Первое срабатывает при обычном тапе, второе — при долгом нажатии. Разные действия — разные события.

❌ Частая ошибка: ожидать, что onTextChanged срабатывает при установке текста программно. Нет — только при вводе пользователем.
