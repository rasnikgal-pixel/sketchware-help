DatePickerDialog — диалог выбора даты

DatePickerDialog — компонент для показа диалога выбора даты. Пользователь тапает — открывается всплывающее окно с календарём. Выбирает день, месяц, год — и подтверждает.

Иконка в диалоге добавления — календарь с выделенной датой.

Как работает

  • Открывает всплывающее окно с календарём.
  • Пользователь выбирает дату: день, месяц, год.
  • Нажимает «ОК» — дата подтверждена, срабатывает событие.
  • Нажимает «Отмена» — диалог закрывается без изменений.
  • Можно задать минимальную и максимальную дату.
  • Отличие от DatePicker (виджет в разметке) — не занимает места на экране, открывается по необходимости.

Когда использовать

  • Дата рождения — в формах регистрации.
  • Бронирование — выбор даты поездки, визита.
  • Напоминания — установка даты срабатывания.
  • Фильтры — «с какой по какую дату».
  • Календарь событий — добавление события на день.
  • Отчётность — период с и по.
  • Заказ доставки — дата доставки.

Настройки при добавлении

Настройка Что задаёт Пример
Имя компонента Идентификатор для вызова в логике. dateDialog, birthdayPicker.

Основные блоки в логике

Блок Что делает
show Показать диалог.
setTitle Задать заголовок окна.
setMinDate Минимальная дата.
setMaxDate Максимальная дата.
setYear / setMonth / setDay Стартовая дата.

Событие DatePickerDialog

Событие Когда срабатывает
onDateSet Срабатывает при подтверждении даты. Внутри — доступ к выбранному году, месяцу, дню.

Как использовать

  1. Подключи компонент DatePickerDialog на вкладке «Компонент».
  2. Задай имя — например, birthdayPicker.
  3. В логике:
    • вызови show — откроется диалог;
    • задай setTitle — например, «Выберите дату рождения»;
    • задай setMinDate и setMaxDate, если нужны ограничения.
  4. В категории «Компонент» добавь событие onDateSet — обработка выбранной даты.
  5. Внутри события получи год, месяц, день — и сохрани их или покажи.

Пример: дата рождения

  • EditText для даты.
  • Button «Выбрать дату».
  • В onClick — birthdayPicker.show().
  • Ограничения: MaxDate = сегодня, MinDate = 1900-01-01.
  • В onDateSet — установи в EditText выбранную дату в формате 29.09.2026.

Пример: напоминание

  • Button «Установить напоминание».
  • onClick → dateDialog.show().
  • Пользователь выбирает дату.
  • В onDateSet — сохрани дату через Calendar и настрой Notification.
⚠️ Важно: месяцы нумеруются с 0. Январь — 0, декабрь — 11. Частая причина сдвигов на месяц.
⚠️ Важно: год указывается полностью: 2026, а не 26. Иначе дата будет неправильной.
⚠️ Важно: DatePickerDialog — компонент, а не виджет. Его не добавляют в разметку — он открывается по вызову.
⚠️ Важно: не открывай второй диалог, пока первый открыт. Второй вызов show — непредсказуемое поведение.
💡 Совет: для даты рождения задавай MaxDate = сегодня. Нельзя родиться в будущем.
💡 Совет: для бронирования задавай MinDate = сегодня. Нельзя забронировать на прошлое.
💡 Совет: для стартовой даты ставь текущий день через setYear, setMonth, setDay. Так пользователь видит актуальный календарь.
💡 Совет: для формата отображения используй Calendar и format с шаблоном dd.MM.yyyy для России.
💡 Совет: для двух дат (начало и конец) используй два DatePickerDialog: один для начала, другой для конца. Второй открывай только после выбора первого.
💡 Совет: для проверки корректности даты сравнивай с текущей и другими условиями. Например, «дата окончания не может быть раньше даты начала».
❌ Частая ошибка: забыть про нумерацию месяца с 0. Январь = 0, не 1.
❌ Частая ошибка: не ограничивать диапазон. Пользователь может выбрать 1800 год или дату через 100 лет.
❌ Частая ошибка: путать DatePickerDialog и DatePicker. Диалог — компонент, открывается по вызову. Виджет — в разметке.
❌ Частая ошибка: не обрабатывать onDateSet. Диалог открывается, пользователь выбирает дату — а приложение ничего не делает.
❌ Частая ошибка: использовать диалог без заголовка. Пользователь не понимает, что именно выбирает — день рождения или дату доставки.

Резюме

  • DatePickerDialog — компонент для выбора даты через всплывающее окно.
  • Основные блоки: show, setTitle, setMinDate, setMaxDate, setYear / setMonth / setDay.
  • Основное событие: onDateSet — при подтверждении даты.
  • Месяц нумеруется с 0 — январь = 0, декабрь = 11.
  • Не открывай два диалога одновременно.
  • Ограничивай MinDate / MaxDate для защиты от ошибок.
  • Для двух дат — два компонента Dialog.
  • Задавай понятный заголовок — что выбирает пользователь.

Частые ошибки новичков

  • Забывают про нумерацию месяца с 0. Дата сдвигается на месяц.
  • Не ограничивают диапазон дат. Пользователь выбирает нереалистичные даты.
  • Путают с DatePicker. Диалог — компонент, виджет — в разметке.
  • Не обрабатывают onDateSet. Дата выбирается, но не используется.
  • Задают заголовок «Дата». Неинформативно. Лучше «Выберите дату рождения».
  • Не ставят стартовую дату. Календарь открывается на текущем дне, но это не всегда удобно.
  • Открывают второй диалог поверх первого. Поведение непредсказуемо.
