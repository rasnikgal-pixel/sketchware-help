Spinner — выпадающий список

Spinner — выпадающий список. Компактный виджет, который показывает выбранный вариант, а по тапу раскрывает меню со всеми доступными. Похож на AutoCompleteTextView, но с ключевым отличием: пользователь не может ввести своё значение — только выбрать из списка.

Иконка в палитре — прямоугольник со стрелкой вниз.

Как работает

  • Отображает текущее выбранное значение в одной строке.
  • Справа — стрелка ∨, обозначающая выпадающее меню.
  • Тап по виджету — открывается всплывающий список со всеми вариантами.
  • Тап по варианту — список закрывается, значение подставляется в поле.
  • При выборе срабатывает событие onItemSelected.
  • Пользователь не может ввести произвольный текст — только выбрать из предложенных.

Когда использовать

  • Выбор из фиксированного списка — пол, страна, город из заранее известных.
  • Фильтры — «Все», «Активные», «Завершённые».
  • Сортировка — «По цене», «По дате», «По популярности».
  • Категории — выбор категории товара или статьи.
  • Настройки — выбор языка, темы, валюты.

Это идеальный выбор, когда вариантов немного (3–20) и они заранее известны.

Настройки

Настройка Что делает Значения
Prompt Подпись, показываемая в выпадающем окне сверху. Любая строка, например «Выберите город».
TextColor Цвет текста выбранного значения. HEX или выбор из палитры.
TextSize Размер текста. Число в sp.
Background Фон виджета. HEX, drawable-ресурс или NONE.
Gravity Выравнивание текста в виджете. left, center, right.
Padding / Margin Внутренние и внешние отступы. Число в dp для каждой стороны.
Width / Height Ширина и высота. Обычно match_parent по ширине.

Свойства виджета

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — spinner1, spinner2 и т. д. Переименуй в sortSpinner, если это выбор сортировки.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». Например, android:spinnerMode="dialog" — открывать как диалог вместо выпадающего меню.
Конвертировать Показывает тип виджета — Spinner. Обычно менять не нужно. Spinner и другие типы виджетов. Оставь как есть.
Режим Spinner
Spinner mode		 Как показывать варианты. dropdown — выпадающее меню под виджетом;
dialog — модальное окно по центру.		 На скриншоте — dropdown. Для длинных списков лучше dialog.
Пользовательский вид
Custom view		 Свой Layout для элемента списка (вместо стандартного текста). none — стандартный вид; любой XML-макет. Оставь none, если достаточно текста.

Внешний отступ
Margin		 Отступ снаружи виджета — от него до соседних элементов. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin bottom 16 — между полями формы.

Layout gravity		 Как виджет выравнивается внутри родителя. none — по умолчанию;

Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — виджет заберёт всё оставшееся место.

Вращение

Прозрачность
Alpha		 Насколько виджет прозрачен. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.

💡 Совет для новичков: в панели свойств задаётся только внешний вид. Список вариантов задаётся в логике через setItems или setSimpleItems, а выбор по умолчанию — через setSelection.

Как перетащить Spinner на макет

Spinner, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V) или RelativeLayout.
  3. Раскрой категорию Списки в палитре слева.
  4. Зажми Spinner и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — спиннер появится в разметке.
  6. Задай Prompt — что написать над выпадающим меню.
  7. Присвой осмысленный ID — он нужен для логики.
  8. Открой вкладку «События» и добавь в onCreate:
    • блок setItems или setSimpleItems — задать список вариантов;
    • блок setSelection — выбрать элемент по умолчанию.
  9. Добавь событие onItemSelected — реакцию на выбор.
⚠️ Важно: обычный тап по Spinner в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: без заполнения списка в логике Spinner пуст — тап по нему ничего не раскрывает.
⚠️ Важно: значения нельзя вводить вручную. Если пользователь должен иметь возможность ввести своё — используй AutoCompleteTextView или EditText.
💡 Совет: для списка из 3–10 вариантов Spinner — идеальный выбор. Для 20+ вариантов лучше использовать AutoCompleteTextView — в нём есть поиск по подсказкам.
💡 Совет: задавай первый элемент как осмысленное значение, а не пустую строку. Например, для фильтра сортировки: «Сначала новые» — понятнее, чем прочерк или пустое значение.
💡 Совет: используй setSelection в onCreate, чтобы при запуске приложения был выбран логичный вариант по умолчанию. Иначе Spinner покажет первый элемент из списка, что не всегда ожидаемо.
💡 Совет: если нужно несколько таких выборов на одном экране (страна, город, категория), используй TextInputLayout над каждым Spinner — так пользователь поймёт, что где.
❌ Частая ошибка: использовать Spinner для большого списка (100+ элементов). В нём нет поиска — пользователь замучается листать.
❌ Частая ошибка: перетащить Spinner и забыть задать список вариантов. Виджет выглядит пустым и не реагирует на тап.
❌ Частая ошибка: путать Spinner (только выбор из списка) и AutoCompleteTextView (можно ввести своё). Для фиксированного выбора — Spinner, для свободного ввода — AutoCompleteTextView.

Резюме

  • Spinner — компактный выпадающий список для выбора одного значения из фиксированного набора.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Список вариантов задаётся в логике — через setItems или setSimpleItems.
  • Значение по умолчанию задаётся через setSelection.
  • Пользователь не может ввести своё значение — только выбрать из предложенных.
  • Подходит для 3–20 вариантов. Для больших списков — AutoCompleteTextView с подсказками.
  • Событие onItemSelected — реакция на выбор.
  • Режим dialog в свойствах Spinner удобен для длинных списков.

Частые ошибки новичков

  • Тапают по Spinner в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетащили спиннер, но не задали список вариантов. Поле пустое, при тапе ничего не раскрывается.
  • Ищут содержимое списка в свойствах. Данные задаются только в логике.
  • Используют Spinner для большого списка. Пользователь замучается листать — нужен AutoCompleteTextView.
  • Путают Spinner с AutoCompleteTextView. Spinner — только выбор; AutoComplete — с возможностью ввода.
  • Не задают setSelection. По умолчанию выбирается первый элемент — не всегда то, что нужно.
  • Не задают ID. Виджет не появляется в событиях, логика не подключается.
