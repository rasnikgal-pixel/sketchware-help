Scroll(H) — горизонтальная прокрутка

Scroll(H) — контейнер с горизонтальной прокруткой. Содержимое внутри него можно сдвигать влево-вправо, если оно не помещается по ширине экрана.

Иконка в палитре — прямоугольник с изогнутой стрелкой в горизонтальной плоскости.

Как работает

  • Внутри Scroll(H) может быть только один дочерний элемент — обычно это Linear(H).
  • Все виджеты перетаскиваются внутрь этого Linear(H), и вместе они образуют прокручиваемую полосу.
  • Ширина содержимого определяется суммой ширин виджетов внутри.
  • Если ширина содержимого больше ширины экрана — появляется горизонтальная прокрутка.
  • Если меньше — прокрутка не появляется, содержимое стоит на месте.

Когда использовать

  • Галерея картинок — ряд миниатюр, которые листаются вбок.
  • Горизонтальное меню — иконки или кнопки в ряд.
  • Карусель карточек — например, подборка товаров или новостей.
  • Таблица с широкими столбцами — больше, чем помещается на экран.
  • Строка с крупными изображениями, которые не влезают целиком.

Структура, которую нужно строить

  • Scroll(H) — внешний контейнер с прокруткой.
  • Linear(H) — единственный дочерний элемент внутри Scroll(H).
  • Внутри Linear(H) — сами виджеты: ImageView, Button, TextView.

Без Linear(H) внутри виджеты не будут корректно выстраиваться в ряд.

Как перетащить Scroll(H) на макет

  1. Открой вкладку «Дизайнер».
  2. Раскрой категорию Layouts в палитре слева.
  3. Зажми Scroll(H) и, не отпуская, перетащи его на макет.
  4. Отпусти в нужном месте — контейнер появится в разметке.
  5. Сразу перетащи внутрь Scroll(H) контейнер Linear(H) — без него прокрутка работать не будет.
  6. Затем перетаскивай нужные виджеты (ImageView, Button, TextView) внутрь Linear(H).
⚠️ Важно: обычный тап по Scroll(H) в палитре ничего не делает. Контейнер попадает на макет только перетаскиванием.

Свойства контейнера

Открой панель свойств, тапнув по контейнеру в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — hscroll2).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя контейнера. По этому имени контейнер виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — hscroll1, hscroll2 и т. д. Переименуй в galleryRow, если это галерея картинок.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». Например, android:scrollbars="horizontal".
Конвертировать Превратить этот контейнер в другой тип (например, в VerticalScrollView). HorizontalScrollView, VerticalScrollView и другие. Если нужна вертикальная прокрутка — переключи на VerticalScrollView.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет контейнер по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent, чтобы область прокрутки заняла весь экран по ширине.
Высота
Height		 Насколько высоким будет контейнер по вертикали. match_parent, wrap_content, число в dp. wrap_content — высота подстроится под самую высокую картинку в ряду.
Внутренний отступ
Padding		 Отступ внутри контейнера — от его краёв до содержимого. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Padding 8 со всех сторон — картинки не липнут к краям контейнера.
Внешний отступ
Margin		 Отступ снаружи контейнера — от него до соседних элементов и краёв родителя. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin top 16 — ряд сдвинется на 16 dp вниз от предыдущего элемента.
Гравитация макета
Layout gravity		 Как контейнер выравнивается внутри родителя: по левому краю, центру, правому и т. п. none — по умолчанию;
например, center_horizontal, right.		 center_horizontal — контейнер встанет по центру родителя.
Вес
Weight		 Доля свободного места родителя, которую займёт этот контейнер. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — контейнер заберёт всё оставшееся место в родителе.

Свойства изображения

Свойство (рус / англ) Что делает Значения Пример
Ресурс фона
Background resource		 Картинка-фон контейнера из ресурсов проекта. NONE — без фона;
любой drawable-ресурс.		 Установи NONE, если фон не нужен.
Цвет фона
Background color		 Заливка контейнера сплошным цветом. NONE — без цвета;
HEX или выбор из палитры (например, #EEEEEE).		 Светло-серый фон под ряд картинок — #EEEEEE.
Вращение
Rotation		 Поворот контейнера вокруг центра. Градусы. 0 — без поворота. 90 — контейнер развернётся на 90°.
Прозрачность
Alpha		 Насколько контейнер и его содержимое прозрачны. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 0.5 — половина прозрачности.
TranslationX Сдвиг контейнера по горизонтали без изменения его места в разметке (визуальный сдвиг). Число в dp. 0.0 — без сдвига. 20.0 — контейнер визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг контейнера по вертикали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.
ScaleX Масштаб по горизонтали — растягивает или сжимает контейнер по ширине. Число. 1.0 — исходный размер. 1.5 — ширина увеличится в 1,5 раза.
ScaleY Масштаб по вертикали — растягивает или сжимает контейнер по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: на первых порах достаточно четырёх свойств — Ширина, Высота, Внутренний отступ, Внешний отступ. Остальные оставь по умолчанию.

Практический пример: галерея картинок

  1. Перетащи на макет Linear(V) — он будет корневым.
  2. Внутрь перетащи Scroll(H).
  3. Сразу перетащи внутрь Scroll(H) контейнер Linear(H).
  4. Внутрь Linear(H) перетащи несколько ImageView подряд.
  5. Тапни по каждому ImageView и задай Ширину 150dp, Высоту wrap_content.
  6. Добавь Внешний отступ справа 8dp у каждого ImageView, чтобы они не слипались.
  7. Готово: ряд картинок можно листать влево-вправо.
⚠️ Важно: Scroll(H) с одним дочерним элементом — жёсткое требование Android. Если попытаться перетащить внутрь несколько элементов напрямую, минуя Linear(H), сборка либо выдаст ошибку, либо поведение будет непредсказуемым.
⚠️ Важно: не вкладывай Scroll(H) в Scroll(H) — получится конфликт жестов, прокрутка будет дёргаться или зависать.
💡 Совет: для галереи картинок задавай каждому ImageView фиксированную ширину (например, 150dp) и wrap_content по высоте. Тогда элементы выстроятся ровным рядом.

Резюме

  • Scroll(H) — контейнер с горизонтальной прокруткой: содержимое листается влево-вправо.
  • Перетаскивается на макет так же, как любой другой виджет — перетаскиванием, а не тапом.
  • Внутри должен быть ровно один дочерний элемент — обычно Linear(H).
  • Прокрутка появляется только тогда, когда ширина содержимого превышает ширину экрана.
  • Главные свойства: Ширина, Высота, Внутренний и Внешний отступы, Гравитация макета, Вес.
  • Свойства изображения — визуальные, для тонкой настройки.

Частые ошибки новичков

  • Тапают по Scroll(H) в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетаскивают Scroll(H) без Linear(H) внутрь. Прокрутки нет — виджеты не размещаются в ряд.
  • Перетаскивают внутрь Scroll(H) несколько элементов напрямую, минуя Linear(H). Это нарушает требование Android «один дочерний элемент».
  • Вкладывают Scroll(H) в Scroll(H). Жесты конфликтуют, прокрутка дёргается.
  • Ждут прокрутки при маленьком содержимом. Если ширина ряда меньше ширины экрана — листать нечего, прокрутка не появится.
