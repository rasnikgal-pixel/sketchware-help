RatingBar — звёзды рейтинга

RatingBar — индикатор рейтинга звёздочками. Пользователь тапает по звёздочкам или видит уже выставленную оценку: от 0 до 5 (или другого максимума).

Иконка в палитре — ряд звёздочек.

Как работает

  • Отображает ряд звёзд — закрашенные и незакрашенные.
  • В интерактивном режиме пользователь тапает по звезде — рейтинг выставляется.
  • В режиме отображения звёзды только показывают оценку, но не реагируют на тап.
  • Может принимать дробные значения (например, 3.5 звезды).
  • Текущее значение читается в логике через блок getRating.

Когда использовать

  • Оценка товаров — покупатель ставит 1–5 звёзд.
  • Рейтинг приложений — «Оцените нас».
  • Оценка статьи или поста — понравилось / не понравилось.
  • Отзывы в приложении — насколько удобно.
  • Рейтинг фильмов — показать среднюю оценку.
  • Опросы — оценка от 1 до 5.

Настройки

Настройка Что делает Значения
Rating Текущее значение рейтинга. Число от 0 до NumStars. Например, 3.5.
NumStars Количество звёзд. Число. Обычно 5.
StepSize Шаг изменения рейтинга. 1.0 — целые звёзды;
0.5 — половинки.
IsIndicator Режим «только отображение» — пользователь не может менять рейтинг. Переключатель: вкл / выкл.
RatingTint Цвет закрашенных звёзд. HEX или выбор из палитры.
ProgressTint Цвет незакрашенных (фоновых) звёзд. HEX или выбор из палитры.
Width / Height Ширина и высота. wrap_content или match_parent.

Свойства виджета

Открой панель свойств, тапнув по RatingBar в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7 (на скриншоте пример ID — ratingbar1).

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя виджета. По этому имени виджет виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — ratingbar1, ratingbar2 и т. д. Переименуй в productRating, если это оценка товара.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». Например, android:numStars="5".
Конвертировать Показывает тип виджета — RatingBar. Обычно менять не нужно. RatingBar и другие типы виджетов. Оставь как есть.

💡 Совет для новичков: в панели свойств доступен только внешний вид. NumStars, StepSize, Rating и IsIndicator задаются через Пользовательские атрибуты — в виде android:numStars="5", android:stepSize="1.0", android:rating="3", android:isIndicator="true".

Как перетащить RatingBar на макет

RatingBar, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V), Linear(H) или RelativeLayout.
  3. Раскрой категорию Widgets в палитре слева.
  4. Зажми RatingBar и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — звёзды появятся в разметке.
  6. Через Пользовательские атрибуты задай:
    • android:numStars="5" — количество звёзд;
    • android:stepSize="1.0" — шаг (1.0 или 0.5);
    • android:rating="0" — начальное значение;
    • android:isIndicator="false" — можно ли менять.
  7. Присвой осмысленный ID — он нужен для логики.
  8. Для интерактивного режима открой вкладку «События» и добавь событие onRatingChanged.
⚠️ Важно: обычный тап по RatingBar в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: если isIndicator = true, пользователь не может изменить оценку. Это режим только для отображения — например, показать средний рейтинг товара.
⚠️ Важно: StepSize = 1.0 запрещает дробные оценки. Если нужно разрешить «3.5 звезды» — поставь StepSize = 0.5.
💡 Совет: для оценки товаров используй StepSize = 1.0 — обычно пользователю достаточно целых звёзд. Половинки нужны редко.
💡 Совет: для среднего рейтинга (например, из 100 отзывов) используй IsIndicator = true и StepSize = 0.5. Так можно показать 4.5 звезды без интерактивности.
💡 Совет: после того как пользователь поставил оценку — покажи ему спасибо или предложи написать отзыв. Просто звёзды без реакции выглядят как «чёрная дыра».
💡 Совет: не делай 10 звёзд. Стандарт — 5. Воспринимается интуитивно.
❌ Частая ошибка: оставить IsIndicator = false на экране, где рейтинг должен отображаться как «средний». Пользователь может случайно изменить чужую оценку.
❌ Частая ошибка: забыть про StepSize и удивляться, почему нельзя поставить «ползвезды».

Резюме

  • RatingBar — индикатор рейтинга звёздочками: интерактивный или только для отображения.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Ключевые настройки задаются через Пользовательские атрибуты: numStars, stepSize, rating, isIndicator.
  • Для интерактивного режима используется isIndicator = false + событие onRatingChanged.
  • Для отображения среднего рейтинга — isIndicator = true.
  • Стандарт — 5 звёзд. StepSize = 1.0 для целых, 0.5 для половинок.
  • Текущее значение читается в логике через блок getRating.

Частые ошибки новичков

  • Тапают по RatingBar в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Ищут NumStars и StepSize в обычных свойствах. Их нужно задавать через «Пользовательские атрибуты».
  • Оставляют IsIndicator = false на экране отображения среднего рейтинга. Пользователь может случайно изменить оценку.
  • Забывают про StepSize. Половинки звёзд не работают.
  • Не добавляют событие onRatingChanged. Оценка не считывается в логику.
  • Делают 10 звёзд. Пользователь путается. Стандарт — 5.
  • Не показывают реакцию на оценку. Пользователь поставил звезду — и ничего. Лучше показать «Спасибо!».
