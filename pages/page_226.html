Компоненты HelpStudio

Компоненты — невидимые сервисы приложения. В HelpStudio их три:

  • Намерение / (Intent) — переходы между экранами.
  • Диалог / (Dialog) — всплывающие окна.
  • Индикатор выполнения / (ProgressDialog) — показ процесса.
Внимание. SharedPreferences в компонентах нет. Хранение данных в Sketchware Pro 7 работает через блоки из палитры: Записать строку / (Put String), Прочитать строку / (Get String) и другие. Эти блоки находятся в палитре блоков на вкладке «События». Компонент для этого подключать не нужно.

Как подключить компонент — по шагам

  1. Открой вкладку «Компонент» в шапке рабочего экрана проекта.
  2. Нажми «+» в правом нижнем углу — откроется диалог со списком компонентов.
  3. Найди нужный в категории.
  4. Тапни по нему — откроется форма настройки.
  5. Задай имя компонента.
  6. Нажми «Добавить» — компонент появится в списке.
Внимание. Компоненты подключаются один раз на весь проект. Они доступны во всех экранах.

Компонент 1. Намерение / (Intent)

Механизм переходов между экранами и передачи данных.

Как подключить:

  • Вкладка «Компонент» → «+» → категория «Основные» → Intent.
  • Имя компонента: goToScreen.
  • Нажать «Добавить».

Блоки, которые появятся в логике:

  • Установить экран / (Set Screen) — задать, на какой экран перейти.
  • Добавить данные / (Put Extra) — передать значение.
  • Получить данные / (Get Extra) — прочитать переданное значение.
  • Запустить экран / (Start Activity) — открыть экран.
  • Завершить / (Finish) — закрыть текущий экран.
Внимание. Ключи данных при передаче и чтении должны совпадать. Если в Put Extra ключ project_id, то в Get Extra должен быть тот же ключ.

Компонент 2. Диалог / (Dialog)

Всплывающее окно поверх текущего экрана.

Как подключить:

  • Вкладка «Компонент» → «+» → категория «Основные» → Dialog.
  • Имя компонента: myDialog.

Блоки:

  • Показать / (Show) — показать диалог.
  • Установить заголовок / (Set Title).
  • Установить сообщение / (Set Message).
  • Установить положительную кнопку / (Set Positive Button).
  • Установить отрицательную кнопку / (Set Negative Button).
  • Закрыть / (Dismiss).

События:

  • При нажатии положительной / (onDialogPositiveClick).
  • При нажатии отрицательной / (onDialogNegativeClick).
Частая ошибка. Забыть добавить события onDialogPositiveClick и onDialogNegativeClick. Без них диалог откроется, но нажатия ничего не сделают.

Компонент 3. Индикатор выполнения / (ProgressDialog)

Всплывающее окно с крутящимся спиннером.

Как подключить:

  • Вкладка «Компонент» → «+» → категория «Основные» → ProgressDialog.
  • Имя компонента: loadingDialog.

Блоки:

  • Показать / (Show).
  • Закрыть / (Dismiss).
  • Установить сообщение / (Set Message).
Внимание. Прогресс-диалог не закрывается сам. Вызвал Show — обязательно вызови Dismiss.

Хранение данных — через блоки

В HelpStudio нужно сохранять данные между запусками приложения. Для этого используются блоки из палитры логики, а не компоненты.

Где найти блоки:

  1. Открой вкладку «События».
  2. Открой любое событие (например, onCreate).
  3. В палитре блоков найди категорию с блоками хранения.
  4. Блоки: Записать строку / (Put String), Прочитать строку / (Get String), Записать булево / (Put Boolean), Прочитать булево / (Get Boolean), Записать число / (Put Int), Прочитать число / (Get Int), Удалить / (Remove), Очистить всё / (Clear).

Что будем хранить:

Ключ Тип Что хранит
projects_listСтрокаСписок проектов (разделитель ;;;).
theme_darkБулевоТёмная тема включена.

Частая ошибка. Забыть про значение по умолчанию при чтении. Если ключа нет (первый запуск), Прочитать строку / (Get String) без значения по умолчанию может вернуть ошибку. Всегда указывай значение по умолчанию.

Что важно понять про компоненты

Первое — компоненты не работают сами по себе. Они становятся доступны в логике, но вызывать их нужно через блоки в событиях. Просто подключить Dialog — недостаточно. Нужно в событии вызвать Показать / (Show), чтобы диалог появился.

Второе — компоненты видны во всех экранах. Один компонент Intent можно использовать и в MainActivity, и в EditorActivity, и в PreviewActivity, и в SettingsActivity. Не нужно дублировать.

Третье — не подключай лишние компоненты. Если компонент не используется — он всё равно увеличивает вес APK. Подключай только то, что реально нужно.

Подсказка для новичка. После подключения компонента в шапке проекта на секунду появляется сообщение «В редакторе логики добавлены новые блоки». Это значит, что в палитре блоков появились новые блоки для этого компонента. Открой любое событие и убедись, что они там есть.
