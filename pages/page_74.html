Switch — тумблер

Switch — переключатель «вкл/выкл». Выглядит как ползунок, который пользователь двигает вправо или влево. По смыслу похож на CheckBox (два состояния), но визуально отличается и используется для мгновенного применения настроек.

Иконка в палитре — овальный ползунок.

Как работает

  • Имеет два состояния: Checked = true (включён) или false (выключен).
  • Тап по переключателю мгновенно меняет состояние.
  • В отличие от CheckBox, визуально показывает «включено прямо сейчас» — как тумблер на физическом приборе.
  • При переключении срабатывает событие onCheckedChanged.
  • Дополнительно может озвучивать состояние текстом: например, «Вкл» / «Выкл».

Когда использовать

  • Настройки приложения — «Тёмная тема», «Уведомления», «Звук».
  • Быстрые переключения — Wi-Fi, Bluetooth, автосохранение.
  • Мгновенно применяемые опции — изменения вступают в силу сразу, без кнопки «Сохранить».
  • Включение / отключение функций — «Показывать рекламу», «Использовать геолокацию».

Switch идеален там, где переключение сразу что-то делает. Для «отметить и потом нажать кнопку» больше подходит CheckBox.

ShowText Показывать ли на самом переключателе надписи «ON»/«OFF» (зависит от темы). Переключатель: вкл / выкл.
Padding / Margin Внутренние и внешние отступы. Число в dp для каждой стороны.
Width / Height Ширина и высота. wrap_content или match_parent.

💡 Совет для новичков: главные свойства Switch — Текст, Checked, Размер текста и Цвет текста. Чтобы состояние переключателя сохранялось — используй SharedPreferences в логике.

Как перетащить Switch на макет

Switch, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V), Linear(H) или RelativeLayout.
  3. Раскрой категорию Widgets в палитре слева.
  4. Зажми Switch и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — переключатель появится в разметке.
  6. Тапни по нему и задай Текст — например, «Уведомления».
  7. Присвой осмысленный ID — он нужен для чтения и сохранения состояния.
  8. Открой вкладку «События» — добавь событие onCheckedChanged для этого переключателя.
  9. Внутри события опиши логику и при необходимости сохраняй состояние в SharedPreferences.
⚠️ Важно: обычный тап по Switch в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: без onCheckedChanged переключатель визуально двигается, но ничего не делает. Логику нужно описывать вручную.
⚠️ Важно: Switch не сохраняет своё состояние между запусками приложения автоматически. Чтобы настройка «запомнилась», нужно сохранять её в SharedPreferences в логике, а при запуске — восстанавливать.
💡 Совет: для настроек, которые должны сохраняться между сессиями, используй SharedPreferences (категория «Компоненты»). В onCheckedChanged записывай значение, в onCreate — читай и устанавливай Checked.
💡 Совет: для мгновенных переключателей (например, включить/выключить звук в игре) Switch подходит идеально. Для опций, которые применяются по кнопке «Сохранить» — лучше CheckBox.
💡 Совет: не делай подписи слишком длинными. Switch с текстом «Включить автоматическое обновление данных в фоне» выглядит плохо. Коротко: «Автообновление».
❌ Частая ошибка: ждать, что состояние Switch сохранится само после выхода из приложения. Без SharedPreferences — сбросится в исходное значение.
❌ Частая ошибка: использовать Switch для множественного выбора. Если нужны «галочки» на нескольких опциях — это CheckBox, а не Switch.

Резюме

  • Switch — тумблер «вкл/выкл» для мгновенного применения настроек.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • По смыслу похож на CheckBox, но визуально — тумблер и чаще используется для настроек.
  • Ключевые свойства: Текст, Checked, Размер текста, Цвет текста.
  • Состояние не сохраняется между запусками приложения — используй SharedPreferences.
  • Для реакции на переключение используется событие onCheckedChanged.
  • Для множественного выбора — CheckBox, а не Switch.

Частые ошибки новичков

  • Тапают по Switch в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Не добавляют событие onCheckedChanged. Переключатель двигается, но ничего не делает.
  • Ждут, что состояние сохранится само. Нужно писать логику с SharedPreferences.
  • Используют Switch для множественного выбора. Нужен CheckBox.
  • Используют Switch для формы, которая отправляется по кнопке. Лучше подходит CheckBox.
  • Пишут длинные подписи. Switch с длинным текстом выглядит громоздко.
  • Не задают ID. В событиях переключатель не появится, состояние прочитать нельзя.
