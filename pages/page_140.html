BluetoothConnect — Bluetooth-соединение

BluetoothConnect — компонент для работы с Bluetooth. Позволяет подключаться к устройствам по Bluetooth, отправлять и получать данные. Используется для общения с внешними устройствами.

Иконка в диалоге добавления — значок Bluetooth.

Как работает

  • Ищет доступные Bluetooth-устройства рядом.
  • Подключается к выбранному устройству по MAC-адресу.
  • Отправляет и принимает данные между устройствами.
  • Работает в паре с другими компонентами: TextToSpeech, SpeechToText, FilePicker.
  • Требует разрешений: BLUETOOTH, BLUETOOTH_ADMIN, BLUETOOTH_CONNECT (Android 12+).

Когда использовать

  • Управление Arduino — отправка команд на микроконтроллер.
  • Bluetooth-колонки — воспроизведение звука.
  • Умный дом — управление устройствами.
  • Bluetooth-принтеры — печать чеков.
  • Геймпады — подключение игровых контроллеров.
  • Медицинские устройства — глюкометры, тонометры.
  • Обмен файлами — между устройствами.

Настройки при добавлении

Настройка Что задаёт Пример
Имя компонента Идентификатор для вызова в логике. btConnect, bt.

Основные блоки в логике

Блок Что делает
enableBluetooth Включить Bluetooth.
disableBluetooth Выключить Bluetooth.
getBondedDevices Список уже подключённых (спаренных) устройств.
connect Подключиться к устройству по адресу.
sendData Отправить данные.
disconnect Отключиться.

События BluetoothConnect

Событие Когда срабатывает
onConnected Успешное подключение.
onDisconnected Устройство отключено.
onDataReceived Получены данные от устройства.

Как использовать

  1. Подключи компонент BluetoothConnect на вкладке «Компонент».
  2. Задай имя — например, bt.
  3. Добавь разрешения: BLUETOOTH, BLUETOOTH_ADMIN, BLUETOOTH_CONNECT (для Android 12+).
  4. В onCreate — проверь, включён ли Bluetooth. Если нет — предложи включить через enableBluetooth.
  5. Получи список спаренных устройств через getBondedDevices.
  6. Подключись к выбранному через connect с MAC-адресом.
  7. В категории «Компонент» добавь события:
    • onConnected — что делать после подключения;
    • onDataReceived — обработка полученных данных.
  8. Отправляй данные через sendData.

Пример: подключение к Arduino

  • Пользователь спарил HC-05 с телефоном в настройках Android.
  • В приложении — getBondedDevices, выбери HC-05.
  • connect с его MAC-адресом.
  • В onConnected — покажи «Подключено».
  • Кнопка «Свет» → sendData("LED_ON").
  • Микроконтроллер получает команду.
⚠️ Важно: устройство нужно сначала спарить в настройках Android. В приложении ты подключаешься только к уже спаренным устройствам.
⚠️ Важно: разрешения на Bluetooth в Android 12+ изменились. Если приложение не работает — проверь BLUETOOTH_CONNECT в Менеджере разрешений.
⚠️ Важно: не оставляй Bluetooth включённым постоянно. Он быстро разряжает батарею. Выключай после использования.
⚠️ Важно: Bluetooth имеет ограниченный радиус — обычно до 10–30 метров. За пределами радиуса связь теряется.
💡 Совет: для управления Arduino используй текстовые команды: "LED_ON\n", "MOTOR_STOP\n". Приёмник парсит их и выполняет действия.
💡 Совет: для индикации состояния показывай статус подключения в TextView: «Не подключено», «Подключение…», «Готово». Пользователь должен видеть, что происходит.
💡 Совет: для списка устройств используй ListView или Spinner. Пользователь выбирает нужное — ты подключаешься.
💡 Совет: для обмена данными всегда добавляй символ конца строки (\n). Так принимающая сторона знает, где заканчивается команда.
💡 Совет: для тестирования используй модуль HC-05 или HC-06 — самые простые Bluetooth-модули для Arduino. Стоят недорого, работают надёжно.
💡 Совет: не используй Bluetooth для больших объёмов данных. Скорость передачи низкая. Для файлов — Wi-Fi или интернет.
❌ Частая ошибка: не спарить устройство в настройках Android. Приложение не найдёт его, даже если оно рядом.
❌ Частая ошибка: не добавлять новые разрешения для Android 12+. Приложение работает на старых версиях, но не на новых.
❌ Частая ошибка: забывать про \n в конце команды. Принимающая сторона не понимает, где кончается сообщение.
❌ Частая ошибка: держать Bluetooth включённым постоянно. Батарея быстро садится.
❌ Частая ошибка: не обрабатывать потерю связи. Если устройство отключилось — приложение должно показать статус, а не «молчать».

Резюме

  • BluetoothConnect — компонент для работы с Bluetooth-устройствами.
  • Основные блоки: enableBluetooth, disableBluetooth, getBondedDevices, connect, sendData, disconnect.
  • Основные события: onConnected, onDisconnected, onDataReceived.
  • Требует разрешений BLUETOOTH, BLUETOOTH_ADMIN, BLUETOOTH_CONNECT (Android 12+).
  • Устройства нужно сначала спарить в настройках Android.
  • Радиус связи — до 10–30 метров.
  • Для обмена данными добавляй \n в конце команды.
  • Не оставляй Bluetooth включённым — расход батареи.

Частые ошибки новичков

  • Не спаривают устройство в системе. Приложение его не находит.
  • Не добавляют BLUETOOTH_CONNECT для Android 12+. Не работает на новых устройствах.
  • Забывают \n в командах. Приёмник не понимает конец сообщения.
  • Держат Bluetooth всегда включённым. Батарея быстро садится.
  • Не обрабатывают потерю связи. Приложение не показывает статус.
  • Передают большие объёмы данных. Скорость Bluetooth слишком низкая.
  • Не показывают статус подключения. Пользователь не понимает, что происходит.
