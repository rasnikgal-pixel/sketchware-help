Linear(H) — горизонтальный

Linear(H) — линейный макет с горизонтальным расположением элементов. Все дочерние виджеты выстраиваются в одну строку слева направо, один за другим.

Иконка в палитре — три вертикальные полоски рядом.

Как работает

  • Первый перетащенный виджет — самый левый.
  • Второй — правее первого.
  • Третий — ещё правее.
  • Если виджеты не помещаются по ширине — они обрезаются или сжимаются, в зависимости от настроек.
  • По умолчанию контейнер растягивается на всю ширину экрана.

Когда использовать

  • Строка «иконка + текст» — например, ImageView слева, TextView справа.
  • Панель кнопок — две или три кнопки в ряд.
  • Горизонтальное меню — ряд иконок.
  • Форма с полем и кнопкой — EditText слева, Button справа.
  • Вложенная строка внутри вертикального Linear(V).

Как перетащить Linear(H) на макет

  1. Открой вкладку «Дизайнер».
  2. Раскрой категорию Layouts в палитре слева.
  3. Зажми Linear(H) и, не отпуская, перетащи его на макет.
  4. Отпусти в нужном месте — контейнер появится в разметке.
  5. Чтобы поместить внутрь него виджеты, перетаскивай их из палитры поверх этого контейнера — он подсветится, и виджет встанет внутрь.
⚠️ Важно: обычный тап по Linear(H) в палитре ничего не делает. Контейнер попадает на макет только перетаскиванием.

Свойства контейнера

Открой панель свойств, тапнув по контейнеру в рабочей области. Ниже — все свойства с описанием. Значения указаны в том виде, в каком они отображаются в Sketchware Pro 7.

Основные

Свойство (рус / англ) Что делает Значения Пример
ID Уникальное имя контейнера. По этому имени контейнер виден на вкладке «События» и в блоках логики. Любая строка без пробелов. По умолчанию — linear1, linear2 и т. д. Переименуй в rowHeader, если это строка с заголовком.
Пользовательские атрибуты Дополнительные XML-атрибуты, которые можно задать вручную. Нужны опытным пользователям. Пары «атрибут = значение». Например, android:background="#FF0000".
Конвертировать Превратить этот контейнер в другой тип макета (например, в RelativeLayout). LinearLayout, RelativeLayout и другие. Если передумал и хочешь относительное позиционирование — выбери RelativeLayout.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет контейнер по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp — фиксированная ширина.		 match_parent, чтобы строка заняла весь экран.
Высота
Height		 Насколько высоким будет контейнер по вертикали. match_parent, wrap_content, число в dp. wrap_content — высота подстроится под содержимое.
Внутренний отступ
Padding		 Отступ внутри контейнера — от его краёв до содержимого. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Padding 8 со всех сторон — содержимое не липнет к краям.
Внешний отступ
Margin		 Отступ снаружи контейнера — от него до соседних элементов и краёв родителя. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Margin top 16 — контейнер сдвинется на 16 dp вниз от предыдущего элемента.
Ориентация
Orientation		 Направление, в котором выстраиваются дочерние элементы. horizontal — в строку;
vertical — в столбик.		 Для Linear(H) стоит horizontal, менять не нужно.
Сумма весов
Weight sum		 Общая сумма весов дочерних элементов. Нужна, если хочешь распределять свободное место между детьми в пропорциях. Число. 0 — не используется. 2, если у тебя два ребёнка с весом 1 каждый — поделят ширину пополам.
Положение
Position		 Позиционирование контейнера внутри родителя (влияет на порядок и привязку). none — по умолчанию;
другие варианты зависят от типа родителя.		 Оставь none, если не работаешь с RelativeLayout-родителем.
Гравитация макета
Layout gravity		 Как контейнер выравнивается внутри родителя: по левому краю, центру, правому и т. п. none — по умолчанию;
например, center, center_horizontal, right.		 center — контейнер встанет по центру родителя.
Вес
Weight		 Доля свободного места родителя, которую займёт этот контейнер. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — контейнер заберёт всё оставшееся место в родителе.

Свойства изображения

Свойство (рус / англ) Что делает Значения Пример
Ресурс фона
Background resource		 Картинка-фон контейнера из ресурсов проекта. NONE — без фона;
любой drawable-ресурс.		 Установи NONE, если фон не нужен.
Цвет фона
Background color		 Заливка контейнера сплошным цветом. NONE — без цвета;
HEX или выбор из палитры (например, #FF5722).		 Полупрозрачный серый фон для строки — #33FFFFFF.
Вращение
Rotation		 Поворот контейнера вокруг центра. Градусы. 0 — без поворота. 90 — контейнер развернётся на 90°.
Прозрачность
Alpha		 Насколько контейнер и его содержимое прозрачны. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 0.5 — половина прозрачности.
TranslationX Сдвиг контейнера по горизонтали без изменения его места в разметке (визуальный сдвиг). Число в dp. 0.0 — без сдвига. 20.0 — контейнер визуально сдвинется на 20 dp вправо.
TranslationY Сдвиг контейнера по вертикали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. -10.0 — визуально поднимется на 10 dp.
ScaleX Масштаб по горизонтали — растягивает или сжимает контейнер по ширине. Число. 1.0 — исходный размер. 1.5 — ширина увеличится в 1,5 раза.
ScaleY Масштаб по вертикали — растягивает или сжимает контейнер по высоте. Число. 1.0 — исходный размер. 0.5 — высота уменьшится вдвое.
💡 Совет для новичков: на первых порах тебе достаточно четырёх свойств — Ширина, Высота, Внутренний отступ, Внешний отступ. Остальные оставь по умолчанию и трогай только при необходимости.

Практический пример: строка «иконка + текст»

  1. Перетащи на макет Linear(V) — он будет корневым.
  2. Внутрь него перетащи Linear(H) — он станет строкой.
  3. Внутрь Linear(H) перетащи ImageView слева.
  4. Рядом перетащи TextView — он встанет правее ImageView.
  5. Тапни по Linear(H) и задай Внутренний отступ 8 со всех сторон.
  6. Тапни по ImageView и задай Вес 0, а TextView — Вес 1, чтобы текст занял оставшееся место.
⚠️ Важно: если виджетов слишком много и они не помещаются по ширине — Linear(H) их не переносит на новую строку, а обрезает или сжимает. Для многострочного размещения используй RelativeLayout или несколько Linear(H) внутри Linear(V).
💡 Совет: для строки «иконка + текст» задавай иконке фиксированный размер (wrap_content), а тексту — match_parent с весом 1, чтобы он занимал оставшееся место.

Резюме

  • Linear(H) — контейнер, выстраивающий дочерние элементы в строку слева направо.
  • Перетаскивается на макет так же, как любой другой виджет — перетаскиванием, а не тапом.
  • Виджеты внутрь Linear(H) попадают тем же способом: перетаскиванием поверх контейнера.
  • Главные свойства: Ширина, Высота, Внутренний и Внешний отступы, Ориентация, Вес.
  • Свойства изображения (фон, прозрачность, вращение, масштаб) — визуальные, для тонкой настройки.
  • Если элементы не помещаются — Linear(H) их обрезает, а не переносит.

Частые ошибки новичков

  • Тапают по Linear(H) в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетаскивают виджеты рядом с Linear(H), а не внутрь него. В итоге они оказываются в родителе, а не в строке.
  • Ждут переноса на новую строку. Linear(H) не переносит элементы — только обрезает или сжимает.
  • Меняют Orientation вручную на vertical — тогда контейнер превращается в столбик и теряет смысл Linear(H).
  • Забывают про вес. Без веса один виджет может занять всю ширину, а второму места не останется.
