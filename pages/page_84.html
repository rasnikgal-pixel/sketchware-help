RecyclerView — современный список

RecyclerView — современный компонент для отображения списков, пришедший на смену ListView. Гибкий, быстрый и настраиваемый: поддерживает разные типы элементов, анимации, горизонтальную и вертикальную прокрутку, сетки и «карусели».

Иконка в палитре — прямоугольник с несколькими карточками.

Как работает

  • Отображает список элементов, как ListView, но с гораздо большей гибкостью.
  • Переиспользует (recycle) элементы при прокрутке — создаёт только видимые, остальные «переиспользует». Отсюда и название.
  • Поддерживает несколько типов элементов в одном списке: заголовок, карточка, разделитель, кнопка «Показать ещё».
  • Умеет анимировать добавление, удаление и перемещение элементов.
  • Работает как вертикальный список, горизонтальная карусель, сетка или staggered (плитка разной высоты).

Когда использовать

  • Ленты новостей — карточки с картинками и текстом.
  • Каталоги товаров — с фото, ценой, кнопкой.
  • Чаты — сообщения с разной высотой.
  • Горизонтальные карусели — подборка рекомендаций.
  • Списки с заголовками — секции внутри списка.
  • Сложные элементы — где карточка состоит из нескольких виджетов.

Это самый мощный компонент для списков в Android. Используется практически во всех современных приложениях.

Настройки

Настройка Что делает Значения
LayoutManager Определяет, как располагать элементы. LinearLayoutManager — вертикальный или горизонтальный список;
GridLayoutManager — сетка;
StaggeredGridLayoutManager — плитка разной высоты.
Adapter Посредник между данными и элементами. RecyclerView.Adapter.
ItemAnimator Анимация добавления / удаления элементов. DefaultItemAnimator или свой.
HasFixedSize Оптимизация, если размер элементов не меняется. Переключатель: вкл / выкл.
Background Фон списка. HEX или drawable-ресурс.
Width / Height Ширина и высота. Обычно match_parent.

Основные

Свойство (рус / англ) Что делает Значения Пример

Конвертировать Показывает полный класс: androidx.recyclerview.widget.RecyclerView. RecyclerView и другие типы виджетов. Оставь как есть.
Пользовательский вид
Custom view		 Свой Layout для элемента списка (шаблон одной карточки). none — стандартный вид; любой XML-макет элемента. Укажи макет карточки для новостей.

Свойства макета

Свойство (рус / англ) Что делает Значения Пример
Ширина
Width		 Насколько широким будет список по горизонтали. match_parent — на всю ширину родителя;
wrap_content — по содержимому;
число в dp.		 match_parent — стандарт.
Высота
Height		 Насколько высоким будет список по вертикали. match_parent, wrap_content, число в dp. match_parent — чтобы список занимал весь экран.
Внутренний отступ
Padding		 Отступ внутри виджета. Формат: «осталось: N, top: N, right: N, bottom: N». Числа в dp для каждой стороны: left («осталось»), top, right, bottom. На скриншоте Padding = 8 со всех сторон.
Внешний отступ
Margin		 Отступ снаружи виджета — от него до соседних элементов. Числа в dp для каждой стороны: left («осталось»), top, right, bottom. Обычно 0.
Гравитация макета
Layout gravity		 Как виджет выравнивается внутри родителя. none — по умолчанию;
например, center_horizontal.		 Обычно оставляют none.
Вес
Weight		 Доля свободного места родителя, которую займёт виджет. Работает только внутри родителя с весом. Число. 0 — вес не задан. 1 — список заберёт всё оставшееся место.

Прозрачность
Alpha		 Насколько виджет прозрачен. Число от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный). 1.0 — стандарт.
TranslationX Сдвиг виджета по горизонтали без изменения его места в разметке. Число в dp. 0.0 — без сдвига. 20.0 — визуально сдвинется на 20 dp вправо.

💡 Совет для новичков: в панели свойств задаётся только внешний вид. LayoutManager и Adapter задаются в логике — через блоки setRecyclerViewAdapter и настройку layout manager. Также нужен отдельный Layout для элемента списка.

Как перетащить RecyclerView на макет

RecyclerView, как и любой другой виджет, попадает на экран только перетаскиванием (drag & drop). Обычный тап по нему в палитре ничего не делает.

  1. Открой вкладку «Дизайнер».
  2. Убедись, что на макете уже есть контейнер — Linear(V) или RelativeLayout.
  3. Раскрой категорию Списки в палитре слева.
  4. Зажми RecyclerView и, не отпуская, перетащи его поверх контейнера — он подсветится, и виджет встанет внутрь.
  5. Отпусти в нужном месте — список появится в разметке.
  6. Присвой осмысленный ID — без него логика не сможет обратиться к списку.
  7. Создай Layout элемента списка (файл XML в Менеджере представлений) — это шаблон одной карточки.
  8. Открой вкладку «События» и добавь в onCreate:
    • блок setRecyclerViewAdapter — подключить адаптер;
    • или блок setRecyclerViewData, если Sketchware Pro 7 поддерживает простую установку данных.
  9. Настрой тип layout manager: список, сетка или карусель.
⚠️ Важно: обычный тап по RecyclerView в палитре ничего не делает. Виджет попадает на макет только перетаскиванием.
⚠️ Важно: RecyclerView сложнее ListView и GridView. Ему нужен отдельный Layout для элемента и адаптер. Без всего этого он пустой.
⚠️ Важно: RecyclerView не вставляй в Scroll(V) — как и другие списки, он конфликтует с родительской прокруткой. Для вложения используй NestedScrollView.
⚠️ Важно: не путай вертикальный и горизонтальный layout manager. Если задан горизонтальный — элементы выстраиваются в ряд и прокручиваются вбок.
💡 Совет: для новостных лент используй вертикальный LinearLayoutManager — как ListView, но с карточками.
💡 Совет: для карусели рекомендаций используй LinearLayoutManager с горизонтальной ориентацией. Ширина карточки — 150–200dp.
💡 Совет: для каталога товаров используй GridLayoutManager с 2 колонками. Это даёт аккуратную плитку.
💡 Совет: не делай все элементы сложными. Чем больше виджетов внутри карточки, тем медленнее прокрутка. Оптимально — картинка, заголовок, подпись, кнопка.
❌ Частая ошибка: перетащить RecyclerView без адаптера и Layout элемента. Результат — пустая область, пользователь не понимает, что происходит.
❌ Частая ошибка: использовать RecyclerView для очень простого списка из 5 строк. Здесь ListView проще и быстрее в настройке.
❌ Частая ошибка: забыть про HasFixedSize = true, если элементы одинаковой высоты. Это заметно снижает производительность при прокрутке.

Резюме

  • RecyclerView — современный и гибкий компонент для отображения списков.
  • Перетаскивается на макет как любой другой виджет — перетаскиванием, а не тапом.
  • Работает только с адаптером и LayoutManager, задаваемыми в логике.
  • Требует отдельный Layout элемента (шаблон одной карточки).
  • Поддерживает вертикальный список, горизонтальную карусель, сетку и плитку разной высоты.
  • Не вкладывай в Scroll(V) — используй NestedScrollView.
  • Для простых списков лучше ListView; для сложных карточек и лент — RecyclerView.
  • HasFixedSize = true ускоряет прокрутку, если элементы одинаковой высоты.

Частые ошибки новичков

  • Тапают по RecyclerView в палитре и ждут, что он появится на экране. Нужно именно перетащить.
  • Перетащили список, но не подключили адаптер. Пустая область.
  • Не создали Layout элемента. Адаптеру нечего показывать.
  • Вкладывают RecyclerView в Scroll(V). Прокрутка работает нестабильно.
  • Используют для простого списка. ListView проще и быстрее настроить.
  • Забывают про HasFixedSize. Прокрутка работает медленнее.
  • Не задают ID. Логика не может обратиться к списку.
